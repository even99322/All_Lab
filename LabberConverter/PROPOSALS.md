# 改善項目狀態

使用者已核定 1–4，於 0.4.0 實作。所有驗證只使用本機沙盒合成資料，沒有存取真正 NAS。

| 項目 | 已實作行為 |
|---|---|
| 1. NAS 存取逾時 | 本機暫存與轉換、可恢復 I/O 最多三次嘗試、傳回前後 SHA-256 驗證；有限重試不改變作業系統的單次 I/O 逾時。 |
| 2. 來源仍在量測 | 複製前觀察穩定性，檢查寫入鎖與明確執行狀態，複製後及發佈前重新確認；發現量測或變動時拒絕處理。停止但未量滿的資料仍可轉。 |
| 3. 批次中斷 | 原子進度紀錄、勾選續轉、來源／輸出校驗值與設定核對、發佈後中斷恢復、確認已結束的本機工具鎖回收。 |
| 4. 多人修改 Database | 更新前核對版本、變動時重新讀取合併、保留分類與額外節點；持續衝突保留輸出並標記待同步。外部程式未配合鎖定時仍有最後檢查與取代間的競爭窗口。 |

尚待核定的第 5 項：支援多維掃描、額外標量通道、非均勻曲線軸等新來源格式。這些格式目前仍明確報錯，沒有忽略或插值。

詳細操作與限制見 README.md。原廠 Labber 相容性仍需使用目標版本實際確認。
