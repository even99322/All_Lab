# 局部放大、觸控板與拖曳分享
> 框選放大一個區域、用觸控板縮放平移，或把圖直接拖到 PowerPoint、Word、Finder。

## 最短流程
1. **局部放大。** Viewer 工具列三個互動按鈕中的第三個 **局部放大**（放大鏡）。按住左鍵在圖上拖出矩形，放開就放大到那個範圍，可以連續放大好幾層。 ![](zoom_draw.png)
2. **退回上一層。** 在圖上按 **右鍵** 或按 **Esc**，一次退一層，最後回到放大前的畫面。 ![](zoom_back.png)
3. **回到一般操作。** 按第一個按鈕 **指標／一般操作**：左鍵拖曳平移、滾輪縮放、雙擊或右鍵選單 **顯示全部**。
4. **拖曳分享。** 按中間的 **拖曳分享**，然後把圖從 Viewer 拖到 PowerPoint、Keynote、Word 或 Finder，放開就會插入一張 PNG。多窗格時用 **拖曳範圍** 選 **作用中 Pane** 或 **所有 Panes**。 ![](zoom_share.png)

## Mac 觸控板
- **雙指捏合**：以手指位置為中心縮放 1D／2D 圖。
- **雙指滑動**：平移圖（滑鼠滾輪仍然是縮放）。
- 3D 視窗：雙指滑動旋轉、按住 Shift 滑動平移、捏合縮放。

## 結果代表什麼
- 放大、平移只改變看的範圍，不改變資料；匯出時選 **Visible X Range** 才會只輸出看得到的部分。
- 拖曳分享的圖片就是圖表的樣子（包含標記，但不包含畫筆與雷射筆註記）；暫存檔放在資料夾的 `state/drag-share/`，程式會自動清掉舊的。

## 做不出來時先檢查
- **拖曳分享時什麼都沒發生**：確認已按下 **拖曳分享** 按鈕，並從圖的範圍內開始拖。
- **目標程式沒有接收**：有些程式只接受檔案不接受影像，放開後若無反應，改拖到 Finder／桌面再插入。
- **放大後迷路**：右鍵或 Esc 連按幾次，或切回指標模式用 **顯示全部**。
- **觸控板捏合沒作用**：只在 macOS 有原生捏合手勢；Windows 觸控板以滾輪事件運作。
