# 繪圖設定：旋轉、運算、平滑、第三維度
> Viewer 左側面板現在可在繪圖前先處理資料：旋轉複數資料、扣平均、微分、平滑，2D 還能沿第三軸處理。只改變顯示，不會改動 HDF5 檔。

## 最短流程
1. **打開面板。** 在 Viewer 載入檔案，在 **PLOT SETTINGS** 往下捲到 **固定旋轉**（1D、2D 皆有），2D 模式還有 **第三維度**。 ![](plotcfg_2d.png)
2. **選運算。** 在 **固定旋轉** 開啟 **運算**，例如 **y-<y>**（每條 trace 扣平均）或 **d/dx**（沿 X 微分）。圖立即重畫，色條或座標軸標籤會顯示新的量（例如 "d/dx"）。 ![](plotcfg_1d.png)
3. **平滑。** 在 **平滑** 填數字（3 代表對 3 個點做移動平均，1 為關閉）。雜訊下降，尖銳特徵會變寬。
4. **僅 2D：沿另一軸處理。** 在 **第三維度** 選 **通道**（任一掃描通道，它會成為熱圖的 Y 軸），再設定它自己的 **運算** 與 **平滑**。選 **d/dx** 會得到沿 Y 的微分圖，使用藍／紅發散色階。 ![](plotcfg_third.png)
5. **還原。** 把 **運算** 設為 **None**、**平滑** 設為 1，即回到原始顯示。

## 各控制項的意義
| 控制項 | 意義 |
|---|---|
| **旋轉/x** + **計算** | 僅複數資料：先把 I/Q 平面旋轉一個角度（度），再取 Magnitude/Re/Im/Phase；**計算** 會擬合出讓訊號落在實軸的角度 |
| **固定旋轉** + **計算** | 同上，但整份資料共用一個角度，而非每條 trace 各自一個 |
| **自動旋轉** | 旋轉每條 trace，使其主要變化軸落在實軸上 |
| **以 dB 顯示** | 把 Magnitude 以 20·log10 顯示（與 Transform 的 dB 選項相同；繪製的量不是 Magnitude 時為灰色） |
| **解開相位角** | 沿 X 移除 Phase 圖的 360° 跳變 |
| **運算** | **None**；**y-<y>** 扣平均；**Normalize** 除以最大絕對值；**d/dx** 數值微分；**FFT** 沿 X 取傅立葉轉換的大小；**Histogram** y 值分布（用 **分箱數** 設定）；**Histogram-2D**（2D）圖中數值的分布，複數資料則另開視窗顯示實部對虛部（I/Q）的直方圖 |
| **平滑** | 對 N 個點做移動平均 |
| **Trace 顯示／逐條顯示** | 1D：繪出所有選取的 trace，或只畫目前這條 |
| **第三維度 › 通道** | 哪個掃描通道當 Y 軸 |
| **顯示 Trace 清單**、**忽略 x 資料** | 以點序號而非 X 值作圖 |

## 結果代表什麼
- 處理順序固定：旋轉 → 成分（Magnitude、Re、Im、Phase）→ dB／解開相位 → 運算 → 平滑 → 第三維度運算與平滑 → 公式。因此公式作用在已處理過的數值上。
- **d/dx** 是對物理單位微分（數值變化量除以 X 變化量），不是逐點差分。dB 資料的單位會顯示成 "mdB" 這類衍生單位。
- **FFT**、**Histogram** 會改變 X 軸的意義：變成 X 的頻率或數值分箱，軸標籤會跟著變。
- 標記、Compare Traces 與匯出「Displayed Data」使用處理後的數值；「Raw Data」則不受影響。

## 做不出來時
- **「旋轉需要複數（I/Q）資料；此通道是實數。」**：改選複數通道，或改用「轉換」。
- **「無法計算旋轉」**：資料為常數或全是 NaN。
- **Histogram-2D（I/Q）說需要複數資料**：原因同上；實數通道只有數值直方圖。
- **d/dx 很雜**：微分會放大雜訊，先提高 **平滑**。
- **1D 沒有第三維度**：它只存在於 2D 模式。
