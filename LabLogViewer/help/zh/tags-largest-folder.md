# 在最大資料夾依標籤搜尋
> 所有量測集中在一個超大資料夾（上萬到上百萬筆）時，一次搜尋全部，而不是只搜目前的資料庫。

## 最短流程
1. **設定最大資料夾。** **設定 → 一般 → 最大資料夾（標籤搜尋）→ 瀏覽⋯**，選那個大資料夾。 ![](largest_setting.png)
2. **開啟篩選。** 瀏覽器工具列 **依標籤篩選**，勾選標籤、選 AND／OR。
3. **選搜尋範圍。** **搜尋範圍** 選 **最大資料夾**（未設定時是灰色），按 **篩選**。 ![](largest_query.png)
4. **看結果。** 列表顯示所有符合的量測；**來源資料夾** 欄是它相對於最大資料夾的位置。點選、預覽、雙擊開啟、加星、改標籤都和一般一樣。 ![](largest_results.png)

## 結果代表什麼
- 搜尋讀的是 LabLogViewer 的**標籤紀錄**，不是逐一掃描硬碟，所以上百萬筆也很快。
- 因此**只找得到有標籤紀錄的檔案**：檔案所在的資料庫必須曾經被開啟過（並有標籤，手動或自動）。從沒開過的資料夾不會出現。
- 已經被搬走或刪除的檔案會自動略過。
- 每筆結果保留它自己所屬的資料庫，所以星號、標籤、註解與重新命名都寫到正確的位置。

## 自動標籤的範圍
開啟一個資料庫時，自動標籤（BG、Flux、De-background）只加在「往下 4 層資料夾以內」的檔案。把整個超大資料夾直接當資料庫開啟時，深層的檔案不會自動加標籤——請手動標記，或開啟它們所在的子資料夾。

## 做不出來時先檢查
- **最大資料夾選項是灰色**：還沒在設定中指定，或該資料夾已不存在。
- **找不到某個檔案**：它所在的資料庫還沒開過，或它沒有這些標籤；先開啟那個資料夾讓標籤建立。
- **結果太多**：用 AND 或加更多標籤縮小範圍。
