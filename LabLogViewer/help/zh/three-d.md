# 3D 曲面
> 把 2D 資料畫成可以旋轉的 3D 曲面、瀑布圖或點雲，並點選讀出科學數值。

## 最短流程
1. **開啟 3D。** 在 Viewer 開好一個有 Sweep 的量測（單一窗格），工具列 **分析** → **3D 曲面⋯**。3D 在獨立的程序中執行，就算 3D 卡住或當掉，Viewer 也不受影響。 ![](three_open.png)
2. **選資料。** 左上：**幾何類型** 選 **曲面**，**X**（例如 Frequency）、**Y**（例如 Average Current）、**高度（Z）**（例如 VNA - S21）、**轉換**（例如 Magnitude (dB)）。 ![](three_data.png)
3. **轉動與讀值。** 在圖上左鍵拖曳旋轉、中鍵拖曳平移、滾輪縮放；左鍵點一下讀出那一點的 X、Y、Z 科學數值。**相機** 區的 **頂視／前視／側視／等角視圖／重設視角／檢視全部** 可以快速切換。 ![](three_view.png)
4. **調整外觀。** **表面** 區：**渲染方式**、**Z 軸比例**、**投影方式**（透視／正交）、**不透明度**、**底部投影**、**參考平面**；**色彩** 區：**顏色來源**、**色彩映射**、範圍。 ![](three_style.png)

## 幾何類型代表什麼
| 類型 | 適合 |
|---|---|
| **曲面** | 連續的 2D 資料，看整體形狀 |
| **透明曲面** | 需要看到被前方擋住的部分；以深度排序畫出半透明曲面 |
| **雙曲面** | 同時比較兩個通道或兩種轉換（Surface A／B，各自設定映射與不透明度） |
| **瀑布圖** | 每條 trace 畫成一條線、沿 Y 排開；看每條 trace 的形狀演變 |
| **軌跡** | 依擷取順序連線的點；看掃描路徑 |
| **散點圖** | 每個量測點畫成一點；資料不是規則網格時使用 |

## 結果代表什麼
- **3D 只改變「畫法」，不改變資料。** 點選讀出的數值來自原始資料（經過你選的轉換）。
- **顯示取樣**：大型網格會以較少的頂點顯示（狀態列：「顯示取樣：來源 R × C → r × c 個頂點。科學資料未變更」）。細小的特徵在降取樣時可能看不清楚；需要時選 **渲染方式：完整解析度**。
- **Z 軸比例** 只拉伸顯示高度；軸上的刻度仍是真實數值。
- **參考平面**（最小值平面、零平面、自訂）幫助判斷高低；超出高度範圍時會提示。
- 非有限的 Z 值以缺口顯示，狀態列會顯示數量。

## 選項與參數
- **渲染方式**：**自動**（依網格大小選擇）、**效能優先**、**自適應 LOD**（互動時簡化、靜止時提高細節）、**完整解析度**（大網格會先警告記憶體與 GPU 用量）。
- **顏色來源**：預設與高度相同；也可以用另一個通道或轉換上色（例如高度用 Magnitude、顏色用 Phase）。
- **頂部互動色條**、**自動範圍**：與 2D 熱圖的色彩範圍相同。
- 效能上限在 **設定 → 3D → 3D 效能**（平衡、高畫質、省資源）；只影響顯示的頂點數。
- 匯出見〈3D 匯出〉。

## 做不出來時先檢查
- **「3D 曲面目前僅支援單一 Viewer Pane」**：先把 **Pane 配置** 改回 1 個窗格。
- **「請選擇不同的 X 與 Y 維度」**：X 與 Y 不能是同一個維度。
- **很慢或卡頓**：選 **效能優先** 或 **自適應 LOD**，或把 **設定 → 3D 效能** 設為省資源。
- **視窗關閉並出現「3D 程序意外結束」**：通常是顯示卡驅動問題；Viewer 不受影響，重新開啟即可。見〈3D 問題〉。
- **透明曲面看起來不透明**：部分顯示卡上 Qt 曲面的透明度會維持不透明；改用 **透明曲面** 類型。
