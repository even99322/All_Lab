# App 圖示與 Windows 捷徑
> 從七個圖示或你自己的圖片中選一個；在 Windows 上捷徑會跟著換。2.0 新增。

## 最短流程
1. **選圖示。** **設定 → 外觀 → App 圖示**：點選七個圖示之一（5 號是預設）。Dock 或工作列圖示與每個視窗的圖示會立刻改變。想用自己的圖片，按 **匯入圖片⋯** 並選擇圖檔（PNG、JPG、BMP⋯，至少 32 x 32 像素）；它會變成圖示旁邊的 **我的圖片** 按鈕，之後可以隨時再選。不是正方形的圖片會補成正方形，不會被拉伸。下方的 **3D 視窗圖示** 讓 3D 曲面視窗有自己的圖示：三個可選，或按該群組裡的 **匯入圖片⋯** 用自己的圖片（會變成同一排的 **我的圖片** 按鈕，用法與 App 圖示相同）；也可勾選 **與主軟體圖示同步** 則讓它跟著 App 圖示。 ![](settings_appearance.png)
2. **僅限 Windows。** 安裝程式建立的桌面與開始功能表捷徑會改為所選圖示（檔案總管可能要稍等或重新整理才會重畫）。若捷徑是你自己釘選的，按 **重建桌面捷徑** 取得新的。 ![](settings_appearance.png)

## 結果代表什麼
- Windows 的捷徑自己存一份圖示，所以只有 LabLogViewer 建立的捷徑能被更新；你自己的不會被更動。
- 安裝時安裝程式也會詢問要用哪個圖示（1–7）。

## 選項與參數
- 所有圖示（包含你自己的圖片）都不需要授權。
- 匯入的圖片會以 `custom_app_icon.png`（App）與 `custom_3d_icon.png`（3D 視窗）存在設定檔旁的 `state` 資料夾；原始檔案不會被更動，之後也不需要它。

## 做不出來時
- **「這個檔案不能當圖示」**：請選擇一般圖片檔，且至少 32 x 32 像素。
- **Windows 上仍是舊圖示**：在桌面按 F5 重新整理，或登出再登入；Windows 會快取圖示。
