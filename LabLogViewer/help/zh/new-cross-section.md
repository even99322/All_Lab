# 2D X/Y 截面
> 像 Labber 一樣讀 2D 圖：熱圖上兩條可拖曳的線，上方是沿 X 的切線，左側是沿 Y 的切線，左上角是強度直方圖。

## 最短流程
1. **顯示 2D 圖。** 開啟檔案，把 **Plot Mode** 設為 **2D Heatmap**（單一窗格）。
2. **開啟截面。** 按上方工具列的 **X / Y 截面** 按鈕（工具按鈕右邊、格線圖示），一次打開 X 和 Y 切線；再按一次關閉。也可以從 **檢視 → 顯示 → 顯示 X 切線／顯示 Y 切線** 只開其中一個。Viewer 自己的 2D 圖會就地改成截面版面，不會另開視窗。 ![](xsec_window.png)
3. **移動線。** 拖曳虛線的垂直（紅）或水平（藍）線。線只在你拖曳時移動，滑鼠移動時不會跟著動；拖曳時切線圖即時更新。圖上方的文字列顯示交點的 X、Y 與數值。
4. **讀切線。** 上方圖是水平線所在 Y 處的「數值對 X」。**左側**圖是垂直線所在 X 處的「數值對 Y」，它的縱軸就是熱圖的 Y 軸（範圍相同、永遠對齊），數值軸為鏡像，所以曲線往左長，右邊的色條不受影響。
5. **調對比。** 左上角的 **Intensity** 直方圖顯示各數值的像素數量，藍色區段就是上色的範圍；拖曳整個區段或任一邊緣即可精細調整對比（色條無法這麼精準），或拖曳右側色條的把手。直方圖的橫軸會自動縮放到目前的色彩範圍加上邊界，所以範圍再小也容易抓取。若範圍停在視圖邊緣，可以 **按住滑鼠中鍵拖曳**（或拖曳空白處）平移視圖，甚至超出資料範圍；滾輪縮放，**雙擊** 則把視圖重新對準色彩範圍。精確的 **Minimum** / **Maximum** 與 **Auto Range** 在左側工具欄。工具欄的 **Auto Range** 會以穩健方式依資料調整對比。熱圖與色條會立即跟著變。

## 結果代表什麼
- 切線就是目前顯示的圖（已經過旋轉、運算、平滑、公式與第三維度設定），所以 **d/dx** 圖得到的是微分切線。
- 截面跟著 Viewer 走：換通道、轉換或設定時會自動更新，並保留你的線位置。開關截面不會改變資料，也不會改變已儲存的色彩範圍。
- 這裡設的色彩範圍與 Viewer 使用（並儲存）的是同一個；色條把手與 Max/Min 欄位永遠一致。
- 會使用 Viewer 目前的深色或淺色主題。

## 多個窗格
窗格超過一個時，每個窗格都太小放不下這種版面，所以 **顯示 2D X/Y 截面** 會改開獨立視窗（圖相同、跟隨作用中的窗格、有 **Always on top** 選項）。

## 做不出來時
- **狀態列提示先開啟 2D 圖**：Viewer 在 1D 模式，或沒有載入 2D 資料。
- **線跳回中央**：載入了新檔案或不同的圖，十字線從中心重新開始。
- **直方圖縮放得太大或太小**：在直方圖上雙擊，重新對準色彩範圍。
- **整張都同一個顏色**：把直方圖的藍色區段拉到涵蓋全部資料範圍，或資料本身變化很小。
- 舊的 **顯示 X 切線** / **顯示 Y 切線** 視窗仍然可用。
