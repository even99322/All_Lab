# 主題擴散、按鈕回彈、玻璃捲軸
> 介面的三種動態效果：它們做什麼、為什麼不影響操作。

## 最短流程
1. **主題擴散。** 在瀏覽器工具列按主題按鈕（或 **設定 → 外觀 → 主題**）。新主題會以你按下的按鈕為中心，像一個圓向外擴散，直到蓋滿最遠的角落；其他開著的視窗從中央擴散。 ![](motion_ripple.png)
2. **兩色對抗。** 若外觀其實沒變（例如系統本來就是深色、又選了深色），圓的邊緣會出現兩種顏色互相推擠，邊界被推回兩次，最後主題色獲勝。
3. **按鈕回彈。** 按住任何按鈕時它會縮到 96%，並沿著按鈕本身的形狀加上陰影（淺色介面變暗、深色介面變亮）；玻璃工具列上的圖示按鈕會出現柔和的圓形膠囊。放開時帶一點彈性回到原大小，並直接顯示按下後的新狀態。
4. **玻璃捲軸。** 所有上下與左右捲軸浮在內容之上，滑塊是會折射底下內容的液態玻璃；滑鼠移到捲軸上時滑塊變寬、比較好抓。 ![](motion_scroll.png)

## 結果代表什麼
- 主題在擴散開始前就已經套用完成；擴散只是一層蓋在上面、不接收滑鼠與鍵盤的舊畫面，所以動畫期間所有功能照常可用。
- 按鈕回彈也是畫在按鈕上方的一層，點擊、快捷鍵都照常觸發。
- 玻璃的外觀使用 **設定 → 外觀 → 工具列玻璃** 的 **厚度** 與 **霜化**。
- 捲軸浮在內容上，所以表格最右側或最下方約 12 px 會在捲軸底下（和 macOS 原生捲軸相同）。

## 做不出來時先檢查
- **電腦較慢時動畫卡頓**：動畫本身不影響功能；如需關閉，可設定環境變數 `LABLOGVIEWER_DISABLE_EFFECTS=1`（主題擴散、按鈕回彈）或 `LABLOGVIEWER_DISABLE_GLASS=1`（玻璃改為一般霧面）。
- **捲軸擋住最後一欄**：把表格稍微往左捲，或拉寬視窗。
