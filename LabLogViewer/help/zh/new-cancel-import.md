# 可中斷的資料庫開啟
> 立刻停止太久的資料夾掃描；已讀完的部分會保留。2.0 新增。

## 最短流程
1. **開始掃描。** 照常在瀏覽器開啟資料夾（見〈開啟與瀏覽資料庫〉）。 ![](db_open.png)
2. **取消。** 在掃描對話框按 **取消**，或在補充中繼資料時按狀態列的 **停止**。 ![](db_scan.png)

## 結果代表什麼
- 已讀完的檔案照常列出；其餘可之後重新掃描。磁碟上的東西都沒有被更動。

## 選項與參數
- **設定 → 外觀 → 進階 → CPU 執行緒數**：掃描最多可用幾條執行緒（預設為邏輯 CPU 的 75%）。

## 做不出來時
- **事後某個檔案是紅色**：只有那個檔案讀不到（例如網路硬碟的輸入／輸出錯誤）；其餘繼續掃描。稍後再掃一次。
