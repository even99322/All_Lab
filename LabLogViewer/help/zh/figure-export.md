# PowerPoint 與圖片輸出
> 輸出的 PowerPoint 中每個元件都是獨立、可編輯的圖形，並使用 PowerPoint 自己的立體效果；也可以輸出 PNG、SVG、PDF。

## 最短流程
1. **輸出 PowerPoint。** 示意圖建構器 → **輸出 PowerPoint⋯**，選檔名。 ![](figexp_pptx.png)
2. **在 PowerPoint 裡編輯。** 每一層、每顆 YIG、每個線圈都是一個群組；雙擊群組可以選到裡面的單一圖形，改顏色、移動或調整 **設定圖形格式 → 效果 → 立體格式／立體旋轉**。
3. **輸出圖片。** **輸出圖片⋯** 選 PNG（寬 3000 px）、SVG 或 PDF（向量）。 ![](figexp_image.png)

## 結果代表什麼
- **板材各層**：平面的自由圖形（螺絲孔、過孔已挖空），套上 PowerPoint 的 **立體格式**（深度 = 層厚、材質、光源）與 **立體旋轉**（你選的視角）。所有層使用同一個傾斜角，位置依同一套投影計算，所以組起來是一個完整的立體裝置。
- **YIG**：圓形加上下圓形斜角，成為真正的立體球；自旋箭頭是另外的白色圖形。
- **線圈**：每一圈是一個加了圓形斜角的甜甜圈（立體圓管環），加上磁場箭頭。
- **正弦波**：一般的虛線自由線條，可以任意方向拉伸。
- 投影片中沒有任何點陣圖片。

## 做不出來時先檢查
- **光影和編輯器看起來不一樣**：PowerPoint 使用自己的光源與材質計算，屬正常；可在立體格式中調整。
- **拖動某一層後整體錯位**：各層依相同的投影對齊，移動請選取整個群組或全部一起移動。
- **某些舊版或非 Microsoft 的簡報軟體沒有立體效果**：立體格式是 PowerPoint 的功能；其他軟體可能只顯示平面圖形。
