# 通知（鈴鐺與寵物氣泡）
> 瀏覽器視窗的鈴鐺會收集更新、量測完成、連續登入與寵物升級的通知。2.0 新增。

## 最短流程
1. **看鈴鐺。** 在瀏覽器視窗工具列的右上方，有未讀通知時鈴鐺會出現紅色數字；滑鼠停在上面可看到數量。 ![](notice_bell.png)
2. **打開清單。** 按下鈴鐺：最新的通知在最上面。更新通知會列出前三項變更，按 **⋯ 更多** 會開啟完整的更新預覽。上方可按 **全部標為已讀** 或 **清除**。 ![](notice_list.png)
3. **閱讀更新。** 預覽會把變更分成「新功能」「改進」「修正」。**略過此版本** 會隱藏這個版本且不再提醒；**關閉** 則保留清單中的通知。 ![](notice_update.png)
4. **在寵物上看到。** 桌面寵物顯示時，新通知也會以半透明氣泡出現在寵物頭上約 6 秒；多則通知會排隊，點氣泡即可開啟清單。 ![](notice_pet.png)
5. **選擇要收到什麼。** 在清單按齒輪按鈕：**全部靜音**，或關閉某一類（更新、量測、連續登入、升級）。

## 結果代表什麼
- **更新**：公告了較新的版本。啟動後約 2.5 秒，程式會在背景讀一次專案的 GitHub 更新檔（只讀 `latest.json`，約 6 秒逾時，離線時靜默略過）；也可改讀這台電腦上的資料夾。除這個 GitHub 位址外，程式不會連到任何網址，網路磁碟路徑一律拒絕。通知本身不會安裝或重新啟動任何東西；有通知時，桌面寵物也會以氣泡告知。
- **量測完成**：量測程式回報一次量測結束。
- **連續登入**：你連續 3、7、14、30、60、100、200、365⋯ 天開啟 LabLogViewer（需要已領養寵物）。
- **升級**：桌面寵物升到新的等級。

## 選項與參數
- 清單保留最近 50 則通知，關閉程式後仍會記得。
- 通知以你閱讀時使用的語言顯示。
- 螢幕上沒有寵物時，通知只會進鈴鐺。

## 做不出來時
- **鈴鐺沒有數字**：可能全部已讀，或在齒輪選單中選了 **全部靜音** 或關閉了該類通知。
- **沒有更新通知**：離線或讀不到 GitHub 更新檔、版本不是較新的，或你選了 **略過此版本**。
- **沒有連續登入通知**：連續天數由桌面寵物計算，請先在 設定 → 寵物 領養一隻。
