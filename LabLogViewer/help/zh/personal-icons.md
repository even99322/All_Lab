# 自訂圖示（SVG）
> 用自己的 SVG 檔替換任何工具列圖示；不受解鎖限制。

## 最短流程
1. **開啟。** **設定 → 個人化 → 圖示**。清單列出所有可替換的圖示。 ![](personal_icons.png)
2. **選圖示。** 點一個（例如 `zoom`）。
3. **替換。** 按 **以 SVG 替換...**，選你的 `.svg`。勾 **跟隨主題換色** 時，圖示會隨淺色／深色主題自動變色。
4. **恢復。** **恢復預設** 或 **恢復全部圖示**。

## 限制（安全）
- 只接受純 SVG，最大 256 KB；不能有程式碼（script）、外部連結、內嵌圖片或影片、事件屬性。
- 你的檔案會另存一份到資料夾的 `state/personal_icons/`，原始圖示保留。

## 做不出來時先檢查
- **「這個 SVG 無法使用」**：訊息會說明原因，例如含有 `<script>`、`<image>` 或外部連結；用繪圖軟體輸出「純 SVG」再試。
- **圖示是黑的看不到**：勾 **跟隨主題換色**，或檔案本身用了固定的深色。
