# 科學示意圖建構器
> 把 AutoCAD 電路圖（DXF）變成 3D 裝置示意圖：板材、介電層、銅走線、貫穿的螺絲孔與過孔，再加上 YIG 球、線圈和正弦波。

## 最短流程
1. **開啟。** 資料庫瀏覽器 → **處理** → **科學示意圖建構器⋯**。它在獨立程序執行，卡住或關閉不影響其他視窗。 ![](fig_open.png)
2. **載入 DXF。** 按 **開啟 DXF⋯**，選以「AutoCAD 2013 DXF」儲存的檔案。程式自動辨識圖層並畫出 3D 板子；有問題時警告顯示在 **圖層** 分頁下方。 ![](fig_loaded.png)
3. **加入 YIG 與線圈。** 按 **加入 YIG**、**加入線圈**，用滑鼠拖到想要的位置（YIG 停在下方的表面上，線圈固定在板子下方）。 ![](fig_objects.png)
4. **加入正弦波。** 按 **加入正弦波**，會在板子長邊方向、板面正上方畫出一條 3D 波。拖曳波形線條可在板面上移動；拖曳兩端的方形控制點可在 3D 中指定 **起點** 與 **終點**；拖曳任一波峰上的圓點上下移動，可改變該波峰的高度。 ![](fig_wave.png)
5. **調視角並輸出。** 拖曳空白處轉視角（或 **視角** 分頁的 **俯仰角**、**旋轉**），再按 **輸出 PowerPoint⋯** 或 **輸出圖片⋯**（見〈PowerPoint 與圖片輸出〉）。 ![](fig_view.png)

## DXF 的規則
- 以 **AutoCAD 2013 DXF** 儲存（其他版本會警告，結果可能不同）。
- **微帶線（MS）**：`b` 板材（產生底層地平面與介電層）、`g` 微波線（頂層走線）、`h` 螺絲孔（貫穿所有層）。
- **共面波導（CPW）**：`db` 下板材（底層地平面與介電層）、`ub` 上板材（頂層地平面）、`g` 微波線、`h` 螺絲孔、`v` 金屬化過孔（紫色銅，貫穿上下地平面）。
- 有 `db`、`ub` 或 `v` 任一圖層就判定為 CPW，否則 MS。圖層名稱不分大小寫；其他圖層會被忽略。
- 外框可以由散線組成：端點距離小於容差（約 0.002 mm 或圖面大小的 2×10⁻⁵）會自動接上；框中有框時，以奇偶規則決定實心或挖空（所以環狀走線會保持環狀）。

## 結果代表什麼
- 預設厚度：銅 **0.032 mm**、介電層 **0.813 mm**，可在 **圖層** 分頁逐層修改；比例是真實比例。
- **位置**：「疊在下層上」往上堆疊、「與下層同高」（例如 CPW 的走線與上地平面同一層）、「貫穿全部」（過孔）。**上移／下移** 改變堆疊順序。
- 螺絲孔從每一層挖掉；過孔從其他層挖掉並以紫色顯示。
- 視角是正交投影：與 PowerPoint 輸出使用同一套計算，所以兩邊位置一致。

## 選項與參數
- **選取項目** 分頁：
  - 選取 YIG 或線圈後，可拖曳它的 8 個控制點（4 邊加 4 角）：物件會等比例縮放（球仍是球、線圈保持形狀），且與所拖控制點相對的一側保持不動。
  - YIG：半徑、離表面高度、自旋箭頭數、球體顏色、自旋顏色。
  - 線圈：半徑、線徑、圈數、圈距、與板底距離、顏色、磁場箭頭與顏色。
  - 正弦波：週期數、相位、**波峰形狀**、線寬（pt）、虛線、顏色。3D 波另有 **高度（mm）**（垂直於起終點連線、在鉛直面內的擺幅）與以板子座標表示的 **起點／終點 X、Y、Z（mm）**（z = 0 是最底層的底面；新加入的波位於堆疊頂面）。
  - **波峰形狀**：*等高*（預設）、*指數衰減*、*高斯*、*駐波*，或 *自訂（拖曳）*（拖曳波峰圓點後出現，其他波峰維持原高度）。改變週期數或相位會重新排列波峰；自訂形狀會被拉伸到新的波峰數。
  - 所有數字欄位在輸入或滾動時就即時更新圖面；一次連續的調整只算一步復原。
- **圖層** 分頁：顯示、顏色、厚度、位置、上移／下移。
- **視角** 分頁：俯仰角（90° 為正上方）、旋轉、背景顏色。
- **復原／重做**（⌘/Ctrl+Z、⌘/Ctrl+Shift+Z，最多 60 步）；Delete 鍵刪除選取的物件。
- **儲存示意圖⋯** 存成 `.llvfig`（含幾何、物件與視角），之後用 **開啟示意圖⋯** 繼續編輯。

## 做不出來時先檢查
- **「找不到已知的圖層」**：圖層名稱不是 b／g／h 或 db／ub／g／h／v。
- **某層顯示「沒有找到封閉外框」**：線沒有接起來（缺口大於容差），回 AutoCAD 把端點接好。
- **線圈看不到**：它在板子下方，被板子擋住了；拖到板子前緣附近，或降低俯仰角。
- **文字標籤**：示意圖不含文字；請在 PowerPoint 或繪圖軟體加上。
- **視窗關閉並出現「示意圖建構器意外關閉」**：其他視窗不受影響，從 **處理** 再次開啟。
