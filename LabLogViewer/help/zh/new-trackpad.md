# Mac 觸控板手勢
> 在圖上用滑鼠能做的操作，在 MacBook 觸控板上也都能做。

## 最短流程
1. **平移。** 在 1D 或 2D 圖上用兩指滑動：圖會跟著手指移動。 ![](shortcuts.png)
2. **縮放。** 兩指捏合或張開：以手指下方的點為中心縮放。
3. **看全部。** 兩指輕點兩下（智慧縮放）：圖自動範圍，顯示全部資料。
4. **右鍵選單。** 兩指按壓（觸控板的次要點按）：開啟與滑鼠右鍵相同的選單（複製、複製所有窗格…）。
5. **繪圖。** 開啟註解或畫筆時，單指按住拖曳即可繪圖。
6. **3D。** 單指拖曳旋轉、兩指滑動也旋轉（按住 Shift 為平移）、捏合縮放、兩指扭轉為滾轉、兩指輕點兩下重設視角。

## 手勢表
| 手勢 | 1D / 2D 圖 | 3D 視圖 |
|---|---|---|
| 兩指滑動 | 平移 | 旋轉（按 Shift：平移） |
| 捏合 | 縮放 | 縮放 |
| 兩指輕點兩下 | 自動範圍 | 重設視角 |
| 兩指扭轉 | 不使用 | 旋轉 |
| 兩指按壓 | 右鍵選單 | 右鍵選單 |
| 單指拖曳 | 依目前工具為指標／註解 | 旋轉 |

## 須知
- 重按（Force Click）與三指手勢屬於 macOS 系統層級，Qt 不會傳給程式，因此不使用。
- 滑鼠操作完全不變。
- 手勢只在觸控板（或 Magic Mouse）上有效；一般滾輪仍然是縮放。

## 做不出來時
- **沒有反應**：到「系統設定 → 觸控板」確認已開啟「縮放」與「智慧縮放」。
- **平移方向相反**：它遵循 macOS 的「自然捲動」。
- **捏合時整頁跟著捲動**：先點一下圖，讓它取得焦點。
