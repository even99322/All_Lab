# 網路硬碟的「檔案暫時忙碌」
> 這個訊息的意思、為什麼檔案沒有損壞，以及該怎麼做。2.0 新增。

## 最短流程
1. **讀訊息。** 開啟網路硬碟（NAS）上的檔案時可能回報 *unable to lock file, errno = 35*。LabLogViewer 現在以不加檔案鎖的方式讀檔並重試數次；硬碟仍沒有回應就顯示 **檔案暫時忙碌**。 ![](new_busy_dialog.png)
2. **稍等再開。** 等幾秒再開一次。如果一直發生，把檔案複製到這台電腦再開複本。 ![](trouble_general.png)

## 結果代表什麼
- 檔案沒有損壞，也沒有被更動；只是硬碟忙碌。
- 真正損壞的檔案會顯示不同訊息（*Not a readable HDF5 file*）。

## 選項與參數
- 異常結束後，**復原報告** 會顯示真正的崩潰堆疊，或說明程式是從外部結束（強制結束、記憶體不足、睡眠、斷電）。標題為 **未預期的錯誤** 的訊息有 **顯示詳細資料⋯**，內含完整 traceback。

## 做不出來時
- **同一個檔案每次都出現**：硬碟可能已中斷連線；到檔案管理員確認。
