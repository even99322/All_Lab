# 比較 Trace 與檔案
> 把最多六條 1D trace 疊合、堆疊、相減或相除：同一檔案的 I、Q、相位與振幅，或 A 檔案的第 3 條對 B 檔案的第 10 條。

## 最短流程
1. **開啟視窗。** 選單 **Analysis → Compare Traces⋯**（**分析 → 比較 Trace⋯**；Viewer 有沒有開檔都能用，已開啟的檔案會自動列入）。按 **開啟檔案⋯** 可加入更多 HDF5 檔案；它們只會被讀取，不會被更動。 ![](compare_open.png)
2. **描述每一條 trace。** 每個 **Trace** 方塊有：**檔案**、**通道**、**量**（複數通道可選 real、imag、magnitude、magnitude_db、phase_deg、phase_rad）、**X 軸**（哪一個維度當橫軸），以及其餘每個掃描維度的 **… 索引** 框，用來選位置（例如 *Current 索引 12* 就是第 13 個電流值，從 0 開始算）。用 **新增 Trace**／**移除最後一條 Trace** 增減，最多六條。 ![](compare_traces.png)
3. **看疊合圖。** **檢視 = 疊合**、**X 軸處理 = 原始 X 值** 時，每條 trace 畫在自己量測的 X 上。圖例會寫出檔案、通道、量與位置。若出現兩種 Y 單位（例如 dB 與 deg），第二種會畫在右側座標軸；超過兩種單位會被拒絕並顯示訊息。 ![](compare_overlay.png)
4. **只比形狀，或看差值。** 選 **檢視 = 差值（第一條 − 第二條）** 或 **比值（第一條 ÷ 第二條）**（使用第 1、2 條 trace），再設定 **X 軸處理** 與 **Y 軸處理**（見下方）。 ![](compare_options.png)
5. **檢查結果。** 一條 trace 與自己的差值是 0 的水平線；虛線標出 0。選項下方的說明會列出你該知道的事（單位不同、X 範圍不同、已忽略 X）。 ![](compare_difference.png)

## 結果代表什麼
- **疊合／堆疊** 顯示的是量測資料，沒有任何更動。**堆疊（各自 X 軸）** 讓每條 trace 有自己的圖與 X 軸；**堆疊檢視時連動 X 軸** 會讓一張圖縮放 X 時其他圖一起動（X 不同但想一起瀏覽時很有用）。
- **差值** 與 **比值** 是先用線性內插把兩條 trace 放到同一個 X 格點後才計算，所以品質取決於內插：兩條 trace 的量測格點差很多時，細小的特徵不要相信。第二條為 0 的地方比值留空。
- **忽略 X 值（只比較形狀）** 會把兩條都拉伸到位置 0 … 1；此時 X 軸代表 *相對位置*，不是頻率或電流。用來看兩次掃描範圍不同但形狀是否相同；它不能告訴你特徵在真實單位上的位置。
- **縮放到 0 … 1**、**平均為零、單位分散**、**除以最大 |Y|** 會去掉絕對大小，讓不同的量（或不同增益）可以比較形狀。此時差值與比值是縮放後 trace 的結果，沒有物理單位。

## 選項與參數
- **X 軸處理**：*原始 X 值*（每條在自己的 X，僅疊合與堆疊）、*共同 X 範圍*（全部內插到第一條 trace 在所有 trace 都涵蓋的範圍內的 X 點）、*忽略 X 值（只比較形狀）*、*固定間距*（在共同範圍內以你輸入的 **間距**（X 的單位）建立規則格點；間距大於範圍或會產生超過 200 萬點時會被拒絕）。
- **Y 軸處理**：維持量測值，或上述三種縮放之一。
- X 或 Y **單位** 不同的 trace 仍會畫出，但會有說明提醒你，因為把 dB 減去角度沒有物理意義。
- 這個視窗是獨立的：關閉時會釋放它自己開啟的檔案；它不會寫入任何檔案。

## 做不出來時
- **「兩條 Trace 沒有共同的 X 範圍」**：兩次掃描沒有重疊；疊合時改用 **忽略 X 值** 或 **原始 X 值**。
- **「請為每一條 Trace 選擇檔案與通道」**：先按 **開啟檔案⋯**，再在每個方塊選通道。
- **Y 軸寫著「縮放後的 Y」**：有開啟 Y 軸處理；改回 *Y 維持量測值* 才是真實單位。
- **「Y 單位超過兩種」**：在 **Y 軸處理** 選一種縮放，或減少比較的量。
- **平線或空白圖**：你選的索引可能落在沒有量測的部分（檔案提早中止）；換一個索引試試。
