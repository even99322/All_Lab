# 桌面寵物
> 陪在 LabLogViewer 旁邊的小夥伴。可以不用；不會鎖住任何科學功能；關掉程式時會一起離開。

## 最短流程
1. **開啟。** **設定 → 寵物**。 ![](settings_pet.png)
2. **領養。** 在 **寵物** 區按橘貓、柴犬或水豚的 **領養這隻寵物**，確認後寵物會出現在主螢幕右下角。
3. **互動。** 可以拖到任何地方、甚至別的螢幕；點牠會有反應，並把 LabLogViewer 帶到最前面（對睡著的寵物點一下只會叫醒牠；拖曳不會跳轉）。**滑鼠移到牠身上**，下方會出現深色工具列，有 **面板** 按鈕（▦）和你的快捷動作。在牠身上按右鍵有 **睡覺／叫醒**、**寵物設定⋯**、**隱藏寵物**。 ![](pet_panel.png)
4. **隱藏或顯示。** 取消或勾選 **顯示寵物**（或在寵物上按右鍵 → **隱藏寵物**）。**讓寵物一直顯示在所有程式上方**（預設勾選）會讓寵物浮在其他所有程式上方；就算你點了別的程式、或桌面上沒有任何視窗，牠都還在。取消勾選後，一般視窗可以蓋住寵物。全螢幕播放影片或簡報的程式不會被寵物蓋住。

## 面板、快捷動作與等級
- **面板**（工具列的 ▦）：顯示寵物等級與你的 **快捷動作**。**經驗條** 在 **設定 → 寵物**，不會出現在寵物旁邊。
- **快捷動作** 是開啟現有視窗的捷徑：YIG 分析、匯出資料、3D 曲面、Node / Antinode、比較 Trace、公式、De-background、顯示瀏覽器。點格子直接執行；用旁邊的箭頭更換或清空。Viewer 類動作會在你最後使用的 Viewer 上執行；沒有開啟量測檔時寵物會提醒你。
- 格數依等級：Lv.1 = 2、Lv.10 = 3、Lv.20 = 4、Lv.30 = 5、Lv.40 = 6、Lv.50 = 8。前四個也會出現在工具列。
- **經驗值來自正常做研究。** 基準：開啟量測檔做基本數據分析（10）。每天開啟程式更少（3）。**operator 類的專業分析**——在某個檔案上的第一次實際操作，例如轉換、公式、標記、局部放大——是 1.5 倍（15）。**外接分析** 例如完成 YIG 擬合，以及產生 De-background 結果，是 2.0 倍（20）。匯出資料和基本分析相同（10，同一檔案每天一次）。
- **連續天數加成**：每連續開啟 LabLogViewer 10 天，所有經驗值加成 +2%（10 天 +2%、20 天 +4%⋯）。中斷一天就重新計算。設定 → 寵物會顯示目前的連續天數與加成。
- 同一個事件不會重複給分（重開同一個檔、同一天重複匯出同一檔、同一天重做同一個擬合）；點寵物、拖寵物不給經驗；結果不理想照樣算。
- 每天約 20 筆量測，大約 **半年升到 Lv.50**（雛形；正式數字會配合量測軟體再調整）。每次升級都會播放慶祝動畫；Lv.10／20／30／40／50 會換造型。
- **科學功能永遠不會因為等級被鎖住。**

## 背包、最近、通知、Dock 與儀表板
面板有五個分頁；尚未解鎖的分頁顯示 🔒 與解鎖等級。
- **背包**（Lv.1：5 件⋯Lv.50：50 件）：**加入目前的量測**；**Lv.10** 起可以把檔案、圖片或文字拖到寵物身上。量測檔只記**參照**（不會複製）；圖片和文字存在 `state/pet_backpack/`。**開啟**、**複製**、**全部複製**、**匯出選取⋯**（不會覆蓋，同名檔會加上「(2)」）、**移除**、**清空**（不會刪除量測檔）。
- **最近**（Lv.20）：最近處理過的量測、擬合、匯出與 De-background；點兩下開啟；**釘選／取消釘選** 讓項目固定在最上面。
- **通知**（Lv.30）：擬合完成、匯出、De-background、升級與錯誤的紀錄；**全部標為已讀**、**清除紀錄**。必要警告在任何等級仍會直接出現在寵物身上。
- **Dock**（Lv.40）：快捷分頁一眼看到背包、未讀通知與最近項目；格子的箭頭選單可以把動作往左或往右移。
- **儀表板**（Lv.50）：今天／本月／累計的量測、operator 分析、外接分析、De-background、匯出次數、研究天數與累計經驗；可以儲存與載入快捷動作的**工作組合**（例如「早上量測」）。

## 外觀與成長劑
- **外觀**（設定 → 寵物）：升級後可以換回任何已經解鎖的造型（Lv.1、10、20⋯）。選較低造型時不會顯示更高等級才有的動作。
- 寵物下方的工具列不會比寵物寬：放不下的快捷動作留在面板裡。
- **成長劑** 由開發者以這台電腦的授權檔提供（設定 → 關於 → 授權⋯）。可以增加經驗值、直接設定等級（最高 Lv.50），或給一次**重新選擇**機會（在 Lv.50 前領養另一隻一般寵物）。每瓶只能用**一次**，重新安裝也不會再生效。

## 領養規則
- 一次只能領養**一隻**寵物。目前的寵物升到 **Lv.50** 後，才能領養**新的**寵物。
- 以前領養過的寵物隨時可以換回來，等級會保留。
- 寵物升到 Lv.50 之前，其他一般寵物會顯示 **請先把目前的寵物養到 Lv.50**。

## 寵物會做什麼
- 待機、眨眼、偶爾看向滑鼠游標（睡覺時不會），大約 3 分鐘沒動滑鼠會打盹，移動滑鼠會醒來。
- 必要警告在任何等級、即使在睡覺也會通知：發生未預期的錯誤時，寵物會跳起來並出現紅色 **!**。
- 點別的程式時寵物留在原處；點寵物會把你最後使用的 Viewer（或瀏覽器）帶到最前面，即使從別的程式切過來或 LabLogViewer 已最小化。
- 寵物是 LabLogViewer 自己的小視窗：關掉 LabLogViewer 寵物也會關閉。牠不會讀取或修改量測檔；選擇存在資料夾的 `state/pet.json`。

## 做不出來時先檢查
- **用別的程式時寵物不見了**：**設定 → 寵物 → 讓寵物一直顯示在所有程式上方** 沒有勾選，或別的程式正在全螢幕（寵物會留在它後面）。
- **沒看到寵物**：沒有勾選 **顯示寵物**，或還沒領養寵物。
- **「領養這隻寵物」是灰的**：原因寫在寵物下方（通常是「請先把目前的寵物養到 Lv.50」）。
