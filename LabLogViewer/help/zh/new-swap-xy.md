# 2D 熱圖的 X／Y 對調
> 一個按鈕把熱圖轉 90 度：原本的 X 軸變成 Y，反之亦然。2.0 新增。

## 最短流程
1. **切到 2D。** 把 **Plot Mode（繪圖模式）** 設為 **2D Heatmap**，在 **PLOT SETTINGS** 選 Z、X、Y；**Swap X / Y** 在 Y 下方。 ![](new_swap_button.png)
2. **按 Swap X / Y。** X 與 Y 的通道互換，圖以轉置方式重畫；顏色（Z）不變。 ![](new_swap_result.png)

## 結果代表什麼
- 沒有重新計算：同樣的資料只是座標軸互換。再按一次就回到原來。
- 位在某個 X 或 Y 位置的標記與座標軸綁定，對調後請再檢查。

## 選項與參數
- 轉換、色盤與色彩範圍都保留。只有 2D 模式有這個按鈕。

## 做不出來時
- **按鈕是灰色**：目前沒有 2D 圖（1D 模式或尚未開檔）。
