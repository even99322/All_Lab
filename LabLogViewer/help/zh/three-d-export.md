# 3D 匯出
> 把 3D 圖複製、存成論文樣式的 PNG／PDF／SVG，或擷取螢幕上的互動畫面。

## 最短流程
1. **選匯出樣式。** **設定 → 3D → 3D 匯出樣式**：**論文樣式** 或 **螢幕畫面**。3D 視窗工具列右側會顯示目前的樣式（「匯出：論文樣式」）。 ![](three_export_style.png)
2. **調好視角。** 在 3D 視窗轉到想要的角度、設定顏色與範圍——匯出會使用目前的視角與設定。
3. **複製或儲存。** 3D 視窗工具列 **複製 3D 圖**（直接貼上）或 **儲存 3D 圖⋯**。論文樣式可存 PNG、PDF、SVG；螢幕畫面可存 PNG、SVG。 ![](three_export_save.png)
4. **拖曳分享。** 工具列也有 **拖曳分享**，把圖拖到其他 App。

## 兩種樣式的差別
| | 論文樣式 | 螢幕畫面 |
|---|---|---|
| 產生方式 | 依目前視角重新繪製一張期刊風格的圖（白底、細格線、標準字體） | 直接擷取視窗中看到的畫面 |
| 格式 | PNG（高解析）、PDF、SVG | PNG、SVG |
| 解析度 | 與視窗大小無關 | 等於視窗大小 |
| 透明度 | 真正的半透明混色 | 依顯示卡而定 |
| 資料點 | 最多約 20,000 個頂點（大網格會取樣） | 與畫面相同 |

## 結果代表什麼
- 兩種樣式畫的都是同一份資料；論文樣式為了檔案大小與清晰度會降取樣，細節極小的特徵請確認在圖上看得到。
- 論文樣式的 PDF／SVG 中，大量資料點以點陣方式嵌入（避免檔案過大），座標軸與文字仍是向量。

## 做不出來時先檢查
- **「沒有可匯出的 3D 場景」**：3D 還在準備中或沒有資料，等畫面出現再匯出。
- **存檔失敗**：確認目的地資料夾可寫入；檔名副檔名依選擇的格式自動補上。
- **論文樣式和畫面看起來不同**：論文樣式使用自己的配色與字體；需要一模一樣時改用螢幕畫面。
