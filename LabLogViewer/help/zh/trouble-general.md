# 一般問題
> 程式卡住、意外關閉、看到不懂的訊息時，先做什麼、怎麼求助。

## 最短流程
1. **等 8 秒以上的卡住。** 任何視窗超過 8 秒沒有回應，程式會自動把當時在做什麼寫成一份報告，存在資料夾的 `logs/unresponsive-…-時間.txt`；恢復後狀態列會告訴你報告位置。程式不會因此被關閉或改變任何東西。 ![](trouble_general.png)
2. **意外關閉後重新啟動。** 下次啟動會提供 **安全復原模式**：還原資料庫與瀏覽器，但先略過上次開著的 Viewer 與處理作業，避免再次觸發同一個問題。
3. **看真正的原因。** 異常結束後，**復原報告** 現在會顯示當時崩潰的 Python 或原生堆疊（存在工作階段檔旁的 `native_crash.txt`）。若報告說「最可能是從外部結束」，代表程式被強制結束、記憶體不足，或電腦睡眠／斷電：不是 LabLogViewer 內部崩潰。標題為 **未預期的錯誤** 的訊息有 **顯示詳細資料⋯** 按鈕，內含完整 traceback；求助時請一併複製。
4. **求助。** **說明 → 匯出給 AI⋯** 產生一份包含全部說明的文字（可勾選附上目前的視窗狀態，不含資料與個人路徑），連同你的問題交給 AI 助手；或把 `logs/` 裡的報告與 **設定 → 偵錯 → 複製偵錯資訊** 的內容寄給開發者。

## 常見狀況
| 狀況 | 先檢查 |
|---|---|
| 開大型檔案很慢 | 第一次讀取需要時間；2D 大檔可先用 1D 看單條 trace |
| 某筆資料開不了 | 瀏覽器中是否為灰色列（非 Labber 格式或檔案損毀） |
| 啟動時說「已從損壞中復原」 | 某個紀錄檔損壞，已備份並以空白狀態繼續；備份在同一資料夾 |
| 資料夾裡留著 `.hdf5.lock` 檔 | 程式在寫入時被關閉；約 2 分鐘後視為被遺棄，下次寫入會自動清除，確定沒人在寫時也可手動刪除 |
| 狀態列顯示有變更等待寫入資料檔 | 檔案正被使用（其他電腦、Labber、磁碟離線）；標籤與星號先留在這台電腦，約每 60 秒與重開程式後會再試 |
| 紀錄（星號、標記）不見 | **設定 → 一般 → 資料夾位置** 是否指向原本的資料夾 |
| **檔案暫時忙碌**（例如 *unable to lock file, errno = 35*） | 網路硬碟（NAS）沒有即時回應，檔案沒有損壞。LabLogViewer 以唯讀、不加檔案鎖的方式開檔並自動重試數次；稍等再開一次即可 |
| 掃描資料夾後某個檔案是紅色 | 只有那個檔案讀不到（硬碟輸入／輸出錯誤）；資料夾其他檔案都已掃描；稍後重新掃描 |
| 3D 或示意圖建構器關閉 | 它們在獨立程序；其他視窗不受影響，重新開啟即可 |

## 做不出來時先檢查
- **報告檔很多**：可以刪除舊的，不影響任何紀錄。
- **安全復原模式每次都出現**：上次沒有正常結束；確認是否從工作管理員強制結束程式。
