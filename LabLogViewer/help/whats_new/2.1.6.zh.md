### 大量數據、VPN、快捷鍵與 Phase delay
- **VPN / NAS 上的數據變快**：網路磁碟上的檔案會先完整複製到這台電腦一次（大量連續讀取，比逐筆讀快很多），預覽、Viewer、切換 trace、調整繪圖都讀本機副本。副本只在跟原檔完全一樣時使用；量測中還在寫入的檔案不會被複製。開啟較大的檔案時會顯示複製進度（可取消）。「設定 → 一般」可以看副本占用的空間並清除。
- **切換數據時預覽跟得上**：選了別的數據，還在讀的上一筆會停止，不再搶頻寬。
- **開啟到獨立視窗不再空白**：先把數據準備好再開 Viewer。
- **大資料夾**：超過 100 筆時先顯示前 100 筆，往下捲動再載入更多；開啟網路上的資料夾時不再逐一打開每個檔案。日期、掃描維度等資訊在背景讀取，**目前看的資料夾優先**，讀到就直接填進列表（不會整個重排）；預覽或開啟數據時背景讀取會暫停讓路。
- **切換 trace 更順**：從第二條 trace 起整個通道只讀一次，之後在記憶體裡切換。
- **開啟資料庫的預設位置**：量測電腦直接開桌面的「數據集散地」；其他電腦開 NAS 的數據集散地。
- **專案資料夾**：Folder 上方可以選專案，切換後自動顯示該專案的資料夾。
- **拖曳開啟**：把數據檔（.hdf5、.h5、.nc）或資料夾從檔案總管 / Finder 拖到任何 LabLogViewer 視窗就會開啟。
- **快捷鍵**（Viewer）：Esc 回到全域圖、M 開關 Point Mark、1 / 2 切換 Plot Mode、F 最大化繪圖、P 顯示資料點、A 自動色階（2D）、H 隱藏控制面板、D 開關 Phase delay、T Traces。都可以在「設定 → 快捷鍵」更改或關閉。
- **Phase delay**（Plot config）：去除線路的電學延遲 τ（z·exp(+i·2π·f·τ)，f 是 X 軸，會依 Hz / MHz / GHz 換算）。按「計算」會用掃描兩端的相位斜率自動擬合 τ。
- **與 Lab Control 連動**：量測完成的新數據會自動在讀檔程式開啟（雙層分檔除外）；從讀檔程式把數據拖到 Lab Control 的量測視窗會套用該數據的量測設定。
- **Folder 子資料夾縮排變小**。
- **程式內更新**：修正「立即更新」有時不出現（同一版先由 GitHub 通知時沒有安裝檔資訊），以及更新時卡在命令視窗。
