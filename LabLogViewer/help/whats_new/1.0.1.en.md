### Smoother trace switching, Viewer straight after a measurement
- **Much faster trace switching**: the axes keep a cached picture, so switching traces no longer redraws the tick labels; the curve is reused; holding an arrow key down draws only the last trace instead of queuing redraws.
- **2D changes no longer freeze the window**: a large map (over 500k points) is recomputed on a worker thread when Transform, Operation, Smooth … change; the window stays usable and the new picture replaces the old one when ready.
- **After a measurement**: Lab Control's new data opens directly in a Viewer (the database / Folder window does not come up), also when LabLogViewer was not running.
