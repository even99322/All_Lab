### The NAS index: big folders open at once, also over VPN
- **Opening a folder inside 數據集散地 is almost instant**: the hub on the NAS has already read every file with this program's own parser (name, creation time, sweep dimensions, Tags, Star); LabLogViewer gets the whole folder from the hub in one request instead of opening files over VPN.
- **Previews come from the NAS**: clicking a Data first asks the hub for its default preview (a few tens of KB) instead of copying the whole file; the status line says "Preview from the NAS index". Files whose display you changed in the Viewer are still read themselves.
- A file changed after indexing (other size or time), an unreachable hub, or a NAS without the index: LabLogViewer simply reads the files as before.
- No extra login: a computer that can read 數據集散地 uses the key in its `.qel` folder to get the index.
