### Desktop pet (new)
- **Settings → Pet**: adopt the Cute Cat, Shiba or Capybara as a desktop pet. Drag it anywhere and onto other monitors, click it, right-click to sleep or hide it; it closes with LabLogViewer and never locks a scientific function.
- One pet at a time; a new pet becomes available when the current one reaches Lv.50. Research earns EXP (prototype: about 20 measurements a day reach Lv.50 in half a year); levels add quick-action slots and new looks.
- Hover over the pet for its bar: the pet panel and quick actions (shortcuts to YIG, Export, 3D and other existing windows).
- The pet panel adds a backpack (drag-to-pet from Lv.10), Recent (Lv.20), Alerts (Lv.30), Dock (Lv.40) and Dashboard with presets (Lv.50); earlier looks can be chosen again.
- An unexpected error makes the pet raise an alert.

### Plot settings (Viewer, 1D and 2D)
- New **Fixed Rotation** group: **Rotation/x**, **Fixed Rotation** (both with **Calculate**), **Auto-rotate**, **Unwrap angle**, **Plot in dB**, **Operation** (`y-<y>`, Normalize, d/dx, FFT, Histogram, Histogram-2D incl. I/Q histogram), **Smooth**, **Traces** (show individual).
- 2D has a **Third dimension** group: choose any sweep channel as the Y axis, with its own Operation (`y-<y>`, Normalize, d/dx), Smooth, trace list and Ignore x-data. Data with more than two sweep dimensions can be viewed through it.
- **Equations** now work in 1D and 2D and are switched by **Enable equations**; the typed text is kept when you switch off.

### 2D X/Y Cross-section
- **View → Show → Show 2D X/Y Cross-section** turns the Viewer's own 2D plot into a Labber-style cross-section: two draggable lines (only move when dragged), X cut on top, Y cut on the left (mirrored, aligned with the heat map's Y axis), contrast Max/Min boxes with Auto/Full range in the top-left corner (the colour bar already shows the distribution). With several panes it opens in its own window. It follows the dark/light theme.

### Export
- **MATLAB (.mat)** in **Export Data**.

### Multi-Pane
- **Sync Point Marks across panes** (MARKS panel): a Point Mark placed, moved, hidden or deleted in one pane appears on the same data point in all panes, even when they show Magnitude, Phase, etc. The 2D cross-section always opens in its own window with several panes.

### Quick Preview
- Faster: large 2D previews are thinned to about 1600 points per axis, the last 6 previews are cached, and the first readable file is selected automatically so the preview is never empty after opening a folder.

### Mac trackpad
- Two-finger slide pans, pinch zooms, two-finger double-tap fits all data, two-finger press opens the context menu; one finger draws with Annotation; in 3D one finger or two-finger scroll rotates, twist rolls, double-tap resets. See **Shortcuts**.
- With Annotation on, a left-button (one-finger) drag now draws.

### Compare Traces (new window)
- **Analysis → Compare Traces...** overlays, stacks, subtracts or divides up to six 1D traces: I / Q / phase / magnitude of one file, or any trace of one file against any trace of another. Options: ignore X values (compare shape only), shared X range, fixed step, scale Y, two Y axes when two units occur. Read-only.

### Network drives and errors
- Opening a file on a network drive no longer fails with *unable to lock file (errno 35)*: files are read without file locks and a busy drive is retried, then reported as **File temporarily busy** instead of a damaged file.
- After a crash the **Recovery Report** shows the real stack (or says the run ended from outside) instead of "unknown", and the 3D window attaches the crash details of its process. **Unexpected error** dialogs show the full traceback under **Show Details...**.

### Settings
- **Performance Monitor...** (Settings > Appearance > Advanced): live UI lag, CPU, memory, where the interface is busy and a list of freezes; report can be saved.
- Windows: the installer's Desktop and Start-menu shortcuts follow the chosen app icon, **Recreate Desktop shortcut** makes a new one, and the installer offers the icon choice.
- **3D window icon** can now be your own picture too: press **Import picture...** in Settings > Appearance > 3D window icon; it becomes a **My picture** button in the same row.

### Smoother after long use
- Closing a data window now frees everything it used. Before, each opened and closed file left about 35 MB and 1,300 interface objects behind, so the program slowed down after days of use.
- Moving between traces no longer saves an empty Mark record for every trace you look at, and the Data Table is only filled while it is open, so changing traces is faster.
- A 3D window that was closed no longer stays registered for settings changes.
- Closed Browser/Viewer windows are no longer kept alive by language and theme changes (they used to leave about 8 MB each); the Help, Pet, bell, Figure Builder and Named View windows were fixed the same way.

### Scanning a folder
- One unreadable file on a network drive (for example an input/output error) is now marked as an error and retried; the rest of the folder is still scanned.

### Settings
- New **CPU threads** in Settings > Appearance > Advanced: how many worker threads background work may use. Default: 75 % of the logical CPUs (at least 1).

### Cancel opening a database
- **Cancel** on the scanning dialog (or **Stop** in the status bar while metadata is being read) now stops the import at once; what was already read stays.

### Browser window
- The IP-transfer row (Receive / Receiver / send box) at the top right is hidden for now. The **drag to share data** setting is unchanged.

### TRACES panel and 2D plots
- The buttons in the TRACES panel (bottom right) are now icons that always fit; rest the mouse on one to see its name. The panel needs less height, so the saved-overlay controls no longer disappear.
- 2D heatmaps have a new **Swap X / Y** button that transposes the plot.

### Marks
- New **Horizontal Range** and **Rectangle Range** Mark tools (two clicks; every edge and corner can be dragged or typed in with X/Y Start/End).
- Mark labels and the details panel now show the quantity and unit of each axis (for example Phase in deg). Changing the Y quantity removes marks that sit at a Y value (Horizontal Line, Crosshair, Horizontal/Rectangle Range).

### Notifications
- A **bell** at the top right of the Browser window collects notices: a newer update (with its first three changes, **... more** opens the full update preview, and you can **Skip this version**), a finished measurement, days opened in a row, and pet level-ups. Use the gear button for **Mute all** or per-kind switches.
- With a desktop pet shown, a notice also appears as a translucent bubble above its head for about 6 seconds.
- The update notice now reads the project's GitHub update file in the background after start (the only web address allowed; silently skipped when offline; network-share paths are still always refused).
### Tags and stars
- Tags are now written into the HDF5 file itself (its `Tags` list, as Labber does), so everyone using the same database on the NAS sees them. Tags already in the file are kept, only names are stored, and renaming or deleting a Tag updates the files too. If a file is busy (a measurement, someone else editing, offline drive) a message says so, the file stays intact and the change is retried automatically.
- Stars are now written into the HDF5 file too (the root `star` attribute, as Labber does). A file that is already starred is never switched off by the program; only your own un-star removes it. Stars and Tags share one waiting queue (retried about every 60 s, kept across restarts, count shown in the status bar). Writing creates a short-lived `.lock` file beside the data file so several computers cannot change one file at once; renaming uses the same lock (if in use, try again later). The old `stars.json` is not copied into files.
- Writing a comment into the file also uses the same `.lock` file, and reading retries when the file is briefly busy; after a quick rename or star toggle, an older scan result no longer overwrites the star you just set.
- After a rename the list updates only that one row at once (no full rescan, no progress window); about 1.5 s later a quiet background rescan double-checks it, and several quick renames share one check. Refresh/scan no longer leaves closed progress windows behind, so memory grows much less over long sessions.
- When the program starts again, the Data selected last time begins loading its preview in the background while the folder is still being scanned, and the same file is no longer read more than once: the first preview of a large file appears sooner (a 117 MB file went from about 3.8 s to about 2.3 s in testing) and the memory peak at start-up is much smaller.
