### Big folders over VPN no longer freeze the window
- **No freeze after opening a database**: after the scan, the Browser used to walk the whole NAS folder again on the window's thread (only to list empty folders); over VPN that froze the window for tens of seconds to minutes. The scan's own listing is used now.
- **Faster scan**: on a network drive several folders are listed at once, so listing thousands of files over VPN is much quicker; the progress bar updates only a few times a second.
- **Clicking through the list stays smooth**: the Comment is read in the background (it cannot be edited for that moment); a file's identity (its full path) is remembered instead of asking the server on every click; the preview checks for changes with the size and time from the folder listing.
- **Auto refresh uses less network**: sizes and times come with the folder listing (no request per file); on a network drive the full walk for new folders runs every 5 minutes.
- Automatic Tags for thousands of files start much faster.
