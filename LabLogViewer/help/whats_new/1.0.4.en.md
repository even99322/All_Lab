### Opening 數據集散地 no longer freezes; switching folders is smoother
- **No more freeze (and Safe Recovery Mode) at start-up**: reopening the Viewers of the last session used to ask the NAS about the location of every one of thousands of files (minutes over VPN, which looked like a hang); now only files with the same name are compared, which is instant.
- **Switching folders no longer waits for the NAS**: clicking a new folder does not ask the NAS for each file's full path any more — the opened database folder was resolved once and every file below it is derived from it.
- Phones and tablets can browse 數據集散地 too: open `http://<NAS>:8765/m/data` in the browser (needs Lab Control Hub 1.0.6).
