### Lab Control .nc files work like Labber logs
- Built on the latest 2.0 (tags and stars written into the data files) plus the 2.1.0 `.nc` reader.
- **Tags, star and comment** are written into `.nc` files too, synced to the file like Labber logs: tags in the root attribute `tags`, the star in `star`. The file stays a standard xarray / NetCDF dataset (`xr.open_dataset(...).attrs["tags"]`).
- **De-background**: a `.nc` Target gives `<name>_debg.nc` (same NetCDF layout).
