### Colormap picker, separate cuts, open from the web page
- **2D colormaps with previews**: every entry of the Colormap list shows its colors; new maps RdBu, seismic, Spectral, cividis, turbo and jet. At the end of the list, "Reverse Current Colormap" flips the current map and "Custom Colors..." builds your own from 2–3 colors (low / middle / high, live preview); recent custom maps stay in the list. The Browser preview uses the same map.
- **Full Range**: next to Auto Range, the color range = the data's full minimum to maximum (Auto Range ignores the few most extreme pixels).
- **X Cut and Y Cut separately**: View → Show → X Cut / Y Cut open inside the 2D plot (top / left), each on its own, instead of separate windows; the intensity histogram and Max / Min / Auto / Full range moved into the "Contrast" button in the top-right corner.
- **Open from the web page**: on the platform's web page "數據查看", "用讀檔程式開啟" opens the file in LabLogViewer on this computer (the computer must reach 數據集散地).
- Chinese interface: open drop-down lists are translated too; the 2D color bar no longer shows its title twice.
