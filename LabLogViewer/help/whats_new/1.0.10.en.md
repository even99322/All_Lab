### Labber database
- **Import into Labber Database (the Labber Converter is now part of LabLogViewer)**: File ▸ Import into Labber Database…, right-click selected .nc files in the Browser, or Convert ▸ Import into Labber Database… in a viewer. The measurements are written as Labber logs into the Year / Month / Data_MMDD folders of a Labber database folder and listed in its Database.hdf5, so the native Labber Log Browser opens them.
- **Existing or new database**: pick a folder that already has Database.hdf5, or New Database… to create one.
- **Same-name files**: you are asked to Replace, Skip This File or Keep Both (keeps both with a _1 suffix).
- **NAS-friendly**: network hiccups are retried (5 times, growing pauses); NAS shares without HDF5 file locking work; an interrupted import resumes where it stopped.
- **Sync Labels…** re-reads every log; "Rebuild" also removes stale projects / tags that no longer match any file (e.g. a phantom "mirror").
- Backups of Database.hdf5 now go to a hidden .labber-converter-backups folder (only the last 5 are kept) instead of piling up as .bak files.
- Files with one swept quantity (point layout) and single traces are converted too; files that cannot be converted are skipped with a reason instead of stopping the batch.
