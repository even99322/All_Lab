### Conversion
- **.nc ⇄ Labber .hdf5**: select one or more Data in the Browser, right-click → **Convert to Labber .hdf5... / Convert to Lab Control .nc...**, or use **File → Convert**. With the lab's Labber Python environment the file is written by the Labber API, otherwise by a built-in writer that makes the same layout; multi-axis sweeps follow Labber's order (the first Step-list channel is the inner loop). No file is ever overwritten.
### Plot tools
- **Move tool**: a cross-arrow button right of the pointer; left-drag moves the whole plot.
- **Shortcuts**: F1 pointer, F2 move, F3 share, F4 zoom; Help in the Viewer is now Shift+F1.
- **X / Y Cut button**: one toolbar button opens the X cut above and the Y cut left of the 2D map; click again to close them.

- Real Labber files with two or more swept axes now put every cell in the right place: Labber's first Step-list axis is the inner loop.
