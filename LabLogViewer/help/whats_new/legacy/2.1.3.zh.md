### 去背景、量測參數、和量測程式互通
- **去背景修好了**：Windows 上所有去背景（`.nc` 和 Labber 檔）都會出現「[Errno 9] Bad file descriptor」而失敗，現在可以正常產生 `_debg` 檔。
- **量測參數**：資料庫視窗下方的「備註」分成兩半，右邊顯示選到的數據是怎麼量的：掃描範圍與點數、VNA 頻率 / 點數 / IF 頻寬 / 平均 / 功率、固定的電源值、建立時間。
- **介面 → 量測**：開啟 Lab Control；選了一筆數據時，Lab Control 會詢問是否套用這個檔的量測設定。Lab Control 已經開著就直接交給它。
- **拖曳**：從資料庫清單把數據拖到 Lab Control（套用設定）、檔案總管或郵件，都會帶著檔案本身。
- **Lab Control 的 `_raw/*.lm.h5`** 也能開啟（唯讀）。
