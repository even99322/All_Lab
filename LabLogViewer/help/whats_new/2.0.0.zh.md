### 桌面寵物（新）
- **設定 → 寵物**：領養橘貓、柴犬或水豚當作桌面寵物。可以拖到任何地方與其他螢幕、點牠互動、右鍵睡覺／隱藏，關閉 LabLogViewer 時會一起關閉；不會鎖住任何科學功能。
- 一次養一隻；目前的寵物升到 Lv.50 才能領養新的。做研究會累積經驗值升級（雛形，約每天 20 筆、半年升滿）；升級會增加快捷動作格數並換造型。
- 滑鼠移到寵物上會出現工具列：寵物面板與快捷動作（YIG、匯出、3D 等現有功能的捷徑）。
- 寵物面板新增背包（Lv.10 起可拖曳給寵物）、最近（Lv.20）、通知（Lv.30）、Dock（Lv.40）、儀表板與工作組合（Lv.50）；可以換回已解鎖的低等級外觀。
- 發生未預期的錯誤時寵物會提醒。

### 繪圖設定（Viewer，1D 與 2D）
- 新增 **固定旋轉** 群組：**旋轉/x**、**固定旋轉**（皆附 **計算**）、**自動旋轉**、**解開相位角**、**以 dB 顯示**、**運算**（`y-<y>`、Normalize、d/dx、FFT、Histogram、Histogram-2D 含 I/Q 直方圖）、**平滑**、**Trace 顯示**（逐條顯示）。
- 2D 新增 **第三維度** 群組：任一掃描通道都可當 Y 軸，並有自己的運算（`y-<y>`、Normalize、d/dx）、平滑、Trace 清單與忽略 x 資料。掃描維度超過兩維的資料可由此檢視。
- **公式** 現在 1D、2D 都能用，由 **啟用公式** 開關；關閉時輸入的文字會保留。

### 2D X/Y 截面
- **檢視 → 顯示 → 顯示 2D X/Y 截面** 會把 Viewer 自己的 2D 圖變成 Labber 風格的截面：兩條可拖曳的線（只在拖曳時移動）、上方 X 切線、左側 Y 切線（鏡像、與熱圖 Y 軸對齊）、左上角有對比最大／最小值與自動／完整範圍（色條本身已呈現分佈）。多個窗格時改開獨立視窗。會跟隨深色／淺色主題。

### 匯出
- **匯出資料** 新增 **MATLAB (.mat)**。

### 多窗格
- **跨窗格同步點標記**（MARKS 面板）：在一個窗格新增、移動、隱藏或刪除的點標記，會出現在所有窗格的同一個資料點上，即使各窗格顯示 Magnitude、Phase 等不同量。有多個窗格時，2D 截面一律開獨立視窗。

### 快速預覽
- 更快：大型 2D 預覽每軸精簡到約 1600 點、快取最近 6 個預覽，並自動選取第一個可讀檔案，開啟資料夾後預覽不再是空的。

### Mac 觸控板
- 兩指滑動平移、捏合縮放、兩指輕點兩下看全部資料、兩指按壓開啟右鍵選單；標註時單指繪圖；3D 單指或兩指滑動旋轉、扭轉滾轉、輕點兩下重設。詳見 **快速鍵**。
- 標註開啟時，左鍵（單指）拖曳現在會畫線。

### 比較 Trace（新視窗）
- **分析 → 比較 Trace⋯** 可把最多六條 1D trace 疊合、堆疊、相減或相除：同一檔案的 I／Q／相位／振幅，或一個檔案的任一條 trace 對另一個檔案的任一條。選項：忽略 X 值（只比較形狀）、共同 X 範圍、固定間距、縮放 Y、出現兩種單位時使用雙 Y 軸。唯讀。

### 網路硬碟與錯誤
- 開啟網路硬碟上的檔案不再出現 *unable to lock file (errno 35)*：改以不加檔案鎖的方式讀取，硬碟忙碌時會重試，仍失敗則顯示 **檔案暫時忙碌**，而不是說檔案損毀。
- 崩潰後 **復原報告** 會顯示真正的堆疊（或說明程式是從外部結束），不再只寫「未知」；3D 視窗會附上其程序的崩潰資訊。**未預期的錯誤** 對話框在 **顯示詳細資料⋯** 下附完整 traceback。

### 設定
- **效能監看⋯**（設定 > 外觀 > 進階）：即時顯示介面延遲、CPU、記憶體、介面忙於何處，以及卡頓清單；可儲存報告。
- Windows：安裝程式建立的桌面與開始功能表捷徑會跟著所選 App 圖示，**重建桌面捷徑** 可建立新的捷徑，安裝時也可選圖示。
- **3D 視窗圖示** 也能用自己的圖片：在 設定 > 外觀 > 3D 視窗圖示 按 **匯入圖片⋯**，會變成同一排的 **我的圖片** 按鈕。

### 長時間使用更順暢
- 關閉資料視窗後會完整釋放它用過的資源。以前每開關一個檔案會殘留約 35 MB 與 1,300 個介面物件，使用數天後程式就會變慢。
- 切換 trace 時不再為每個看過的 trace 存一筆空的 Mark 紀錄，資料表也只在開啟時才填入，切換 trace 更快。
- 關閉過的 3D 視窗不再繼續登記接收設定變更。
- 關閉的瀏覽器／Viewer 視窗不再因語言與主題切換而被留在記憶體（以前每個約殘留 8 MB）；說明、寵物、通知鈴、圖表製作與命名視圖視窗也用同樣方式修正。

### 掃描資料夾
- 網路磁碟上單一檔案無法讀取（例如輸入/輸出錯誤）時，只會把那個檔案標為錯誤並重試，其餘檔案照常掃描。

### 設定
- 設定 > 外觀 > 進階 新增 **CPU 執行緒數**：背景工作最多可使用的執行緒數量，預設為邏輯 CPU 數的 75%（至少 1）。

### 可中斷開啟資料庫
- 掃描對話框的 **取消**（或補充中繼資料時狀態列的 **停止**）現在會立刻中斷匯入；已讀完的部分會保留。

### 瀏覽器視窗
- 右上角的 IP 傳輸列（接收／接收端／傳送區）暫時隱藏。**拖曳分享資料** 設定不變。

### Trace 面板與 2D 圖
- Trace 面板（右下角）的按鈕改為圖示，不再被截字；滑鼠停在圖示上會顯示名稱。面板所需高度變小，已存疊圖的控制項不會再消失。
- 2D 熱圖新增 **交換 X / Y** 按鈕，可把圖轉置。

### 標記
- 新增 **水平範圍** 與 **矩形範圍** 標記工具（點兩下放置；每一邊與每個角都能拖曳，或用 X／Y 起點／終點輸入數值）。
- 標記標籤與詳細資料現在會顯示各軸的物理量與單位（例如 Phase、deg）。改變 Y 物理量時，落在 Y 值上的標記（水平線、十字線、水平／矩形範圍）會被移除。

### 通知
- 瀏覽器視窗右上方新增 **鈴鐺**，收集各種通知：有新版本（顯示前三項變更，按 **⋯ 更多** 開啟完整更新預覽，也可 **略過此版本**）、量測完成、連續登入天數與寵物升級。齒輪按鈕可選 **全部靜音** 或逐類開關。
- 桌面寵物顯示時，通知也會以半透明氣泡出現在寵物頭上約 6 秒。
- 更新通知現在會在啟動後於背景讀取專案的 GitHub 更新檔（唯一允許的網址；離線時靜默略過，網路磁碟路徑仍一律拒絕）。

### 標籤與星號
- 標籤現在會寫進 HDF5 檔案本身（檔內的 `Tags` 清單，與 Labber 相同），NAS 上使用同一資料庫的人都看得到。檔內原有的標籤會保留，只存標籤名稱；重新命名或刪除標籤時檔案也會一併更新。若檔案正忙（量測中、別人編輯中、磁碟離線），會跳出訊息，檔案不會損壞，且之後自動重試。
- 星號也改為寫進 HDF5 檔案（根屬性 `star`，與 Labber 相同）；已有星號的檔案不會被程式取消，只有你手動取消才會移除。星號與標籤共用同一個等待佇列（約每 60 秒重試、重開程式仍保留、狀態列顯示等待數量）；寫入時會在旁邊建立暫時的 `.lock` 檔避免多台電腦同時改同一檔案，重新命名也一樣（被占用時請稍後再試）。舊的 `stars.json` 不會寫進檔案。
- 註解寫進檔案時也會用同一個 `.lock` 檔，讀取時若檔案暫時被占用會自動重試；快速連續改名／切換星號時，舊的掃描結果不會再把剛設定的星號蓋回舊值。
- 重新命名檔案後清單會立刻只更新那一筆（不再整份重掃、不跳進度視窗），約 1.5 秒後在背景安靜地重掃一次對帳；連續改名會合併成一次。重新整理／掃描後不再遺留已關閉的進度視窗，長時間使用的記憶體成長明顯減少。
- 重新開啟程式時，上次選的那一筆資料會在掃描資料夾的同時就開始背景讀取預覽，並避免同一個檔案被重複讀取：大檔的第一次預覽更快出現（實測 117 MB 檔案由約 3.8 秒降到約 2.3 秒），啟動時的記憶體尖峰也明顯變小。
