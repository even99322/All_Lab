### De-background, measurement settings, and Lab Control
- **De-background fixed**: on Windows every De-background (`.nc` and Labber files) failed with "[Errno 9] Bad file descriptor"; it now writes the `_debg` file.
- **Metadata**: the note area below the Database Browser preview is split: Comment on the left, and on the right how the selected Data was measured — sweep range and points, VNA frequency / points / IF bandwidth / averages / power, fixed sources, creation time.
- **Interfaces → Measurement** opens Lab Control; with a Data entry selected, Lab Control offers to apply that file's measurement settings (an open Lab Control receives it directly).
- **Dragging** a Data entry from the Browser list now carries the file itself (drop it into Lab Control, a file manager, a mail).
- Lab Control's raw records (`_raw/*.lm.h5`) open too (read-only).
