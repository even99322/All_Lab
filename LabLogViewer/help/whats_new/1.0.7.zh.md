### 轉檔
- **.nc ⇄ Labber .hdf5**：瀏覽器選一個或多個數據按右鍵 → **轉成 Labber .hdf5⋯／轉成量測檔 .nc⋯**，或 **檔案 → 轉檔**。有 Labber 的 Python 環境就用 Labber API 寫檔，沒有就用內建寫法做出一樣結構的檔案；多維掃描的軸順序照 Labber 的規則（Step list 第一個是最內圈）。不會覆蓋任何檔案。
### 看圖工具
- **移動工具**：工具列指標右邊多一個十字箭頭，按住左鍵拖曳整張圖移動。
- **快捷鍵**：F1 指標、F2 移動、F3 分享、F4 局部放大；Viewer 的說明改成 Shift+F1。
- **X / Y 截面按鈕**：工具列一個按鈕就打開 2D 圖上方的 X 切線和左邊的 Y 切線，再按一次關閉。
