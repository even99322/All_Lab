量子工程平台 App

跟論文庫一樣，把這個網站裝成 App：模塊下載、數據查看、量測查看、量測設置都在裡面，從桌面、Dock 或主畫面直接開，不用再打網址。

各裝置的安裝步驟

Windows / Mac · Chrome 這台

  1. 網址列右邊有 安裝 圖示（螢幕加箭頭）就按它；
  2. 沒有的話：右上 ⋮ →「投放、儲存及分享」→「將網頁安裝為應用程式…」（舊版是「建立捷徑」，記得勾「以視窗開啟」）；
  3. 按「安裝」。之後在開始選單 / 啟動台、工作列 / Dock 都找得到「量子工程」。

Windows / Mac · Edge 這台

  1. 網址列右邊的 App 可用 圖示，或
  2. 右上 … →「應用程式」→「將此網站安裝為應用程式」；
  3. 按「安裝」，可勾選釘選到工作列 / 開始。

Mac · Safari 這台

  1. 選單列「檔案」→「加入 Dock…」（或工具列的分享按鈕 →「加入 Dock」）；
  2. 按「加入」。需要 macOS Sonoma 14 以上；舊版請用 Chrome 或 Edge。

Android 手機 / 平板 這台

  1. 用 Chrome 開這一頁，上面的「⬇ 安裝 App」能按就直接按；
  2. 不然右上 ⋮ →「安裝應用程式」或「加到主畫面」→「安裝」；
  3. Samsung 網際網路：選單 →「新增頁面至」→「主螢幕」。

iPhone / iPad 這台

  1. 用 Safari 開這一頁（iOS 16.4 以上 Chrome、Edge 也可以）；
  2. 按 分享 按鈕（方框加向上箭頭；iPad 在網址列右邊，iPhone 在下方或「⋯」裡）；
  3. 往下找「加入主畫面」，「以網頁 App 開啟」保持打開 → 按「加入」。

裝好的 App 有自己的登入，第一次開要再登入一次（之後 30 天內不用）。
