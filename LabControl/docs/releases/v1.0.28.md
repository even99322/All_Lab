# Lab Control 1.0.28

- 發佈日期：2026-11-08
- 類型：修正（4 port VNA 的量測方塊只能選 S21 / S11 / S12 / S22）
- 前一版：1.0.27

## 摘要（貼到版本說明）

- **量測方塊可以選 4 port VNA 全部 16 個 S 參數（S13、S34、S43…）**。
  以前 VNA 沒連線時（編方案、在別台電腦選「執行於節點」、Hub 網頁量測設置），清單只有預設的 S21 / S11 / S12 / S22；
  現在沒連線也會列出全部：
  - VNA 一連線就記住偵測到的 port 數（LAB/vna_ports.json），之後沒連線也照用；
  - 也可以在 instruments.yaml 寫 `ports: 4`；
  - 量測節點會回報 VNA 的 port 數，別台電腦編那台的方案時一樣列出 16 個；
  - VNA 連上線後，流程圖的量測清單自動更新。
- **量測設定可以手動加入 S 參數**：「量測通道」下面輸入 S34 →「＋ 加入」（Hub 網頁量測設置的「其他」欄位也可以）。
  超出 port 數會提示。
- 量測通道清單改成橫向排、自動換行，16 個一眼看完；標示「4 port VNA：可量 S11…S44（Sij：i = 接收 port，j = 激發 port）」。
- 量測時 VNA 上沒有那條 trace 會自動建立（和以前一樣，偵測到的 port 範圍內）。

## 細節

- `core/vna_ports.py`：`known_ports`、`trace_list`、`remember_ports`（R&S ZNA 與模擬 VNA 共用）。
- `remote/instruments.py`：節點回報 VNA 的 `ports` / `traces`；`remote/client.py` 鏡像 Station 帶 `_node_ports`。
- 工作台：VNA 連線 / 偵測到 port → 重建量測清單。
- tests/test_vna_4port.py。

## 更新步驟

量測電腦與編方案的電腦更新到 1.0.28；Hub 網頁的「其他」欄位要在 Hub 控制台更新到 1.0.28。
