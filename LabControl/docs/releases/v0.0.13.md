## 摘要（貼到 Lab APP「版本說明」）

- 實驗室的程式整合成「量子工程平台」。量測（Lab Control）、讀檔（LabLogViewer）、論文庫是各自獨立的模塊，可以單獨更新。
  它們共用：
  - NAS 上的 Hub；
  - 論文庫的帳號；
  - 同一批標籤。
- **登入**：用論文庫的帳號密碼，支援兩步驟驗證。站長就是論文庫的站長。站長可以：
  - 為每個人開關各模塊；
  - 停用帳號（會寫回論文庫並立刻登出）；
  - 發佈各模塊的新版。
- **平台網頁** `http://<NAS>:8765/`，手機也能用，可以加到主畫面。內容有：
  - 模塊；
  - 數據目錄：依標籤、關鍵字找；
  - 標籤與論文；
  - 站長管理。
  原本的節點監控頁改到 `/nodes`。
- **標籤與論文**：「檔案設置」的「標籤」欄改成平台共用的標籤，同時也寫進 Labber 檔的 tags。旁邊「🏷 標籤與論文」：
  - 從共用標籤勾選；
  - 右邊列出每個標籤在論文庫裡的論文，點一下就開。
- **數據目錄**：這台電腦量完存好的檔，會在背景上傳到平台並登記標籤、量測者、方案。量測節點的檔原本就會上傳，現在也會登記。
- **已存的數據**（檔案設置的新分頁）：剛存好的檔可以直接拖到讀檔模塊，或按「在讀檔模塊開啟」。
- **把數據檔拖進 Lab Control = 套用它的設定**：
  - Lab Control 0.0.13 以後存的檔：整個量測方案；
  - 一般 Labber 檔：VNA 設定（頻率、點數、功率、IF、平均）與名稱相同的掃描範圍，加上檔案標籤。
  確認後才會改，而且可以復原。來源可以是：
  - 檔案總管；
  - LabLogViewer 的資料清單；
  - 平台網頁 / 啟動器的數據（會自動下載）。
- 平台網頁按「套用設定到量測模塊」，你開著的 Lab Control 也會套用。
- 工具列新增「平台 ▾」：登入 / 登出、平台網頁、數據目錄、標籤與論文、本機量測自動上傳開關、套用數據檔的設定。
- Monitor 新增「平台（站長）」分頁：
  - 論文庫、Hub、節點、數據目錄的狀態；
  - 使用者 × 模塊權限表；
  - 帳號停用 / 啟用；
  - 發佈模塊新版；
  - 操作紀錄。
- Hub 更新後需要設定論文庫網址，兩種方式擇一：
  - `docker-compose.yml` 的 `LABHUB_PAPERLIB_URL` / `LABHUB_PAPERLIB_PUBLIC`；
  - 或 `data/platform.json`。
  沒設定時其他功能照常，只是不能用論文庫帳號登入。

## 新增

### Hub（labhub 0.0.13）

- `labhub/platform.py`：
  - 論文庫用戶端（伺服器對伺服器，帶 `X-PL` 與 `X-Forwarded-For`，支援兩步驟驗證）；
  - 使用者 session：`u_…` token，30 天，每 10 分鐘向論文庫確認；
  - 模塊權限；
  - 模塊發佈：`data/modules/<模塊>/<版本>/`；
  - 標籤：論文庫的標籤 ＋ Hub 的分類 / 只用在數據的標籤；
  - 論文查詢；
  - 數據目錄：`data/platform.db`；
  - 訊息匯流排；
  - 操作紀錄；
  - 登入失敗限制：同一 IP 10 分鐘 5 次。
- `labhub/platform_routes.py`：`/api/platform/…`，API 見 PLATFORM.md。
- 平台網頁 `/portal`（PWA：manifest、service worker、圖示），新的登入頁（論文庫帳號，或裝置 token）。原本的監控頁改到 `/nodes`。
- 權限分級：
  - 裝置 token：照舊可用；
  - 使用者：需要「量測模塊 / 量測節點」權限才能用量測 API；
  - 站長：管理；
  - Hub 更新 / 重啟：裝置 token 或站長。
- `PUT /api/files/…` 上傳時登記到數據目錄，可以帶 `tags`、`run`、`scheme`、`meta`。啟動時把舊的上傳檔補登記。
- 論文庫網址：環境變數 `LABHUB_PAPERLIB_URL` / `LABHUB_PAPERLIB_PUBLIC`，或 `data/platform.json`。

### Lab Control

- `qelcomm/`：通信模塊，內附，只用標準函式庫。
- `labcontrol/integrations/platform.py`：
  - 沿用啟動器的登入；
  - 標籤快取；
  - 本機量測上傳（`platform.upload_local_runs`）；量測節點匯出時暫停，不重複上傳。
- `labcontrol/integrations/file_settings.py`：
  - 從數據檔讀回設定：Lab Control 原生檔、含 `attrs["labcontrol"]` 的 Labber 檔、一般 Labber 檔（Step list / Step config / Instrument config / Data）；
  - 套用到方案：流程圖方案直接改圖上的方塊。
- Labber 匯出完成後在檔案根目錄寫 `attrs["labcontrol"]`（完整 metadata，含方案），讓檔案拖回來時能還原整個方案。
- `data.exported` 事件多帶 `tags`、`scheme`。`Experiment.output_tags()`。節點上傳到 Hub 時帶標籤。
- `labcontrol/apps/qt/platform_ui.py`：
  - 登入對話框；
  - 標籤挑選（含相關論文）；
  - 「已存的數據」；
  - `PlatformController`：選單、拖放、平台訊息、啟動時的 `QEL_OPEN`。
- `labcontrol/testing/fake_labber.py`：測試用的 Labber 格式小檔。
- `settings.yaml` 新增 `platform:`，包含 `enabled`、`upload_local_runs`、`listen`。

### Monitor

- `labmonitor/platform_tab.py`：「平台（站長）」分頁。
- Monitor 的發佈資料夾內附 `qelcomm/`。
