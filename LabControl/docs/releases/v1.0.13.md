# Lab Control 1.0.13

- 發佈日期：2026-10-21
- 類型：功能（控制台直接從 GitHub 取得新版）；只需要更新 Hub
- 前一版：1.0.12
- 發佈檔：`LabControl_Setup_v1.0.13.exe`、`LabControlHub_v1.0.13.zip`

## 摘要（貼到版本說明）

- **不用再下載安裝檔再上傳**：平台網頁「控制台」最上面多了「從 GitHub 取得新版」。它列出雲端打包好的最新量測程式與讀檔程式
  （Windows 安裝檔、macOS 安裝檔、Hub 更新包…），標出線上已經有哪些；按「⬇ 下載 N 個新檔案並發佈」，NAS 直接從 GitHub 下載，
  下載完自動按順序發佈（Hub 最後更新）。也可以「只下載」之後再發佈，或打開「自動」：每 30 分鐘檢查一次，有新版就自動下載並發佈。
- **GitHub 的發佈也附上 Hub 更新包與程式 zip**：以後量測程式的每一次發佈都有 `LabControlHub_v*.zip`、`LabControl_v*.zip`、
  `LabControlMonitor_v*.zip`，Hub 也能從 GitHub 自己更新。
- 大檔（安裝檔）發佈時不再整個讀進記憶體。

## 變更

- `labhub/github_sync.py`（新）：`GithubSync`（`/repos/<repo>/releases` 快取 60 秒；`guess()` 由檔名判斷模塊與版本；
  `fetch()` 下載到 `staging/_github` 再 `Console.stage_path()`；`publish=True` 時 Hub 最後發佈；自動模式 `github_sync.json`）。
- `labhub/console.py`：`stage_path()`、`github`；模塊發佈改用檔案路徑。`platform_routes.py`：`GET /console/github`、
  `POST /console/github/fetch`、`PUT /console/github/auto`（站長）。`static/portal.html` 控制台卡片。
- `.github/workflows/release.yml`：`labcontrol-*` 的發佈附上 `make_release.py` 產生的 Hub / 量測 / Monitor zip。
- 環境變數：`LABHUB_GITHUB_REPO`（預設 even99322/All_Lab）、`LABHUB_GITHUB_TOKEN`（選用）、`LABHUB_GITHUB_API`。
- 測試：`tests/test_113.py`。
