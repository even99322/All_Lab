## 摘要（貼到版本說明）

- **存檔位置**：
  - 預設存到桌面的「數據集散地」（量測電腦是 `C:\Users\user\Desktop\數據集散地`）。
  - 每個專案一個資料夾：`數據集散地\<專案>\2026\10\Data_1012\`。
  - 檔案設置多了「專案資料夾」：
    - 空白時自動用論文庫專案的名稱，資料夾還沒有就建立；
    - 也可以從清單選已經有的資料夾，或打一個新名稱；
    - 每個專案選過的資料夾，這台電腦會記住；
    - 旁邊的 📂 可以打開存檔資料夾。
  - 設定檔裡還是舊預設 `C:/Users/QEL/Desktop/VNA_data` 的電腦會自動改成新的預設；自己改過的不會動。
- **電流目標旋鈕（即時數據）**：
  - 目標值改成跟網頁面板一樣的位數旋鈕：每一位上下各有 ▲▼，滑鼠停在某一位上滾滾輪也只動那一位，雙擊可以直接輸入。
  - 範圍 ±200 mA（卡片上顯示 `Range: 0.2 A`）。
  - 停手 0.7 秒後以斜坡移過去；旋鈕下面顯示**目前值**。
- **全域最大調整速率**：
  - 即時數據裡所有電流斜坡（目標、記憶 M1–M3、合併）都不會超過這個速率，預設 **10 mA/s**。
  - 面板最上面可以改，記在這台電腦。
  - 儀器的 `ramp_rate` 比較慢時，用儀器的。
- **VNA 量測方塊**：
  - 頻率可以選「起始 / 終止」或「中心 / 頻寬（span）」，切換時會自動換算。
  - 「⤓ 套用儀器目前值」：把 VNA 現在的頻率、點數、IF 頻寬、功率、平均填進來，例如在即時數據調好的值。
- **即時曲線軸運算**：
  - 曲線下面有「軸運算 x = … y = …」，例如 `y = y**2`、`x = log(x)`、`y = y - mean(y)`、`x = x/1e9`。
  - 只影響畫面，不改數據。寫錯會顯示原因，曲線維持原樣。
- **讀檔程式 2.1.5**：
  - 「檔案 → 開啟實驗室數據集散地」（Ctrl+Shift+O）：先找實驗室網路 `\\192.168.50.2\ccuqel\數據集散地`，再找 VPN `\\100.114.33.20\ccuqel\數據集散地`。Mac 會先幫你掛載。
  - 2D 熱圖不再像素化：掃描次數少（例如 77 次 × 10001 點）時，畫面上會平滑內插，讀值、切線、匯出仍用原始數據。「檢視 → 2D 熱圖平滑顯示」可以關掉。
  - 桌面寵物改成選擇性下載，安裝檔小了約 210 MB：
    - Windows 一鍵安裝：勾「讀檔的桌面寵物圖檔」；
    - Mac 一行安裝：會問要不要下載；
    - 之後都可以在「設定 → 寵物」從 NAS 下載；
    - 已經養了寵物的電腦：Windows 更新時會把原本的圖檔搬到新位置；Mac 會在開啟時詢問要不要下載。

## 變更

- **存檔**：
  - `labcontrol/data/naming.py`：
    - `DEFAULT_ROOT = ~/Desktop/數據集散地`、`DEFAULT_PATTERN = {project}/{yyyy}/{mm}/Data_{mmdd}`；
    - `data_root()` 會展開 `~` 和 `%VAR%`；
    - 新增 `project_folder(output)`、`list_project_folders()`、`remember_folder()` / `remembered_folder()`（`LAB/project_folders.json`）。
  - `settings.migrate()` 把舊預設值換成新的。
  - 方案 `output.project_folder` 是選定的資料夾。
  - `FilePanel` 新增「專案資料夾」（下拉、可輸入）與 📂。
- **即時數據**：
  - `labcontrol/apps/qt/live/digit_dial.py`：新增 `DigitDial`。
  - `dc_panel`：
    - 電流群組卡片的目標改用旋鈕，加上目前值與範圍標籤；
    - `capped_rate()`：所有斜坡都受全域最大速率限制（`LAB/live_prefs.json`，預設 `live.max_ramp_mA_s: 10`）；
    - 新的目標會先停掉同一組還在跑的斜坡。
  - `settings.yaml` 新增 `live:` 區段：`max_ramp_mA_s`、`dial_range_mA`、`dial_apply_ms`、`poll_s`、`memory_ramp_mA_s`。
  - `labcontrol/core/axis_math.py`：新增軸運算，只允許數字、x、y 與列出的 numpy 函式。
  - `vna_panel`：
    - 新增軸運算列，記在 `LAB/live_ui.json`；
    - 軸標題與 marker 讀值會跟著軸運算改。
- **量測方塊**：`MeasureDialog` 新增頻率設定方式（起訖 / 中心＋span，自動換算，只留一種）與「套用儀器目前值」。
- **Hub**：
  - 模塊 `llvpets`（`LabLogViewerPets_v*.zip`，用 `qel-module.json` 或 `pets_manifest.json` 辨識）；
  - `GET /get/llvpets/<版本>/<檔名>`；
  - `/get/setup.txt?pets=1` 多一行 `pets|…`（舊的一鍵安裝不帶 `pets=1`，看不到這行）；
  - Mac 腳本會詢問要不要下載寵物（或用 `QEL_PETS=1/0` 決定），解壓到 `~/Library/Application Support/LabLogViewer/pets`；
  - 下載頁加了說明。
- **一鍵安裝 1.1.0**：
  - 新增可選元件 `pets`（預設不勾），解壓到 `%LOCALAPPDATA%\LabLogViewer\pets`；
  - 安靜安裝用 `/COMPONENTS="labcontrol,lablogviewer,pets"`。
- **測試**：
  - `tests/test_live_0030.py`
  - `tests/test_console.py`：寵物清單
  - `tests/test_data.py`
- **雲端測試**：E2E 在 Windows 與兩種 Mac 都會安裝寵物圖檔，並讓讀檔程式的自我檢查載入每一隻寵物。
