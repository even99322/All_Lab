# Lab Control 1.0.2

- 發佈日期：2026-10-13
- 類型：功能（VNA 最低點置中、分檔一個外圈一個檔、背景＋自動去背、Data 方塊命名規則）與修正（熱圖關閉再開啟沒有內容）
- 前一版：1.0.1
- 發佈檔：`LabControl_v1.0.2.zip`（功能更新包）與安裝檔、`LabControlHub_v1.0.2.zip`（只有版本號，可以不發佈）。讀檔程式不變（1.0.1）。

## 摘要（貼到版本說明）

- **即時數據 VNA「⌖ 最低點置中」**：把目前 trace 最低點的頻率設成中心頻率（span 不變）。
- **熱圖關閉再開啟**：重新畫出目前這個外圈已經量到的內容（以前是空的）。
- **分檔：每個外圈各存一個檔**：外圈的值不變（單純重複掃描）時以前會全部併成一個檔，現在依「第幾次」分開存：`data_p1`、`data_p2`、`data_p3`；值有變化時檔名加上那個值：`data_100350mA`、`data_100360mA`。
- **單磁鐵電流掃（範本「2D」）換成「掃描 → 背景 → 去背」**：電流掃完 → 電流設成固定值（預設 50 mA，請依實驗修改）→ 量一次背景（`<檔名>_bg.nc`）→ 主數據每個檔除以背景（複數相除，跟讀檔程式的去背一樣），另存成 `<原檔名>_debg.nc`。
- **點 Data 方塊在右側設定命名**：右邊「Data 方塊」分頁：分檔命名（`{stem}_{label}`，可用 `{n}`、`{index:03d}`）、數值格式（100350mA / 100.35mA / 100p35mA）、檔名預覽；點「去背」方塊設定存到哪個資料夾、後綴（預設 `_debg`）。
- 實驗室 LAB/templates 的舊「2D」範本移到 `舊範本_rev0/`；論文庫專案裡的舊「2D」載入時換成新版。
