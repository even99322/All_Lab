# Lab Control 1.0.27

- 發佈日期：2026-11-05
- 類型：新功能（儀器伺服器：改名、隱藏、兩台量測電腦同步儀器清單）
- 前一版：1.0.26

## 摘要（貼到版本說明）

- **改名**：儀器伺服器工具列「改名…」（或右鍵），儀器和電磁鐵組都可以改。
  - 一起改：instruments.yaml（保留順序與註解，先備份）、電磁鐵組裡用到它的電源、「量測電腦對應」的電磁鐵組 / VNA 清單。
  - 已連線的會先問要不要中斷（不改變輸出）；量測使用中不能改。
  - 別台量測電腦的儀器：送到那台改（名稱以接著儀器的那台為準，那台要在線）。
  - 量測方案、範本裡寫到舊名稱的地方不會自動改。
- **隱藏**：暫時不用的儀器按「隱藏」收起來；設定保留、照常載入，「全部連線」會略過。
  勾工具列「顯示隱藏的儀器」可以再看到（灰色、標「隱藏」），選取後「取消隱藏」。隱藏電磁鐵組 = 整組收起來。
- **兩台量測電腦同步儀器清單**（經 Hub，另一台沒開也可以）：
  - 在 LAB-1 新增 / 改名 / 隱藏 / 移除儀器，LAB-2 約 15 秒內跟著更新，反之亦然。
  - USB / GPIB 儀器與電磁鐵組：只接在新增的那台；另一台列在那台的群組（`node:` 指定、`synced_from:` 標記），那台在線時可以遠端連線 / 控制。
  - 網路儀器（VNA TCPIP、SHFQC）：兩台都載入；兩台都看得到 = 共用，在儀器伺服器拉到要用的那台。
  - 另一台已經有同一台儀器（同位址）就不重複；同名但不同台的不覆蓋（記在 log）。
  - 需要兩台都以「🛰 量測節點」上線過（和以前一樣，開機自動上線即可）。
- **GS200**：掃描與連線測試顯示「YOKOGAWA GS200（*IDN? 型號碼 GS210）」。GS200 用 `*IDN?` 回報的型號碼就是 GS210，
  兩者是同一台；驅動仍是 `yokogawa.gs200`。

## 設定

- `remote.instrument_sync`（預設 true）：關掉 = 不同步。
- `remote.instrument_sync_s`（預設 15）：多久檢查一次別台的清單。
- 只和「量測電腦對應」（`lab_nodes`）列出的量測電腦同步；沒有設定時和 Hub 上所有實機節點同步（模擬模式的節點不同步）。

## 細節

- `core/instedit.py`：改名（含 sources 參照、lab_nodes、Station 重新載入）、隱藏。
- `core/labfile.py`：`rename_instrument`、`apply_changes`（一次寫入、只備份一次）、寫入互斥鎖。
- `remote/instsync.py`：`plan_sync`（新增 / 改名偵測 / 更新 / 移除 / 交接）與 `InstrumentSync`（節點的 node-sync 執行緒）。
- 節點新指令 `rename_instrument`、`set_hidden`。
- tests/test_instsync.py。
