# Lab Control 0.0.17

- 發佈日期：2026-10-08
- 類型：平台網頁可以直接下載啟動器的 Windows .exe、macOS .dmg
- Python：3.12
- 前一版：0.0.16
- 發佈檔：
  - `LabControlHub_v0.0.17.zip`
  - `LabControlMonitor_v0.0.17.zip`
  - `LabControl_v0.0.17.zip`
  - `QELLauncher_v0.0.17.zip`（啟動器的 Python 版，給 Lab APP 與啟動器自我更新）
  - `QELPlatform_v0.0.17.zip`（啟動器原始碼，用來打包 .exe / .dmg）

## 摘要（貼到 Lab APP「版本說明」）

- 平台網頁「模塊」的量子工程啟動器卡片：
  - 有「⬇ Windows 版」「⬇ Mac 版」下載按鈕；
  - 依你用的電腦，把對的那個標成藍色；
  - Mac 依晶片分別列出（Apple 晶片、Intel）。
- 打包：在 Windows 雙擊 `packaging\build_windows.bat`、在 Mac 雙擊 `packaging/build_macos.command`，
  產生 `QELLauncher_v<版本>_windows.exe`、`QELLauncher_v<版本>_macos-<晶片>.dmg`。
- 發佈：把 .exe / .dmg 丟進 Monitor「發佈中心」，會加到同一版的檔案裡（不會被當成「線上已是這一版」略過）。
- 打包版的啟動器也能自己更新：
  - Windows：下載新的 .exe 換掉自己後重新開啟；
  - Mac：下載 .dmg 並打開，把新版拖到「應用程式」。
- 打包版從桌面 / Finder 開啟時，也找得到電腦上的 Python（官網安裝位置、Homebrew），找不到時會說要去哪裡下載。

## 新增 / 變更

- Hub：
  - 模塊的每個發佈檔多了 `platform`（windows / macos）與 `arch`（arm64 / x86_64 / universal2）；
  - 模塊多了 `downloads`：每個平台 / 晶片最新的安裝檔；
  - `latest` 只算有 zip 的版本：只放了 .exe / .dmg 的版本，啟動器不會拿去安裝；
  - 同一版補上檔案時保留原本的發佈說明。
- 發佈中心：
  - 接受 .exe / .msi / .dmg / .pkg；
  - 用檔名辨識，例如 `QELLauncher_v0.0.17_windows.exe`；
  - 同一版已經有同名檔才略過；
  - 安裝檔排在同一版的 zip 後面發佈。
- 啟動器：
  - 打包版把內附的 qelcomm 複製到 `~/.qel/lib` 給模塊用；
  - Windows 不再閃黑色視窗；
  - macOS 沒有開發者工具時不呼叫 `/usr/bin/python3`（會跳安裝視窗）。
