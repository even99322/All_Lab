# Lab Control 1.0.18

- 發佈日期：2026-10-22
- 類型：新功能（模擬工具 3.3：程式內更新、DXF 編輯器）
- 前一版：1.0.17
- 發佈檔：`LabControlHub_v1.0.18.zip`；模擬工具 `HFSSTool_v3.3_windows.exe`（GitHub 發佈 `hfss-v3.3`）

## 摘要（貼到版本說明）

- **模擬工具會自己更新**（跟量測程式一樣）：開啟時問平台有沒有新版，之後一直等推播；有新版右下角通知、狀態列「⬆ 更新到 x」，
  按「立即更新」下載新的 exe（核對 sha256）→ 關掉 → 換掉同一個檔 → 重開（捷徑、工作列釘選照用）。任務執行中不更新。
- **DXF 編輯器**（主控制面板 DXF 路徑旁「✏ 編輯」）：改板材大小（微波線端點跟著板邊）、用節點畫 / 改微波線（中心線＋線寬，
  轉角斜接）、CPW 自動產生上地（板材 − 微波線＋間隙）、螺絲孔 / 過孔、多邊形 / 矩形，復原 / 重做；顯示 Wave Port 位置與存檔前檢查。
- Hub：`/get/info`、`/get/watch` 多了模擬工具（`hfss`），下載頁也列出它（只有 Windows 版）。
