# Lab Control 0.0.21

- 發佈日期：2026-10-09
- 類型：控制台支援模塊「更新包」；讀檔模塊 2.1.0 讀得到 .nc
- 前一版：0.0.20
- 發佈檔：`LabControlHub_v0.0.21.zip`（另附 `LabLogViewer_v2.1.0_patch.zip`）

## 摘要（貼到 Lab APP「版本說明」）

- 網頁控制台可以發佈模塊的**更新包**：zip 裡只有改過的檔案，加上 `qel-module.json` 寫明 `target`、`version`、`base`。
  - Hub 拿平台上 `base` 版的完整 zip，用更新包的檔案覆蓋，合併成新版的完整 zip 再發佈；
  - 各電腦的 App 照常自動更新；
  - 用途：大的模塊（例如 LabLogViewer 約 230 MB）只要傳幾百 KB。
- 平台上還沒有 `base` 版時，會提示先發佈它。基底 zip 和更新包可以一起拖進來，控制台會先發佈完整 zip。
- 讀檔模塊 LabLogViewer 2.1.0（更新包 `LabLogViewer_v2.1.0_patch.zip`）：直接開 Lab Control 的 `.nc` 檔。
  - 開資料庫、開整個專案時，`.nc` 和 `.hdf5` 一起列出；
  - Viewer 的 1D / 2D / N 維、Marks、分析、匯出都和 Labber 檔一樣能用。

## 變更

- `labhub/packages.py`：`qel-module.json` 有 `target` 與 `base` → 判斷為更新包。`id` 用 `<模塊>-patch`，舊版 Hub 不會把它當成完整新版。
- `labhub/console.py`：
  - 合併更新包，更新包的檔案覆蓋基底 zip 裡同路徑的檔案，資料夾名稱沿用基底；
  - 排序：完整 zip 在更新包前面，版本小的先。
- `labhub/platform.py`：`add_release` 可以直接搬入 Hub 上的大檔；新增 `base_zip()`。
