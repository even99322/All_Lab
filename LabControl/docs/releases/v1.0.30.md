# Lab Control 1.0.30

- 發佈日期：2026-11-09
- 類型：調整（流量統計從 Lab Control 拿掉，改由獨立的「流量監看」程式回報）
- 前一版：1.0.29

## 摘要（貼到版本說明）

- **Lab Control 不再回報網路流量**（1.0.29 加的網卡計數、自我檢查「網路計數」、`remote.report_net` 都拿掉）。
- **新的獨立程式「QEL 流量監看」（QELNetMeter 1.0.0）**：裝在每台電腦，開機（登入）自動在背景執行，
  只在連到實驗室網段（192.168.50.x）時記錄那張網卡的上傳 / 下載，每分鐘把最近 8 天的每日總量送到 Hub。
  Windows 雙擊 .exe 一次就裝好（不需要管理員）、之後自己更新；macOS 用 .dmg。下載頁 /get 與模塊清單多了「流量監看」。
- **Hub「網路用量」頁**（整個 Hub 可以裝成 App 來看）：「各台裝置」改成流量監看程式回報的資料，
  多了目前速率、作業系統；頁面上有下載流量監看程式的按鈕。路由器 Traffic Meter、NAS SNMP 不變。
- 控制台「從 GitHub 取得新版」也會抓 `netmeter-v*` 發佈。

## 細節

- Hub：`POST /api/netusage/report`（流量監看程式回報，不用登入；同一天以程式送來的數字覆蓋，重送不會重複算）。
  1.0.29 由 Lab Control 回報的舊資料不再顯示。
- 流量監看原始碼在 repo 的 `NetMeter/`，GitHub Actions `netmeter.yml` 打包（Windows 自我檢查＋安裝 / 回報 / 解除安裝的端到端測試）。

## 更新步驟

1. Hub 控制台更新到 1.0.30，並「從 GitHub 取得新版」把「流量監看」放上平台。
2. 各台電腦到下載頁裝「流量監看」。Lab Control 更新到 1.0.30（App 內更新即可）。
