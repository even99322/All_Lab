# Lab Control 1.0.1

- 發佈日期：2026-10-13
- 類型：儀器依量測電腦對應的修正（LAB-2 會換成 VNA2）、量完用讀檔程式開 Viewer；讀檔程式 1.0.1（切換 trace 更順、2D 調整不卡）
- 前一版：1.0.0
- 發佈檔：`LabControl_v1.0.1.zip`（功能更新包）與安裝檔、`LabLogViewer_v1.0.1_*`、`LabControlHub_v1.0.1.zip`（只有版本號，可以不發佈）。

## 摘要（貼到版本說明）

- **LAB-2 選方案會換成 VNA2**：以前只有「這台的儀器清單裡沒有」的才換，LAB-2 的清單看得到 VNA1（網路儀器）時就不換。現在知道方案在哪台執行（本機 = 這台；遠端 = 選的節點），別台的電磁鐵組 / VNA 一律換成這台的第幾個。
- **「這台電腦是」**：「🔁 量測電腦對應」最上面可以指定這台是 LAB-1 / LAB-2（電腦名稱和表裡不一樣時用），或「不是量測電腦」。指定後儀器清單也只載入這台的儀器（重新開啟生效）。
- **量完開讀檔程式**：改在主執行緒呼叫讀檔程式（以前從匯出的執行緒呼叫，本機連線常失敗，變成另外啟動一個讀檔程式）；讀檔程式 1.0.1 收到檔案只開 Viewer，不會把資料庫視窗叫出來。
- **讀檔程式 1.0.1**：切換 trace 快很多（座標軸快取、曲線重複使用、快速切換只畫最後一條）；大的 2D 圖改設定時在背景重算，視窗不卡。

## 變更

- `scheme/remap.py`：`mapping(..., node)`、`node_lists`、`current_node`；`workbench/doc.py` `run_node`；`window.local_lab_node`；`remote_mixin` 切換目標時設定 `run_node`。
- `core/nodes.my_names`：加上 settings `lab_node_self`；`node_map_dialog`：「這台電腦是」。
- `monitor_panel.open_reader` 訊號：匯出執行緒 → 主執行緒開讀檔程式；遠端下載完直接在主執行緒開。
- 測試：`tests/test_101.py`。
