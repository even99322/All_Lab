# Lab Control 1.0.35

- 發佈日期：2026-11-13
- 類型：修正（網路用量：路由器跨日的假尖峰）
- 前一版：1.0.34

## 摘要（貼到版本說明）

- **修正路由器流量在午夜多出一根假的尖峰**：路由器 Traffic Meter 的「今天」是在路由器自己的時鐘換日才歸零；
  Hub 以前在台北時間 00:00 換日時，把路由器還沒歸零的前一天累計整筆算成「這兩分鐘」的流量（例如 11 GB 上傳）。
  現在改成：只看計數的差值，計數變小才當作路由器歸零；每日量也由 Hub 自己按台北時間累加。
- 11/13 當天「每日」的路由器數字仍含那一筆（更新後不會再發生）；「即時」的尖峰 25 小時後自動消失。

## 更新步驟

Hub 控制台更新到 1.0.35。Lab Control 不用更新。
