## 摘要（貼到版本說明）

- **曲線像 VNA 面板一樣畫**（即時數據與量測監控一致）：每條 trace = S 參數（量測監控是量測通道）＋ 格式
  （dB Mag、Phase、Smith、Polar、Lin Mag、Unwr Phase、Real、Imag、Delay）。點圖上的 trace 名稱選它，上面的 S 參數 / 格式鍵改的就是它；
  「＋ Trace」加一條（疊在同一張圖，疊不下就放旁邊）。拖 trace 名稱到另一張圖中間 = 疊在一起、拖到邊緣 = 自己一張子視窗；
  拖 ⠿ = 整張圖；右鍵 trace 名稱 = 換 S 參數 / 格式、分開、刪除。好幾個 S 參數一次掃描一起讀。Smith 圖有等電阻 / 等電抗格線。
- **量測監控**：曲線跟即時數據用同一套 trace；影像畫「目前的 trace」的通道與格式（點左邊的通道也會換）。
- **手動步進預設一直重複量測**：每一點一進來就循環量測，按「記錄並下一點」前進；「⏹ 停止循環」可以停（`run_defaults.manual_loop`）。
- **只顯示有接線的 port**：VNA 一連線就用目前的設定把全部 S 參數（4 port = 16 個）掃一次，即時數據只留有接線的組合
  （穿透 |S| 中位數高於 −60 dB 的 Sij，以及那些 port 的 Sii）。其他的在「儀器伺服器 → 右鍵 VNA → S 參數顯示…」可以打開或重新掃描；
  即時數據的「掃描 port」也會重新掃。
- **子專案**：論文庫的專案可以建子專案（一層一層嵌套）。量測程式的「論文庫專案」選了有子專案的專案，右邊會多一個選單
  （放不下就換到下一行，名稱不會被擠掉），可以一直選下去；「＋子」在目前的專案底下建子專案。數據存到
  `數據集散地/主專案/子專案/…/yyyy/mm/Data_mmdd`，Hub 的專案資料夾也照這個階層。讀檔程式 1.0.6 的專案選單一樣可以一層一層選。
