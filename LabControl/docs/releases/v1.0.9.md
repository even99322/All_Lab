# Lab Control 1.0.9

- 發佈日期：2026-10-14
- 類型：修正（量測程式更新時當掉、安裝成 App 的提示）
- 前一版：1.0.8
- 發佈檔：`LabControl_Setup_v1.0.9.exe`、`LabControlHub_v1.0.9.zip`

## 摘要（貼到版本說明）

- **量測程式按「更新」關閉時跳出錯誤**（`AttributeError: 'NoneType' object has no attribute 'flush'`，app.py 第 159 行）：
  視窗版沒有主控台，結束時清空輸出就當掉了。改好了；這個錯誤發生在「舊版關閉」那一刻，所以從 1.0.8 或更早更新到 1.0.9 時
  可能還會再看到一次，按掉即可，安裝會照常進行。
- **認得「這台已經裝好了」**：已經裝過「量子工程」App 的電腦，瀏覽器不會再給安裝按鈕；之前頁面會說「這個瀏覽器沒有提供一鍵安裝」，
  現在改成「✓ 這台已經裝好了」，並說明按網址列右邊的「在應用程式中開啟」圖示（方框加箭頭）就能切到 App。導覽列顯示「✓ 已安裝 App」，
  首頁不再出現安裝提示。
- **Edge 的安裝位置更新**：新版 Edge 在「… → 更多工具 → 應用程式 → 將此網站安裝為應用程式」（舊版在 … 選單第一層）。

## 變更

- `manifest.webmanifest`：`related_applications`（`webapp`，自己的 manifest），網頁用 `navigator.getInstalledRelatedApps()` 判斷已安裝；
  另外在 App 裡開過、或 `appinstalled` 時記在 `localStorage qel.installed`，瀏覽器又提供安裝（`beforeinstallprompt`）時清掉。
- `install.html`：已安裝狀態、Edge / Chrome 步驟補「已裝好時網址列的圖示」。
- `labcontrol/app.py`：`flush_streams()`，`sys.stdout` / `sys.stderr` 是 None 時略過。
- 測試：`tests/test_108.py`。
