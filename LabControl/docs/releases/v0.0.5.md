# Lab Control 0.0.5

- 發佈日期：2026-09-30
- 類型：功能版本（遠端量測）
- Python：3.12
- 前一版：0.0.4

## 摘要（貼到 Lab APP「版本說明」）

遠端量測：量測電腦按「🛰 量測節點」上線，其他電腦在工具列「執行於」選該節點，就能用節點的儀器設計方案、在節點上量測、即時看進度與曲線、暫停 / 停止。
以 NAS 共用資料夾（\\192.168.50.2\ccuqel 或 VPN \\100.114.33.20\ccuqel 的 LabControl\remote）當基站，NAS 不用安裝任何服務，也不需要存密碼。
任何人用新版開啟時會自動請較舊的量測節點更新（量測中會等結束）。設定與說明見 docs/REMOTE.md。

## 新增

- **量測節點**（`labcontrol/remote/node.py`）：心跳、接收指令、上傳即時事件；同時只跑一個量測；
  遠端開始 / 設定 / 更新可在 `settings.yaml remote.node` 關閉或限定使用者；停止、暫停任何人可按；同名節點重複上線會被拒絕。
- **NAS 基站**（`labcontrol/remote/hub.py`）：共用資料夾交換 JSON（原子寫入）；依序嘗試區網、VPN；`LAB_CONTROL_HUB` 可指定。
- **控制端**：主視窗「執行於」選節點 → 儀器參數列表與方案檢查換成節點的儀器（模擬鏡像）、取值 / 設定值作用在節點、
  ▶ 開始量測在節點執行、即時監控顯示節點資料並可控制；狀態列顯示 NAS 連線狀態。
- **自動更新節點**：開啟時比較版本，請較舊的節點更新；節點從 NAS `Releases\LabControl\v<版本>` 複製新版、
  沿用或建立 Python 環境、以同樣參數重新啟動（`labcontrol/remote/updater.py`）；量測中延後。
- **NAS 登入**（「設定 ▾ → NAS 登入…」）：密碼交給 Windows 認證管理員保存，Lab Control 不存密碼。
- `python main.py --node`、`settings.yaml remote.node_enabled`；命令列 `python -m labcontrol node`、`nodes [--update]`。
- 文件 `docs/REMOTE.md`（NAS 設定、使用方式、更新流程、安全）。
