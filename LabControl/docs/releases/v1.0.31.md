# Lab Control 1.0.31

- 發佈日期：2026-11-09
- 類型：新功能（磁場校正、重複 N 次方塊、Yokogawa 預設電流模式、Hub 電子實驗記錄）
- 前一版：1.0.30

## 摘要（貼到版本說明）

- **磁場校正（YIG 共振反推）**：量一張「電流 × 頻率」的 YIG FMR 圖（.nc），在「設定 → 磁場校正（YIG 共振）…」
  （或儀器伺服器電磁鐵右鍵）選檔，自動找每個電流的共振頻率，用 Kittel 式 f = γ′(B + B_a)（γ′ 預設 28.0 GHz/T）
  反推磁場，再擬合 B(I) 多項式（自動剔除離群點，也可以在圖上點掉）。存檔後電磁鐵多一個「磁場」參數（mT / Oe），
  量測方案可以直接掃磁場，程式自己換算成電流；超出校正範圍會警告。
- **Yokogawa（GS200 / GS610 / GS820）連線時預設切到電流模式**（`server.yokogawa_function: CURR`；某台要保持原樣：
  instruments.yaml 那台的 `on_connect: {function: keep}`）。
- **新方塊「🔁 重複 N 次」**（流程分類）：單純把裡面的東西重複 N 次，可設每次之間等待幾秒；資料多一個 Repeat 軸
  （1…N）。網頁「量測設置」也有。
- **Hub 新頁面「實驗記錄」（/notebook）**：電子實驗記錄本——標題、Markdown 內文（截圖直接貼上、拖曳附檔）、
  標籤、所屬專案（論文庫主 / 子專案）、連結（數據檔、論文、網址、其他記錄）、作者與時間、每次儲存留一版的修改歷史
  （可以還原）、留言、共同編輯者（同時編輯會提醒，後存的人看得到衝突）、搜尋與篩選、勾選幾筆一起列印 / 另存 PDF。
- **量測自動寫入實驗記錄**：Lab Control 量測存完檔，自動在「實驗記錄」新增一筆（方案、狀態與點數、時間、掃描範圍、
  量測儀器與設定、固定設定、存的檔、標籤、專案），量測者之後補寫備註。關掉：settings.yaml `notebook.auto: false`。

## 細節

- 磁場校正存在 instruments.yaml 那台電磁鐵的 `field_cal`（係數、範圍、γ′、擬合品質），兩台量測電腦會同步。
- 單位多認得 Oe、kOe、Gs（換算成 T）。
- 實驗記錄存在 Hub 的 `data/notebook/`（每筆一個 JSON、附檔各自的資料夾）；刪除會移到 `data/notebook/trash/`。
  權限：任何登入的人可以看與留言；作者、共同編輯者、站長可以改；量測自動新增的記錄任何人都可以補寫；
  作者或站長可以刪除。附檔上限 25 MB；SVG / HTML 之類的附檔一律下載、不在網頁打開。
- API：`/api/notebook`（清單、搜尋、新增）、`/api/notebook/<id>`（讀、改、刪）、`/history`、`/comments`、`/files`、
  `/editing`、`POST /api/notebook/auto`（量測電腦）。
- 同一次量測（run_id）只會有一筆；背景量測不另外記。

## 更新步驟

1. Hub 控制台更新到 1.0.31（導覽列多了「實驗記錄」）。
2. Lab Control 更新到 1.0.31（App 內更新即可）。
3. 要用磁場校正：先量一張 YIG 的電流 × 頻率圖，再開「設定 → 磁場校正（YIG 共振）…」。
