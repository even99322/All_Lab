# Lab Control 1.0.7

- 發佈日期：2026-10-14
- 類型：功能（平台網頁改版、網頁量測設置、每點重複量測＋QC 挑選）；讀檔程式 1.0.5
- 前一版：1.0.6
- 發佈檔：`LabControl_Setup_v1.0.7.exe`、`LabControlHub_v1.0.7.zip`；讀檔程式 `LabLogViewer 1.0.5`

## 摘要（貼到版本說明）

- **平台網頁 `http://<NAS>:8765` 改版**：一律先登入；上方導覽是「模塊下載、數據查看、量測查看、量測設置」（站長另有控制台、帳號與權限，
  論文庫是連結）。原本的「專案、數據、標籤與論文」頁拿掉了。每一頁都可以直接用網址開：`/data`、`/live`、`/setup`。
- **數據查看**：瀏覽數據集散地、搜尋、看預覽與截面；在電腦上按「📖 用讀檔程式開啟」直接在讀檔程式打開那個檔（讀檔程式 1.0.5）。
- **量測設置**（網頁）：
  - 每台量測電腦的狀態、儀器連線與目前值；量測中可以暫停 / 繼續 / 停止。
  - 從量測電腦的範本開始，改掃描範圍、VNA 設定、檔名、每點重複次數、背景＋去背，「檢查方案」後直接送到那台開始量測。
  - 量測電腦對應（每台的電磁鐵組與 VNA）與 instruments.yaml：大家都看得到，站長可以修改（先備份成 .bak）。
- **每點重複量測＋QC 挑選**（移植自電磁鐵異步量測工具 v3）：「執行」分頁「每點重複量測」> 1，或手動步進勾「保留此點所有暫存」；
  量完自動打開 QC 視窗——每個保留點列出每一筆 trace 的 Mag / Jump / Slope 是否達標，看 Magnitude、Phase、IQ 象限圖，打星號、
  「每點選最佳」或「全部用最後一筆」，按「完成 QC」才存檔。量測中也可以按「👀 檢視 / 挑選保留數據」先挑。
- **讀檔程式 1.0.5**：2D 色階清單有預覽、可以反轉與自訂顏色；「完整範圍」；X / Y 截面分開、在圖上打開；強度直方圖收進「對比」按鈕。

## 變更

- `labhub/web_nav.py`（共用導覽）、`labhub/setup_routes.py`、`static/setup.html`；`/` 與 `/get` 頁要登入（`/get/info`、`/get/feed`、
  安裝檔下載照舊不用登入，程式自動更新要用）；`/nodes` → `/setup`（舊頁 `/nodes?old=1`）；`/live`、`/data` 與 `/m`、`/m/data` 相同。
- Hub 送給量測電腦的指令帶登入者帳號與站長身分（裝置 token 不能自稱站長）。
- 量測電腦新指令：`catalog`、`templates`、`check_scheme`、`instruments_file`、`save_instruments`（站長）、`save_lab_nodes`（站長）；
  `settings.yaml remote.node.allow_remote_config` 可以關掉遠端改設定。
- `RunOptions.repeat_shots`（`run_defaults.repeat_shots`）；`labcontrol/apps/qt/workbench/qc_window.py`（QCWindow）；量測監控的「檢視 / 挑選保留數據」。
- 測試：`tests/test_107.py`。
