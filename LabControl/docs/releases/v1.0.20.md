# Lab Control 1.0.20

- 發佈日期：2026-10-22
- 類型：新功能（授權頁直接讀授權伺服器；模擬工具 3.5）
- 前一版：1.0.19
- 發佈檔：`LabControlHub_v1.0.20.zip`；模擬工具 `HFSSTool_v3.5_windows.exe`（GitHub 發佈 `hfss-v3.5`）

## 摘要（貼到版本說明）

- **「授權」頁直接讀授權伺服器（跟 lmstat 一樣準）**：站長在頁面上方填授權伺服器（例如 `1055@<區網 IP>;1055@<VPN IP>`，依序試），
  Hub 每 30 秒請一台開著模擬工具 3.5 的電腦跑 Ansys 內附的 `lmutil lmstat -a -c`，把輸出送回 Hub 解析。
  沒裝模擬工具的電腦在用授權也看得到：每台電腦 / 使用者占了哪些授權、HFSS 求解幾個、HPC 幾核、已經用多久；上方顯示
  Electronics Desktop、HFSS 求解、HPC 的「使用中 / 總數」。預設只看 Electronics / HFSS 相關，展開「所有授權」看全部。
- 標註跟原本共用（同一台電腦＋使用者），沒裝工具的電腦也能標註。
- **模擬工具 3.5**：自動找 `lmutil.exe`（`AWP_ROOTxxx`、`C:\Program Files\ANSYS Inc\v*\licensingclient\winx64\`），找不到可在
  `update.json` 填 `lmutil`；背景執行、不跳視窗；這台查不了平台會改請別台。

## 更新步驟

1. 平台：控制台「從 GitHub 取得新版」→ 發佈 1.0.20 →「授權」頁填授權伺服器（站長）。
2. 實驗室電腦：模擬工具會跳出更新通知 → 立即更新到 3.5（至少一台開著，平台才查得到伺服器）。
