# Lab Control 1.0.8

- 發佈日期：2026-10-14
- 類型：功能（平台網站裝成 App）；只需要更新 Hub，量測與讀檔程式不用動
- 前一版：1.0.7
- 發佈檔：`LabControl_Setup_v1.0.8.exe`、`LabControlHub_v1.0.8.zip`

## 摘要（貼到版本說明）

- **平台網站可以裝成 App**（跟論文庫一樣用瀏覽器「安裝應用程式」）：模塊下載、數據查看、量測查看、量測設置都在同一個「量子工程」App 裡，
  從桌面、Dock、開始選單或手機主畫面直接開，沒有網址列。
- 導覽列多了「⬇ 安裝 App」，首頁上方有「把平台裝成 App」提示（可以關掉）；`/install` 頁會認出你用的裝置，一鍵安裝或照步驟裝：
  - **Windows / Mac**：Chrome「⋮ → 投放、儲存及分享 → 將網頁安裝為應用程式」、Edge「… → 應用程式 → 將此網站安裝為應用程式」、
    Mac Safari「檔案 → 加入 Dock」（macOS 14 以上）。
  - **Android**：Chrome「⋮ → 安裝應用程式 / 加到主畫面」。
  - **iPhone / iPad**：Safari「分享 → 加入主畫面」。
- App 有正式圖示（含 Android 的可裁切圖示、iPhone 主畫面圖示）與捷徑（數據查看、量測查看、量測設置）。
- 連不到 Hub 時（沒連實驗室網路或 VPN），App 顯示上次看過的畫面或「連不到實驗室的 Hub」，不會是空白頁（https 網址才有）。
- Hub 用 https 網址（例如 Tailscale `tailscale serve` 或 DSM 反向代理）時，Chrome / Edge / Android 會直接跳出「安裝」按鈕；
  一般 http 網址也能照步驟裝。

## 變更

- `labhub/static/manifest.webmanifest`：`id`、PNG 圖示 192 / 512 / maskable 512、`shortcuts`；新圖示 `app-icon-{32,180,192,512,maskable-512}.png`，
  `/favicon.ico`、`/apple-touch-icon.png` 也有。
- `labhub/web_nav.py`：`with_head()` 在每一頁（含登入頁、下載頁）補上 manifest、theme-color、iOS 加入主畫面的標籤與 App 腳本
  （`window.qelApp`：攔 `beforeinstallprompt`、一鍵安裝、註冊 `/sw.js`）；舊的 `/m` 手機 manifest 不再掛在頁面上（路由保留給舊的捷徑）。
- `labhub/static/sw.js`（`qel-app-v2`）：頁面先走網路、留最後一份；`/api/`、登入、下載一律不快取。
- `labhub/static/install.html`（`/install`，要登入）；`portal.html` 首頁的安裝提示與「⬇ 安裝 App」卡。
- `pyproject.toml`：`labhub` 的 `static/*` 全部打包（之前只有 `*.html`）。
- 測試：`tests/test_108.py`。

## 升級

- NAS：照平常更新 Hub（控制台上傳 `LabControlHub_v1.0.8.zip`，或換掉 `labhub` 資料夾後重啟容器）。
- 已經用 `/m` 加到主畫面的手機捷徑照樣能用；想換成新的 App，刪掉舊捷徑後到 `/install` 重新裝一次。
