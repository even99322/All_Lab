# Lab Control 1.0.29

- 發佈日期：2026-11-09
- 類型：新功能（Hub「網路用量」：每天用了多少流量）
- 前一版：1.0.28

## 摘要（貼到版本說明）

Hub 導覽列多了「網路用量」（/network），每天的上傳 / 下載，三個來源：

1. **整個網段**：讀 Netgear 路由器（RAX200）的 Traffic Meter，每 10 分鐘一次。
   路由器換日後以它的「昨天」最終數字為準；也顯示本月、上個月合計。
2. **NAS（192.168.50.2）**：SNMP 讀網路介面的 64 位元計數，每分鐘累加。自動挑實體網路（bond > ovs_eth > eth，不重複算）。
3. **各台電腦**：Lab Control 1.0.29 以上連上 Hub 後，定期回報網卡總計數（只算實體網卡，不算 VPN / 虛擬網卡），
   Hub 算成每台每天用量；可以標註是誰的電腦。只算 Lab Control 開著的時間；包含區網內傳檔（例如上傳數據到 NAS）。

每日長條圖（下載 / 上傳疊起來）、今天 / 昨天 / 近 7 天 / 本月、各台電腦近 14 天小圖；可選最近 14 天到一年。資料留 400 天。

## 第一次設定（站長，在「網路用量」頁最下面「設定」）

- **路由器**：
  1. 路由器管理頁（http://192.168.50.1，或 routerlogin.net）→「進階 → 進階設定 → 流量計量器」打開流量計量。
  2. 填位址、管理帳號（通常 admin）、管理密碼，勾「啟用」→「儲存並測試」。連接埠留空會自動試 5000 / 80 / 443 / 5555。
  3. 密碼只存在 Hub 資料夾（data/netusage_secret.json），網頁和 API 都不會回傳。
- **NAS**：
  1. DSM「控制台 → 終端機與 SNMP → SNMP」：勾「啟動 SNMP 服務」與 SNMPv1/v2c，設定社群名稱。
  2. 填 NAS 位址（192.168.50.2）與同樣的社群名稱，勾「啟用」→「儲存並測試」；測試結果會列出統計哪些介面。
- **各台電腦**：不用設定，更新到 1.0.29 即可（不想回報：settings.yaml `remote.report_net: false`）。

## 限制

- RAX200 沒有可靠的「每台裝置」流量統計，所以手機等沒裝 Lab Control 的裝置只算在「整個網段」裡。
- 路由器數字以 1 MB = 1024² byte 換算。
- 電腦超過 2 小時沒回報，那段時間的流量不算（不知道是哪天用的）。

## 細節

- `labhub/netusage.py`：Netgear SOAP（SOAPLogin → GetTrafficMeterStatistics）、SNMP v2c GET / GETNEXT（標準函式庫）、
  每日用量存 data/netusage.json；`labhub/static/network.html`。
- `labcontrol/remote/netcount.py`：網卡計數（psutil；沒有就 Windows GetIfTable2 / macOS netstat -ibn / Linux /proc/net/dev），
  放進 Lab Control 的定期回報與量測節點狀態。安裝檔不用換套件，功能更新包即可更新。
- 自我檢查多一項「網路計數」。
- tests/test_netusage.py。

## 更新步驟

2. 各台電腦的 Lab Control 更新到 1.0.29（App 內更新即可）。
