## 摘要（貼到版本說明）

- **「🔁 量測電腦對應」**（流程圖工具列、儀器伺服器工具列）：在程式裡設定，不用手改檔案。
  - 上半部：每台量測電腦的電磁鐵組與 VNA（依序）。預設 LAB-1：magnet_A、magnet_B、VNA1；LAB-2：magnet_C、magnet_D、VNA2。
    方案在另一台執行時，「第幾個」對到「第幾個」。存在 `settings.yaml` 的 `lab_nodes`，所以這台的 instruments.yaml 不需要有別台的儀器。
  - 下半部：每台儀器接在哪台（`instruments.yaml` 的 `node:`），下拉選 LAB-1 / LAB-2 / 兩台都有 / 不指定；電磁鐵組跟著它的電源。存檔前留 `instruments.yaml.bak`。
- **舊的 instruments.yaml 自動補上 node:**（只在檔案裡還沒有任何 `node:` 時做一次，留 `instruments.yaml.bak-0.0.32`）：
  - DC1–DC4（序號 90ZC38697、90ZC38696、9017D5818、9017D5816）、VNA1（192.168.1.11）→ LAB-1；
  - VNA2（192.168.1.12）→ LAB-2；SHFQC → LAB-1、LAB-2；
  - 其他儀器（例如 LAB-2 的電源）不動，請在「量測電腦對應」或儀器伺服器「移到群組…」設定。
- LAB-2 的電磁鐵組：在 LAB-2 開「儀器伺服器 → ＋ 電磁鐵組…」選兩個電源建立（名稱用 magnet_C、magnet_D 就會直接對上預設的對應）。
