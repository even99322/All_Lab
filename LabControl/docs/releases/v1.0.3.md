# Lab Control 1.0.3

- 發佈日期：2026-10-13
- 類型：修正（更新後工作列的釘選失效）；讀檔程式 1.0.2（用 VPN 開大資料夾不再卡住）
- 前一版：1.0.2
- 發佈檔：`LabControl_v1.0.3.zip`（功能更新包）與安裝檔、`LabLogViewer_v1.0.2_*`、`LabControlHub_v1.0.3.zip`（只有版本號，可以不發佈）。

## 摘要（貼到版本說明）

- **更新後工作列的釘選不再失效**：Lab Control 在 Windows 上的程式 ID 以前帶版本號（`LabControl.1.0.2`），每次更新 Windows 就當成另一個程式，釘選的圖示變成另一顆沒有釘選的。現在固定為 `CCUQEL.LabControl`，安裝程式建立的捷徑也帶同一個 ID。**更新到 1.0.3 之後要再釘選一次**（把舊的取消釘選、在執行中的 Lab Control 上按右鍵 → 釘選到工作列），之後的更新就不會再掉。Monitor 也一樣（`CCUQEL.LabControlMonitor`）。
- **讀檔程式 1.0.2：用 VPN 開大資料夾不再卡住**：掃完檔案後不再在畫面的執行緒上把整個 NAS 資料夾再走一遍（VPN 下會卡幾十秒到幾分鐘，常被強制關閉，下次開啟進入安全復原模式）；網路磁碟同時列出多個資料夾；點選數據時註解在背景讀取、檔案身分記起來、預覽用清單的大小與時間；自動更新清單較省網路。

- `labcontrol/app.py`：`APP_USER_MODEL_ID = "CCUQEL.LabControl"`；`labmonitor/app.py`：`CCUQEL.LabControlMonitor`。
