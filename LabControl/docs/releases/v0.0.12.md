# Lab Control 0.0.12

- 發佈日期：2026-10-01
- 類型：量測方案範本、多個存檔方塊、電流異步、即時監控（精簡 / 獨立視窗疊圖、雙 Y 軸、marker）
- Python：3.12
- 前一版：0.0.11
- 發佈檔：`LabControl_v0.0.12.zip`、`LabControlMonitor_v0.0.12.zip`、`LabControlHub_v0.0.12.zip`（Hub 只有版本號改變，不一定要更新）

## 摘要（貼到 Lab APP「版本說明」）

- 量測方案新增 4 個範本，放在「範本 ▾」最上面：

  | 範本 | 做什麼 |
  |---|---|
  | 單張 | 直接量一次 VNA，電流沿用目前的值 |
  | 2D | 設定電流 → 量測 VNA |
  | 2D 電流異步 | 兩台交錯設定電流 → 量測 VNA，與舊 sweep_main 的 DC 異步相同 |
  | N 層量測 | 3 層範例：磁鐵 A × 磁鐵 B × VNA 功率 |

- 可以放多個 Data（存檔）方塊：每個 Data 各自決定分檔方式、檔名、格式。例如外圈每個值存一個檔，另外再存一個完整的檔。
- 主視窗右上的「即時監控」只顯示 dB 曲線和「量測 / 循環」。電源群組、VNA 參數等其他功能在「⧉ 獨立視窗」。
- 獨立視窗的曲線：
  - 「疊圖」：同一張圖、左右兩個 Y 軸，最多兩種單位，例如 dB 和 Linear 用左軸、Phase 用右軸；
  - 拖曳曲線 = 上下移動那條曲線；
  - 在軸上拖曳 = 縮放那個軸；
  - 雙擊 = 加 marker，可以加很多個，下方列出每個 marker 的頻率與各曲線的值。
- 修正：遠端節點的即時監控讀取，有時因為節點正在執行慢指令（例如全部連線）而逾時「沒有回應（20 s）」。

## 新增

### 量測方案範本（`labcontrol/defaults/templates/01_*.scheme.yaml`～`04_*`）

- **單張**：只有量測方塊與 Data，沒有迴圈，所以量一次。
- **2D**：磁鐵 A 從 100 掃到 150 mA，每步 0.5 mA，存一個檔。設定的值在 1 µA 網格上，所以兩台電源同時設成相同的值。
- **2D 電流異步**：磁鐵 A 掃描節點勾選「電流異步」，步進 = 每台每次前進的電流。
  - 每一點只有一台前進：DC3 +步進 → 量測 → DC4 +步進 → 量測 → …（A 先走），平均電流每點走步進的一半，與舊 sweep_main 相同；
  - 範例：每台步進 0.01 mA，從 150 到 152 mA，共 401 點。
- **N 層量測**：
  - 3 層巢狀迴圈：磁鐵 A（外）× 磁鐵 B × VNA 功率（內）；
  - 兩個 Data：一個每個 A 值存一個檔，另一個存完整的檔；
  - 加層：把參數拖進迴圈的「每一點 ⟲」；減層：刪掉那個掃描節點。
- 預設開啟的範本改為「2D」（`settings.yaml app.default_template: 02_2d`）。
- 原本的「單磁鐵電流掃描」（`single`）已由「2D」取代，其他舊範本保留。

### 電流異步（Step 設定）

- Step 設定視窗多了一個勾選框「電流異步（兩台交錯）」。目標是兩台交錯的電磁鐵組（`virtual.interleaved_pair`）時才會出現。
- 勾選後：
  - 「步進」改叫「每台步進」；
  - 只能用步進設定，不能用點數；
  - 預覽會顯示平均每點走多少。
- 實作：
  - `virtual.interleaved_pair` 新增 `interleave_step` 和 `interleave_origin` 兩個參數（交錯網格）。量測方案每次開始前都會明確設定這兩個值；
  - 異步時，網格 = 每台步進、原點 = 起點；其他情況 = 0，也就是用 resolution，兩台同步；
  - 掃描軸的步進是每台步進的一半。

### 多個 Data（存檔）方塊

- 一個方案可以放多個 Data 節點，每個 Data 放的位置決定它自己的分檔方式。
- 第一個 Data（主要）的檔名、資料夾、格式、Labber 設定在右下「檔案設置」，與以前相同。
- 第二個以後的 Data：雙擊開啟設定，可以設檔名、格式（Labber / HDF5）、同名處理。流程圖上顯示「Data（額外）」和它的檔名。
- 右下「檔案設置」會列出每個額外 Data 存什麼；預估檔案數也包含額外 Data。
- 設定格式：`output.extra: [{file_name, collision, split_by, export}]`。Experiment 會為每個輸出建立自己的分段匯出。

### 即時監控

- **主視窗（精簡）**：只有 dB 曲線、「▶ 量測」「循環」。按「⧉ 獨立視窗」才會出現電源群組、VNA 參數、曲線種類等。放回主視窗時又變回精簡。
- **獨立視窗的曲線**：
  - 「疊圖（同一張、左右兩軸）」：
    - 第一種單位用左軸，第二種單位用右軸；
    - 單位群組：dB / 線性（Linear、Real、Imag）/ 角度（Phase、Unwrap）；
    - 要加第三種單位時會提示；IQ 只在分開的圖裡顯示。
  - **拖曳曲線**上下移動：圖例會顯示偏移量，marker 讀數不受影響；「重設偏移」歸零。
  - **在軸上拖曳**縮放那個軸：往上 / 往右拖 = 放大；左右 Y 軸各自縮放，下方頻率軸縮放頻率。滾輪照常縮放；「自動範圍」恢復。
  - **marker**：
    - 雙擊加一個 marker，可以加很多個；IQ 圖上雙擊會取最近的量測點；
    - marker 可以拖曳，在 marker 上按右鍵刪除；「清除 Marker」全部刪除；
    - 下方列出每個 marker 的頻率，以及各曲線在那個頻率的值（IQ 顯示 Re + jIm，並在 IQ 圖上標點）。
  - 分開模式（九宮格）的每張圖也都支援以上操作。
- 按鈕改名：「⟳ 讀取」→「▶ 量測」、「連續」→「循環」。

### 節點

- 即時監控的讀取 / 控制指令（get、describe、get_all、sources、vnas、vna_catalog、vna_trace、fine_step、output、group_ramp）改由另一條佇列處理。不會排在「全部連線」「開始量測」這類慢指令後面而逾時。

## 修正

- `run_bg`（背景執行）改用單一常駐的轉送物件，不再每次建立 QObject。舊做法偶爾出現「wrapped C/C++ object of type _Relay has been deleted」，Monitor 的 `labmonitor/bg.py` 也一併修改。
- 測試偶發 segfault 的根本原因：各測試的 `QApplication` 只存在區域變數裡，測試結束就被銷毀。`tests/conftest.py` 改成整個測試期間只保留一個 QApplication。程式本身不受影響，因為主程式的 QApplication 一直存在。
- 工具列「▶ 開始量測」改為自己建立的按鈕，不再從工具列取回 Qt 內部的按鈕。
