# Lab Control 1.0.4

- 發佈日期：2026-10-14
- 類型：功能（NAS 上的數據索引、手機看即時量測）；讀檔程式 1.0.3
- 前一版：1.0.3
- 發佈檔：`LabControl_v1.0.4.zip`（功能更新包）與安裝檔、`LabControlHub_v1.0.4.zip`（**要更新**：索引程式與手機網頁都在裡面）、
  `QELPlatform_NAS_v1.0.4.zip`（新的 docker-compose.yml）、`LabLogViewer_v1.0.3_*`。

## 摘要（貼到版本說明）

- **NAS 先算好每個檔的資訊與預覽**：NAS 上新的「數據索引」容器用讀檔程式自己的解析程式，把數據集散地每個檔的名稱、建立時間、
  掃描維度、Tag、Star 與預設預覽先算好（新的檔先做，之後只做新增 / 改過的檔）。讀檔程式 1.0.3 開數據集散地裡的資料夾時，
  一次向 Hub 拿整個資料夾的資訊、點選時拿算好的預覽，不必隔著 VPN 開檔或複製檔案。
- **手機看即時量測**：手機瀏覽器開 `http://192.168.50.2:8765/m`（VPN：`http://100.114.33.20:8765/m`），用論文庫帳號登入。
  看得到每台量測電腦的狀態、進度、剩餘時間與預計完成時間、目前設定值、熱圖（目前這一段外圈）、最後一條 trace 與最低點、紀錄；
  點圖可以看數值。Android（Chrome）、iPhone（Safari）都可以「加到主畫面」，像 App 一樣開。
  量測電腦要用 Lab Control 1.0.4（自動送；設定 `remote.mobile_live: false` 可以關掉）。

## NAS 要做的事（一次）

1. Monitor「發佈中心」或 Hub 控制台上傳 `LabControlHub_v1.0.4.zip`。
2. 在數據集散地裡建一個資料夾 `.qel`（Windows：`\\192.168.50.2\ccuqel\數據集散地` → 新增資料夾 → 名稱 `.qel`）。
3. 用 `QELPlatform_NAS_v1.0.4.zip` 裡的 `docker-compose.yml` 換掉 `docker/QELPlatform/docker-compose.yml`
   （或只把 `indexer:` 這段、`agent` 的 `INDEXER_CONTAINER` 加進去）；數據集散地不在 `/volume1/ccuqel/數據集散地` 時改路徑。
4. Container Manager → 專案 `qelplatform` →「建置」。第一次啟動會安裝 numpy、h5py（NAS 要能上網），然後開始索引。
5. 進度：`http://192.168.50.2:8765/api/index/status`（登入後）。

## 變更

- `labhub/indexer.py`（新，`python -m labhub.indexer`）：走數據集散地（跳過 `.`、`@eaDir`、`#recycle` 等）、解析新的 / 改過的檔、
  預覽存成 `data/index/previews/*.npz`、結果在 `data/index/index.sqlite`；60 秒內改過的檔下一輪再做；讓程式當掉的檔記為錯誤、跳過；
  存取鑰匙 `data/index/share_key` ＋ 數據集散地 `.qel/index_key`。
- `labhub/llvcore/`（新）：讀檔程式解析核心的複本；`tools/sync_llvcore.py` 從讀檔程式更新（測試檢查兩邊一致）。
- `labhub/index_codec.py`：預覽格式（2D 最多 800 × 400、1D 4000 點，縮小時保留離中位數最遠的值：窄的 dip 不會消失）。
- `labhub/index_routes.py`：`/api/index/status`、`/tree`、`/preview`（登入 / 裝置 token，或 `X-QEL-Share-Key`）。
- `labcontrol/remote/live_publish.py`：量測摘要每秒送到 Hub（不在量測執行緒做事）；`RemoteManager` 啟動，名稱 = 量測節點 /
  量測電腦對應（LAB-1…）/ 量過才用電腦名稱。
- `labhub/mobile_routes.py`、`static/mobile.html`、`mobile.webmanifest`、`m-icon-*.png`：`/m`、`/api/m`。
- `labhub/agent.py`：Hub 更新 / 回到舊版後重新啟動數據索引容器。
- `deploy/platform/docker-compose.yml`：`indexer` 服務。
- 測試：`tests/test_104.py`。
