# Lab Control 0.0.22

- 發佈日期：2026-10-10
- 類型：儀器歸屬哪台量測電腦；VNA 偵測 port
- 前一版：0.0.21
- 發佈檔：`LabControlHub_v0.0.22.zip`

## 摘要（貼到 Lab APP「版本說明」）

- `instruments.yaml` 每台儀器可以寫 `node: LAB-1`，標明它接在哪台量測電腦。
  - 量測電腦只載入、只連線自己的儀器：LAB-2 不會再列出 LAB-1 的 USB 電源 DC1–DC4（也不會出現 `VI_ERROR_RSRC_NFOUND`）；
  - 別台的儀器顯示在那台的群組；magnet_A / magnet_B 跟著它們的電源；
  - 兩台都可能用的寫 `node: [LAB-1, LAB-2]`（共用，拉到誰的群組誰用）；
  - 不想改檔案：在儀器伺服器把 USB 儀器拖到它接著的那台群組，自動寫入 `node:`；拖回來改成這台。
  - 客戶端電腦照樣全部列出（編輯、模擬不受影響）。
- VNA 自動偵測 port（`INST:PORT:COUN?`，不支援時看型號 ZNA26-4Port）：4 port 可量 S11…S44，例如 S31、S43。
  - 即時監控的 S 參數按鈕依 port 數排成矩陣，ZNA 上已有 trace 的用粗體；
  - 新的「**偵測 port**」按鈕（即時監控、儀器伺服器控制視窗的 trace 分頁）；
  - 量測方案的 VNA 方塊也列出全部 S 參數；ZNA 上沒有的 trace 量測時自動建立（LC_S31）。

## 你們實驗室的設定（兩台量測電腦共用的 instruments.yaml）

```yaml
  DC1: {..., node: LAB-1}
  DC2: {..., node: LAB-1}
  DC3: {..., node: LAB-1}
  DC4: {..., node: LAB-1}
  VNA1: {..., node: LAB-1}
  DC5: {..., node: LAB-2}
  DC6: {..., node: LAB-2}
  DC7: {..., node: LAB-2}
  VNA2: {..., node: LAB-2}
  SHFQC1: {..., node: [LAB-1, LAB-2]}
```

兩台量測電腦都改好後重新開啟 Lab Control（或在 App 重新啟動量測電腦模式）生效。

## 變更

- 新增 `labcontrol/core/nodes.py`：`node:` 解析、這台的名稱、`foreign_map()`（哪些儀器屬於別台；虛擬儀器跟著電源）。
- `core/station.py`：別台的儀器不建立，記在 `Station.foreign`；方案用到時錯誤訊息指出該送到哪台執行。
- `remote/groups.py`：
  - 設定檔指定給別台的儀器放到那台的群組（那台有回報就用它的即時狀態）；
  - 沒寫 `node` 的 USB 同時設定在兩台時，放在連線中的那台；
  - 在線的量測節點即使沒有儀器也列出群組；
  - USB / GPIB「移動」＝ 改 `node:`。
- `apps/qt/server/window.py`：`pin_local()` 改設定檔並立刻套用（中斷、移出 / 載入）。
- 遠端新增儀器（`add_instrument`）時，設定檔裡已經有這台（指定給別台）→ 改成指定給這台。
- 新增 `labcontrol/core/sparams.py`：S 參數名稱、port 解析。
- `drivers/rohde_schwarz/vna.py`：`port_count()`、`detect_ports()`；連線時自動偵測（`detect_ports: false` 關閉、`ports:` 直接指定）；
  `trace_list()` 偵測後列全部 S 參數；偵測範圍內的 S 參數沒有 trace 時自動建立。
- `drivers/sim/sim.py`：模擬 VNA 的 port（`sim: {ports: 4}`），反射 Sii 與其他 port 的曲線不同。
- 節點指令 `vna_ports`；`vnas` 回傳 port 資訊。
- 即時監控 VNA：S 參數矩陣、「偵測 port」按鈕、選 VNA 時自動偵測。
- `defaults/instruments.yaml`：DC1–DC4、VNA1 `node: LAB-1`，VNA2 `node: LAB-2`，SHFQC1 兩台。
- 文件：`docs/REMOTE.md` 6.3、6.4。
