# Lab Control 0.0.7

- 發佈日期：2026-09-30
- 類型：功能版本（Lab Control Hub：NAS 網站取代共用資料夾）
- Python：3.12
- 前一版：0.0.6

## 摘要（貼到 Lab APP「版本說明」）

遠端量測改用 NAS 上的 Lab Control Hub（小網站，Docker 一鍵啟動）：
- 監控網頁 `http://192.168.50.2:8765/`：所有開著 Lab Control 的電腦、量測節點的進度，可以暫停、停止；
- 指令與即時資料經 Hub 中轉，節點 long-poll，指令立即送達；
- 量測檔上傳 Hub，開始量測的人自動下載；
- 節點更新從 Hub 下載新版。

不再需要 SMB 共用資料夾和 Windows 登入 NAS。安裝見 `deploy/hub/README.md`；各電腦在「設定 ▾ → Hub 連線設定…」填入 token（不是 NAS 帳號密碼）。

## 為什麼改

0.0.5 / 0.0.6 的節點靠 SMB 共用資料夾交換檔案，實際使用時有幾個問題：
- 各電腦要先在 Windows 登入 NAS；
- 連不到時看不出原因：even-pc 的節點從來沒有成功上線，但記錄檔裡沒有任何錯誤；
- 輪詢檔案有延遲；
- 線上 / 離線依各電腦的時鐘判斷。

改成 Hub 之後：
- 每台電腦只需要連得到一個網址；
- 線上 / 離線由 Hub 判斷；
- 連線錯誤會顯示在狀態列，也會寫進 `LAB/logs/labcontrol.log`；
- 同時多了監控網頁和數據中轉。

## 新增

- **Lab Control Hub**（`labhub/`，只用 Python 標準函式庫）：
  - 裝置清單：每台 Lab Control 每 2 秒回報，包括控制端與節點、版本、目前的量測；
  - 節點狀態，以及同名節點在不同電腦上線時拒絕；
  - 指令佇列與回覆：long-poll；
  - 即時資料：每個節點保留 600 批；
  - 量測檔上傳與下載；
  - 提供 Lab APP 發佈資料夾給節點更新（自動打包 zip，不含 `.git`）；
  - token 驗證：第一次啟動自動產生；網頁用 cookie 登入；
  - 狀態每 10 秒存檔，重開 Hub 後仍記得有哪些電腦與節點。
- **監控網頁**：
  - 統計：節點上線數、電腦數、量測進行中、最新發佈版本；
  - 節點卡片：狀態、版本（標示可更新）、量測進度條與剩餘時間、儀器與電源值、最近訊息、暫停 / 停止；
  - 所有電腦列表、量測檔下載；
  - 淺色 / 深色跟隨系統，手機可看。
- **部署**（`deploy/hub/`）：
  - `docker-compose.yml`：官方 `python:3.12-slim` 映像，不需要 build，Synology Container Manager、QNAP、ASUSTOR 都能用；
  - 沒有 Docker 時用 `run_hub.bat` / `run_hub.sh`，或 `python -m labcontrol hub`；
  - `deploy/hub/README.md`：安裝步驟、token、防火牆、疑難排解。
- **數據中轉**：
  - 節點在量測結束後，把資料檔和 `_raw/` 原始檔上傳到 Hub，保留 `yyyy/mm/Data_mmdd` 結構；某個格式匯出失敗時，已寫好的檔仍會上傳；
  - 開始這次量測的控制端自動下載到自己的資料根目錄（`remote.download_results`、`remote.download_root`）；
  - 其他人可以從網頁下載。
- 主視窗「設定 ▾」：
  - **Hub 連線設定…**：網址與 token、測試連線，寫回 settings.yaml；
  - **開啟 Hub 監控網頁**：自動帶 token 登入；
  - **重新連線 Hub**。
- 「🛰 量測節點」上線訊息會說明：自己這台的「執行於」不會列出自己，要從其他電腦選。
- 命令列：`python -m labcontrol hub`；`nodes` 也列出所有電腦與網頁網址。
- 儀器控制視窗的 VNA Trace：RF 輸出關閉時顯示警告。這時 S 參數等於雜訊除以雜訊，所以 trace 是平均約 0 dB、上下跳動很大的雜訊。

## 變更

- `settings.yaml remote:` 改為：
  - `hub_urls`（預設 `[192.168.50.2, 100.114.33.20]`）、`port: 8765`、`token`、`timeout_s`；
  - `command_wait_s`、`upload_results`、`download_results`、`download_root`；
  - `update.method` 預設改為 `hub`。
  
  舊的 `root`、`hosts`、`share`、`folder`、`poll_s`、`offline_after_s`、`update.releases`、`node.keep_batches` 不再使用，留在檔案裡也不影響。
- 節點更新：從 Hub 下載 `v<版本>.zip`，取代從 SMB 共用資料夾複製。
- 移除「NAS 登入…」（Windows 認證管理員）與 `nas_login.py`：已不需要 NAS 帳號。

## 上線步驟

1. 在 NAS 安裝 Hub（`deploy/hub/README.md`），記下 `data/token.txt` 的 token。
2. 每台電腦更新到 0.0.7，在「設定 ▾ → Hub 連線設定…」填 token，按「測試連線」。
3. 量測電腦按「🛰 量測節點」。在另一台電腦的「執行於」選它；或打開網頁，確認節點出現。

## 測試

自動測試 88 項全部通過（Python 3.11、3.12）。新增的測試：
- Hub：token 驗證、找 Hub 的錯誤訊息、網頁登入 cookie、裝置清單與狀態存檔、同名節點衝突；
- 指令：long-poll 延遲小於 1 秒、讀寫儀器；
- 資料：遠端量測即時資料、量測檔上傳與下載內容一致、中途加入與 Hub 重開後重新同步；
- 遠端停止、從 Hub 更新（找不到版本拒絕、自動要求、下載解壓、不含 .git）；
- 兩個視窗：節點與控制端，量測結束自動下載資料檔。
