# Lab Control 0.0.25

- 發佈日期：2026-10-10
- 類型：量測介面版面
- 前一版：0.0.24
- 發佈檔：`LabControl_v0.0.25.zip`

## 摘要（貼到 Lab APP「版本說明」）

- 量測面板只剩兩欄：
  - 左邊設計流程：上面是流程圖，下面是儀器參數（拖進流程圖）；
  - 右邊設置存檔：檔案、執行、檢查與估時、已存的數據（整個高度）。
- **量測監控**（進度、曲線、2D 影像、暫停 / 退回 / 停止）：
  - 按「▶ 開始量測」後以獨立視窗彈出（「執行於」量測節點時也一樣）；
  - 關掉視窗只是收起來，量測照常進行；
  - 工具列「📈 量測監控」隨時再打開，量完的結果也還在。
- **即時數據**（電源群組、VNA 參數與曲線）：工具列「📡 即時數據」開獨立視窗，關掉一樣只是收起來。
  量測進行中即時控制暫停（數值照常更新），與以前相同。

## 變更

- `apps/qt/workbench/window.py`：
  - 兩欄版面；
  - 新增 `ToolWindow`（常駐的獨立視窗，關閉 = 隱藏）；
  - `show_measure_window()`（開始量測、量測開始時自動彈出）、`popout_live()`；
  - 工具列新增「📡 即時數據」「📈 量測監控」。
- 即時數據面板不再有主視窗內的精簡模式與「⧉ 獨立視窗」按鈕。
- 介面文字「右下」改成「右邊」。

## 測試

- `tests/test_workbench.py`：主視窗只有流程與存檔；開始量測時量測監控視窗彈出；關閉後再開，結果還在。
- `tests/test_live_gui.py`：即時數據一開始不顯示，按鈕開啟、關閉收起再開；量測開始時量測監控視窗自動彈出。
