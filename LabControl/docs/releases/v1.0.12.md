# Lab Control 1.0.12

- 發佈日期：2026-10-20
- 類型：功能（即時數據常用設定、VNA 平均開關、手機控制電磁鐵、讀檔程式 1.0.9）
- 前一版：1.0.11
- 發佈檔：`LabControl_Setup_v1.0.12.exe`、`LabControlHub_v1.0.12.zip`

## 摘要（貼到版本說明）

- **即時數據的常用設定（快速切換）**：VNA 參數上方多一排「常用」按鈕。調好設定後按「＋ 存成常用」取名字，
  之後點一下就把起訖頻率、點數、功率、IF、平均、掃描時間與 S 參數一起套用到 VNA。右鍵可以重新命名、用目前設定覆蓋、刪除、往前移。
  存在這台電腦（最多 12 個）。
- **VNA 平均改成「勾選 ＋ 次數」**：不再用 0 表示關閉。取消勾選 = 關閉平均，次數保留，下次勾選沿用；
  即時數據與量測方塊的 VNA 設定都一樣（次數記在這台電腦，兩邊共用）。
- **手機 / 網頁控制電磁鐵**：平台網站導覽列多「電磁鐵」頁（/magnet）。選量測電腦，就看到跟那台「即時數據」一樣的電源群組：
  每台的電流、目標（斜坡移動）、微調 ±（可選步進）、記憶 M1–M3（點了用記憶速率移過去；也可以把目前值存進去，量測電腦的即時數據同步更新）、
  輸出開關、停止斜坡。
- **量測進行中鎖住遠端寫入**：量測電腦正在量測時，手機、網頁或別台電腦都不能調整儀器（節點拒絕寫入指令，頁面顯示 🔒 並只顯示最後的值、不去讀儀器），
  避免跟量測的指令衝突；量測結束自動恢復。`remote.node.lock_during_run`（預設開）。
- **讀檔程式 1.0.9**：2D 截面改成跟 Labber 一樣（X 截面在上、Y 截面在右、交點讀值框、白色截線），對比度（直的強度直方圖、
  Max / Min、Auto range / Full range）放在圖左側；Auto range 跟 Labber 一樣去掉離群值（第 1–99 百分位）；新版本在右下角跳出通知，可以直接更新。

## 變更

- `apps/qt/live/vna_panel.py`：`AvgEdit`（勾選 ＋ 次數）、`PRESET_KEYS`、`save_preset / load_preset / delete_preset / _preset_menu`，
  `live_ui.json` 的 `vna_presets`、`avg_count`。`workbench/dialogs.py` MeasureDialog 的 VNA 平均也用 `AvgEdit`。
- `remote/node.py`：`_check_idle()`（量測中拒絕 set / group_ramp / fine_step / output / magnet_memory）、`cmd_magnets`、`cmd_magnet_memory`；
  `live/dc_panel.py` `sync_store_memory()`（網頁改的記憶同步到桌面）。
- `labhub/static/magnet.html`、`mobile_routes.py` `/magnet`、`web_nav.py` 導覽「電磁鐵」。
- 設定：`remote.node.lock_during_run: true`。
- 測試：`tests/test_112.py`；讀檔程式 `tests/test_v1_0_9_viewer.py`。
