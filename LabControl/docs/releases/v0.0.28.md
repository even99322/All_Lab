- 發佈日期：2026-10-11
- 類型：安裝方式（從 NAS 一鍵安裝）、量測介面修正、和讀檔程式互通
- 前一版：0.0.27
- 一起發佈：LabLogViewer 2.1.3

  - `LabControlHub_v0.0.28.zip`：**Hub 要更新**，新增一鍵安裝清單與下載頁；
  - `LabControl_v0.0.28.zip`：原始碼，也是功能更新包；
  - `LabControl_v0.0.28_windows-setup.exe`、`LabControl_v0.0.28_macos-*.dmg`；

  - `LabLogViewer_v2.1.3_windows-setup.exe`、`LabLogViewer_v2.1.3_macos-*.dmg`。

## 摘要（貼到版本說明）

- **一鍵安裝（Windows）**：
  - 下載頁最上面的「Windows 一鍵安裝」（好記的網址 `http://192.168.50.2:8765/get/setup`）是一個小安裝程式；
  - 執行後勾選要裝的程式（量測、讀檔），它會從 NAS 下載最新版、檢查檔案、安靜安裝；
  - 程式裝在使用者資料夾，不需要系統管理員；之後兩個程式都在程式內收到更新推播。
- **Lab Control 改用安裝程式**：
  - Windows 跟 LabLogViewer 一樣有安裝程式（`LabControl_v<版本>_windows-setup.exe`），裝到 `%LOCALAPPDATA%\Programs\Lab Control`，有開始功能表、桌面捷徑和解除安裝；
  - 程式內更新：只改程式碼時下載功能更新包；需要整個程式時，下載安裝程式，Lab Control 關閉後安靜安裝並自動重開。
- **檔名**：
  - 修正「改了檔名，存出來還是 aaa_1」：以前檔名要按 Enter 或換到別的欄位才會記下，打完直接按「▶ 開始量測」或 F5 就會用舊的檔名；
  - 現在打字時就記下，開始量測前也會再確認一次。
- **不再存 `_raw/`**：
  - 量測時不再另存 `_raw/<檔名>_<時間>.lm.h5`；
  - 要的話在 `settings.yaml` 設 `data.raw_backup: true`，舊的 `data.raw` 不再看。
- **DC 微調**：
  - 即時數據的電源群組，「＋／－」下面可以選一步多大：最小步進、×10、×100、×1000、×10000；
  - 每一組記在這台電腦；一台的群組也能微調。
- **滾輪調整**：
  - 即時數據的 VNA 參數（中心頻率、頻寬、起訖頻率、功率…）可以用滑鼠滾輪或 ↑↓ 調整游標所在的那一位數，停手 0.7 秒後寫入 VNA；
  - 量測方塊的設定視窗也一樣。
- **流程圖顯示 VNA 設定**：
  - 量測方塊多兩行：頻率範圍、點數、IF 頻寬、平均、功率；
  - 沒有在方塊裡設定的項目顯示「⚠ … 用儀器目前值」，免得忘了改。
- **和讀檔程式互通**：
  - 讀檔程式「介面 → 量測」會打開 Lab Control，選了一筆數據時會詢問是否套用它的設定；
  - 從讀檔程式的資料庫清單直接拖數據到 Lab Control 也可以；
  - Lab Control 已經開著時，會直接交給開著的那一個。

## 第一次升級

1. 控制台發佈 `LabControlHub_v0.0.28.zip`。
2. 控制台發佈：
   - `LabControl_v0.0.28.zip`：0.0.27 的電腦會收到推播，用功能更新包幾秒更新；
   - `LabControl_v0.0.28_windows-setup.exe`、`LabControl_v0.0.28_macos-*.dmg`；
   - `LabLogViewer_v2.1.3_*`；
   - `QELSetup_v1.0.0_windows.exe`。
3. 已經在用的電腦：兩個程式都會收到推播，按「立即更新」。
4. 新電腦：下載頁 →「Windows 一鍵安裝」。

0.0.27 的單一 .exe 會先用功能更新包升到 0.0.28。之後要換整個程式時，會改裝到 `%LOCALAPPDATA%\Programs\Lab Control`。如果開了「開機自動開啟」，會跟著改到新位置；舊的 .exe 可以刪掉。

## 變更

- **Hub**：
  - `GET /get/setup.txt`：一鍵安裝讀的清單，每行 `app|版本|檔名|大小|sha256|網址`；
  - `GET /get/setup`：轉到最新的 `QELSetup_v*_windows.exe`；
  - `/get/info` 多了 `setup`；
  - 控制台認得 `QELSetup_v<版本>_windows.exe`（模塊 `setup`）；
  - 下載頁新增「Windows 一鍵安裝」卡片。
- **打包**：
  - `packaging/build_app.py`：Windows 改成資料夾版加 Inno Setup 安裝程式，打包前會先自我檢查；
  - `packaging/labcontrol.iss`：新增；
  - `packaging/qel_setup.iss`：新增，是一鍵安裝。它會從 Hub 下載安裝程式、檢查 sha256、用 `/SILENT` 安裝；連不到實驗室網路時改試 VPN，也可以用 `/HUB=` 指定 Hub。
- **程式內更新**：`selfupdate.update_to` 遇到 `*setup*.exe` 時，等 Lab Control 結束後安靜安裝並重開；`autostart.refresh()` 讓開機自動開啟跟著換到新位置。
- **和其他程式溝通**：
  - `labcontrol/apps/qt/local_link.py`：本機連線 `qel-labcontrol-<使用者>`，並寫 `~/.qel/labcontrol/app.json`；
  - `LabControl --apply 數據檔`；用 Lab Control 開數據檔也等於套用設定。
- **其他修改**：
  - 檔名欄位改成打字時就記下，開始量測或存方案前會呼叫 `FilePanel.commit_edits()`；
  - `fine_step(refs, direction, step)` 可以帶步進，量測節點也支援；
  - `labcontrol/apps/qt/digit_edit.py`：新增，包含 `WheelLineEdit` 與 `DigitSpinBox`；
  - `graph_view.measure_details`：量測方塊顯示 VNA 設定；
  - `data.raw_backup` 預設 false，取代 `data.raw`。
- **測試**：
  - `tests/test_measure_ui_0028.py`
  - `tests/test_local_link.py`
  - `tests/test_console.py`：一鍵安裝清單
  - `tests/test_standalone.py`：安裝程式式更新
  - `tests/test_live_*`：微調步進
- **雲端測試**：All_Lab 的 E2E Windows 會在 Windows 雲端機器上：
  - 開一個測試用 Hub；
  - 用一鍵安裝把兩個程式裝起來，再各跑一次自我檢查；
  - 在 Windows 上跑 LabLogViewer 的去背景測試。
