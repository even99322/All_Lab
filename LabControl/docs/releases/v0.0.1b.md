# Lab Control 0.0.1b

- 發佈日期：2026-09-30
- 類型：bug 修正
- Python：3.12
- 前一版：0.0.1a（Lab APP 上發佈為 v0.0.1）

## 摘要（貼到 Lab APP「版本說明」）

修正：前一版啟動即失敗（No module named 'labcontrol.data'）。原因是 .gitignore 的 data/ 把程式裡的 labcontrol/data 套件一起排除，Lab APP 以 git 發佈時這個資料夾沒有被上傳。功能與 0.0.1a 相同。

## 修正

| 問題 | 原因 | 修正 |
|---|---|---|
| 啟動時 `ModuleNotFoundError: No module named 'labcontrol.data'` | `.gitignore` 的 `data/` 會比對任何層級名為 data 的資料夾，`labcontrol/data/`（資料格式、Labber 匯出）沒有進 git | 改為 `/data/`（只忽略專案根目錄的資料資料夾）；`.venv`、`*_venv` 同樣限定在根目錄 |

## 防止再發生

- 新增測試 `test_gitignore_does_not_exclude_package_files`：`labcontrol/` 內每個檔案與 Lab APP 必要檔（`main.py`、`.entry`、`.icon`…）都不可被 `.gitignore` 排除。
- 發佈前檢查（開發者）：在專案資料夾執行 `git status --ignored`，確認 Ignored 清單裡沒有程式檔。

## 升級

直接在 Lab APP 更新即可；`C:\Users\even9\LAB` 內的設定不受影響（0.0.1a 因啟動失敗，可能還沒建立這個資料夾，第一次開啟 0.0.1b 會自動建立）。
