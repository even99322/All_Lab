# Lab Control 0.0.31

- 發佈日期：2026-10-13
- 類型：電流斜坡 10 mA/s、論文庫服務帳號、6 個範本＋專案範本同步、流程圖常改數值面板、儀器依量測電腦自動對應、電磁鐵組改名、專題歸檔、與讀檔程式連動、遠端量測存到量測電腦、更新卡住修正；讀檔程式 2.1.6（VPN / NAS 加速、大資料夾、快捷鍵、Phase delay）
- 前一版：0.0.30
- 發佈檔：
  - `LabControlHub_v0.0.31.zip`：**Hub 要更新**（論文庫服務帳號、專案範本、上傳完整性檢查）；
  - `LabControl_v0.0.31.zip`：功能更新包；
  - `LabControl_v0.0.31_windows-setup.exe`、`LabControl_v0.0.31_macos-arm64.dmg`、`..._macos-x86_64.dmg`；
  - `LabLogViewer_v2.1.6_windows-setup.exe`、`LabLogViewer_v2.1.6_macos-*.dmg`。

## 摘要（貼到版本說明）

- **電流斜坡預設 10 mA/s**：
  - 設定檔、內建儀器設定、量測預設（approach / park）都改成 10 mA/s；
  - 還是舊預設（0.5 mA/s）的 `LAB/instruments.yaml` 會自動改成新預設（備份成 `instruments.yaml.bak-0.0.31`），自己改過的值不會動；
  - 斜坡改成依「經過的時間」前進：顯示 10 mA/s 就真的是 1 秒 10 mA（以前每一步的儀器寫入時間沒算進去，會慢很多）。如果受限於 `max_jump` 或儀器寫入速度，面板會顯示「實際 x mA/s」。
- **論文庫專案讀不到**：Hub 用一個服務帳號查詢論文庫的專案，所有量測電腦都看得到專案清單。
  - 帳號密碼**只存在 NAS 上**：控制台「論文庫服務帳號」設定，或 docker-compose 的 `LABHUB_PAPERLIB_SERVICE_USER` / `_PASSWORD`；
  - 程式裡、安裝檔裡都沒有密碼。
- **量測範本只留 6 個**：單張、2D、2D 電流異步、雙層分檔、雙層單檔、flux。
  - 舊的內建範本搬到 `LAB/templates/舊範本_0.0.30/`（不刪；自己做的範本不動）。
  - flux：大範圍掃電流（0 → 200 mA，1 mA 一步）＋ VNA 寬頻，看整體的 flux map；數值請依實驗調整。
- **專案範本**：檔案設置選了論文庫專案時，範本選單顯示「這個專案的」範本：
  - 選「2D」就載入這個專案上次用的 2D 設定（沒有就用內建的）；
  - 改了方案，停手 1.5 秒自動寫回這個專案的範本，存在 Hub，**所有電腦共用**；Hub 連不到時先存本機，之後自動送出；
  - 換專案時，先把目前的設定存回舊專案，再載入新專案的同一個範本。
- **流程圖左邊「常改的數值」**：改過兩次以上的欄位（電流值、起點 / 終點 / 步進、等待…）會列在這裡，直接調整；右鍵「從這裡移除」。跟著專案範本一起同步。
- **儀器依量測電腦自動對應**：方案在 LAB-1 是 magA、magB、VNA1，在 LAB-2 執行時自動換成 magC、magD、VNA2（同一台的第幾個電磁鐵組對到另一台的第幾個，VNA 也一樣）。
  - 在 `instruments.yaml` 每台儀器寫 `node: LAB-1` / `node: LAB-2`。
- **電磁鐵組改名**：流程圖上電磁鐵組的右鍵「改電磁鐵組名稱…」。改的是這台電腦的 `LAB/instruments.yaml` 顯示名稱（遠端量測電腦的要在那台改）。
- **專題歸檔**（工具列「📦 專題歸檔」）：選單一數據或整個資料夾 → 選專案 → 複製到 NAS `數據集散地\<專案>\`，保留日期資料夾；相同的檔案跳過，同名不同內容加 `_2`。
- **與讀檔程式連動**：
  - 量測完成的新數據自動用讀檔程式開啟（讀檔程式開著就直接顯示，沒開就啟動它）；雙層分檔不開。`settings.yaml` 的 `lablogviewer.open_after_measure: false` 可以關掉；
  - 從讀檔程式把數據拖到 Lab Control 的任何視窗（量測、即時數據），自動套用該數據的量測設定。
- **遠端量測存到量測電腦的路徑**：在非量測電腦對量測電腦下指令時，數據存到那台量測電腦自己的存檔位置（檔案設置會顯示那台的資料夾）。
- **程式內更新**：
  - 修正更新時卡在「find」命令視窗、接著「找不到 LabControl.exe」：等待舊程式結束最多 45 秒、不再跳命令視窗、安裝失敗時改開一般安裝畫面；
  - 修正「The setup files are corrupted」：控制台上傳時檢查檔案大小，不完整會直接報錯並顯示 sha256，不會發佈壞掉的安裝檔。
- **讀檔程式 2.1.6**：
  - VPN / NAS 上的數據先複製到本機一次再讀，預覽、切換數據、切換 trace、調整繪圖都快很多；開啟到獨立視窗不再空白；
  - 超過 100 筆的資料夾先顯示 100 筆，捲動再載入；資訊在背景讀取，目前資料夾優先；
  - 開啟資料庫預設：量測電腦開桌面的數據集散地，其他電腦開 NAS 的；Folder 上方可以選專案資料夾；子資料夾縮排變小；
  - 拖曳數據檔到程式上直接開啟；
  - 快捷鍵：Esc 全域圖、M Point Mark、1 / 2 Plot Mode、F 最大化、P 資料點、A 自動色階、H 控制面板、D Phase delay、T Traces，「設定 → 快捷鍵」可以改；
  - Phase delay（去除電學延遲 τ，可自動擬合）；
  - 修正「立即更新」不出現 / 更新卡住。

## 第一次升級

1. 控制台發佈 `LabControlHub_v0.0.31.zip`，等 Hub 重新啟動。
2. 控制台「論文庫服務帳號」填論文庫的查詢帳號與密碼（或在 docker-compose 設定 `LABHUB_PAPERLIB_SERVICE_USER` / `LABHUB_PAPERLIB_SERVICE_PASSWORD` 後重建）。
3. 控制台發佈 `LabControl_v0.0.31.zip` 與安裝檔、`LabLogViewer_v2.1.6_*`。上傳後確認控制台顯示的大小與 sha256。
4. 量測電腦：兩個程式都會收到推播，按「立即更新」。（0.0.30 的更新腳本可能還會卡在命令視窗一次：等它結束或關掉後，用安裝檔安裝一次即可；之後的更新用新的腳本。）
5. `LAB/instruments.yaml`：每台儀器加上 `node: LAB-1` 或 `node: LAB-2`（電磁鐵組、VNA），自動對應才會生效。

## 變更

- **斜坡**：
  - `core/grouping.py` GroupRamp 依經過時間計算每一步（rate × elapsed，上限 `max_jump`），回報 `actual_rate`；`live/dc_panel.py` 顯示實際速率。
  - `core/config.py`：`DEFAULT_RAMP_RATE = 1e-2`、`LEGACY_RAMP_RATE = 5e-4`；`migrate_instruments_text`；`paths.ensure_lab_home` 一次性轉換（`.migrated_ramp_0031`）。
  - `settings.yaml`：`run_defaults.approach_rate` / `park_rate` 10 mA/s（`OLD_DEFAULTS` 自動換掉舊預設）、`live:`、`lablogviewer:`。
- **Hub**：
  - `labhub/platform.py`：服務帳號（`service_info`、`set_service_account`、`service_session`），裝置 token 查專案改用服務帳號；使用者 401 時回快取。
  - `labhub/platform_routes.py`：`GET/PUT /api/platform/console/paperlib-service`（站長）；`GET /api/platform/project-templates/<專案>`、`PUT /api/platform/project-templates/<專案>/<範本>`；上傳 `?size=` 檢查。
  - `labhub/server.py`：body 比 Content-Length 短 → 400；`console.py` 記 sha256，控制台顯示。
- **方案**：
  - `scheme/model.py`：`template`、`quick`；`scheme/templates.py` 載入時記範本 key；`scheme/remap.py`（`role_lists`、`remap_scheme`）。
  - `apps/qt/workbench/project_sync.py`（ProjectTemplateSync）、`integrations/project_templates.py`（本機快取 `LAB/project_templates/<專案>/<範本>.json`，`pending` 之後再送）。
  - `apps/qt/workbench/quick_panel.py`；`doc.py` 計數（`QUICK_FIELDS`、`QUICK_MIN = 2`）。
  - `graph_view.py`：電磁鐵組右鍵改名 → `window.rename_magnet_group`（`config.set_instrument_label`）。
- **歸檔**：`data/archive.py`（`find_nas`、`plan`、`copy`；`LABCONTROL_ARCHIVE_ROOT` 可指定）、`apps/qt/archive_dialog.py`。
- **讀檔程式連動**：`integrations/lablogviewer.py`（本機連線 `qel-lablogviewer-<使用者>`、`~/.qel/lablogviewer/app.json`、`LABLOGVIEWER_EXE`）；`monitor_panel._export` 量完呼叫；`window._DataDropFilter`（整個程式接受外部拖進來的數據檔）。
- **遠端**：`remote/node.py` 狀態帶 `data`（root、pattern、folders），`cmd_run_scheme` 不用客戶端的 `output.root`；`files_panel.set_remote`。
- **更新**：`selfupdate.py`（`CREATE_NO_WINDOW`、`WAIT_ROUNDS = 45`、`/LOG`、找不到 exe 時開互動安裝；`exit_for_update` / `hard_exit_after`）。
- 測試：`tests/test_0031.py` 等。
