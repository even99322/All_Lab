# Lab Control 0.0.26

- 發佈日期：2026-10-11
- 類型：不用啟動器；Lab Control 獨立程式與程式內更新；下載頁
- 前一版：0.0.25
- 發佈檔：
  - `LabControlHub_v0.0.26.zip`（**Hub 要更新**：新的下載頁）；
  - `LabControl_v0.0.26.zip`（原始碼，用來打包 .exe / .dmg）；
  - LabLogViewer 2.1.1 的 repo 檔案（`LabLogViewer_v2.1.1_repo_files.zip`）。

## 摘要（貼到版本說明）

- 不再需要「量子工程平台」啟動器。下載頁 `http://192.168.50.2:8765/get` 列出兩個程式，各有 Windows / Mac 版：
  - **量測**：Lab Control，Windows 是單一 .exe，Mac 是 .dmg；
  - **讀檔**：LabLogViewer，Windows 是安裝程式，Mac 是 .dmg。
- 瀏覽器說「不常下載，開啟前請確定您信任…」：
  - 原因：程式沒有向微軟買程式碼簽章、下載的人又少。檔案本身沒問題；
  - 下載頁有教怎麼「保留」；
  - 只有第一次從網頁下載會遇到。
- Lab Control 程式內更新：
  - 有新版時狀態列出現「⬆ 更新到 x.y.z」，按一下就下載、換掉自己、重新開啟；
  - 程式自己下載，不經過瀏覽器，不會再跳警告；
  - 量測中不更新；量測電腦的節點收到「請更新」也是這樣更新。
- 量測電腦：Lab Control「設定 ▾ → 量測電腦：開機自動開啟並上線」，會順便移除舊啟動器的自動開啟。
- 平台網頁的「在讀檔程式開啟 / 套用設定到量測 / 開啟專案」：
  - 改送到你電腦上開著的 Lab Control；
  - Lab Control 直接開這台電腦裝好的 LabLogViewer。
- 控制台認得 LabLogViewer 的安裝檔：
  - 檔名沒有版本時，讀安裝檔的版本資源；
  - 還是沒有，就請站長輸入版本號。

## 怎麼打包、發佈

1. Lab Control：
   - Windows：在原始碼資料夾雙擊 `packaging/build_windows.bat` → `dist/LabControl_v0.0.26_windows.exe`；
   - Mac：雙擊 `packaging/build_macos.command` → `dist/LabControl_v0.0.26_macos-<晶片>.dmg`；
   - 打包完會自己跑一次 `--self-test`，看到「全部通過」才算好。
2. LabLogViewer：
   - 把 `LabLogViewer_v2.1.1_repo_files.zip` 的內容覆蓋到 repo，推 tag `v2.1.1`；
   - GitHub Actions 產生 `LabLogViewer_v2.1.1_windows-setup.exe` 與 `LabLogViewer_v2.1.1_macos-*.dmg`。
3. 平台網頁「控制台」：
   - 先發佈 `LabControlHub_v0.0.26.zip`（新的下載頁）；
   - 再把上面的 .exe / .dmg 全部拖進來 →「全部發佈」。
4. 各電腦到下載頁下載安裝一次，之後 Lab Control 會自己更新。
   - 舊的啟動器可以刪掉；
   - 量測電腦在 Lab Control 打開「開機自動開啟並上線」。

## 變更

- Hub：
  - `/get` 下載頁改成量測 / 讀檔兩張卡片，含「不常下載」的處理說明；
  - `/get/info` 回傳 `apps`；
  - `GET /get/<labcontrol|lablogviewer>/<版本>/<檔名>` 不用登入（只限安裝檔）；
  - 啟動器、Monitor 在平台網頁隱藏；
  - 平台網頁的指令改送到 `labcontrol`。
- `labhub/packages.py`：
  - 沒有版本號的安裝檔名（`LabLogViewer-Windows-setup.exe`）；
  - Windows 版本資源（`pe_version`）；
  - `NeedVersion` → 控制台請站長輸入版本號（`?version=`）。
- Lab Control：
  - `packaging/build_app.py`、`build_windows.bat`、`build_macos.command`（PyInstaller；Windows 版本資源；Mac Info.plist 版本）；
  - `labcontrol/self_test.py`（`--self-test`）；
  - `labcontrol/selfupdate.py`（找 Hub 上這台電腦的安裝檔、下載、換掉、重新開啟、清掉舊檔）；
  - `apps/qt/updates.py`（狀態列「⬆ 更新到…」、「設定 ▾ → 檢查更新…」）；
  - `labcontrol/autostart.py`（開機自動開啟 `--node --minimized`）；
  - `integrations/reader.py`（找 LabLogViewer 並開檔 / 資料夾）；
  - `platform_ui`：處理平台網頁送來的 `open_in`、`open_project`；
  - 量測節點的遠端更新在打包版走程式內更新；
  - `--minimized`。
- LabLogViewer：`installer.iss`、`.github/workflows/build.yml` 輸出檔名帶版本；安裝檔帶 ProductVersion。
