# Lab Control 1.0.0（正式版）

- 發佈日期：2026-10-13
- 類型：正式發佈版。量測程式（Lab Control）與讀檔程式（LabLogViewer）一起定為 **1.0.0**；Hub 控制台上傳顯示進度
- 前一版：0.0.32（讀檔程式：2.1.6）
- 發佈檔：
  - `LabControlHub_v1.0.0.zip`：**Hub 要先更新**（讀檔程式的版號重新開始、上傳進度）；
  - `LabControl_v1.0.0.zip`：功能更新包；
  - `LabControl_v1.0.0_windows-setup.exe`、`LabControl_v1.0.0_macos-arm64.dmg`、`..._macos-x86_64.dmg`；
  - `LabLogViewer_v1.0.0_windows-setup.exe`、`LabLogViewer_v1.0.0_macos-*.dmg`；
  - `LabControlMonitor_v1.0.0.zip`。

## 摘要（貼到版本說明）

- **正式版 1.0.0**：量測與讀檔兩個程式都定為 1.0.0，功能分別等於 0.0.32 與 2.1.6。之後兩邊從 1.0.x 繼續。
- **讀檔程式版號重新開始**：
  - 1.0.0 比之前的 2.1.6「小」，所以 Hub 更新後第一次啟動，會把讀檔程式 2.x 的舊版本搬到 `data/modules_legacy/lablogviewer/`（不刪），1.0.0 才會是最新版；
  - 已經裝 2.x 的電腦**不會收到推播**，請手動安裝一次 1.0.0（NAS 下載頁或一鍵安裝）。資料、標籤、星號、註解都保留，第一次開啟會顯示「新功能」；
  - 1.0.0 起的讀檔程式不會被舊的 2.x 更新通知「更新回去」。
- **量測程式**：0.0.x → 1.0.0 是往上，已安裝的電腦照常收到推播，按「立即更新」即可。
- **Hub 控制台上傳進度**：拖檔或選檔後顯示進度條、已上傳 / 總大小、速度、剩餘時間，多個檔案顯示第幾個；上傳完顯示「Hub 檢查檔案中…」；可以「取消上傳」。

## 升級步驟

1. 控制台發佈 `LabControlHub_v1.0.0.zip`，等 Hub 重新啟動（之後上傳就看得到進度）。
2. 控制台上傳並發佈：`LabControl_v1.0.0.zip` 與安裝檔、`LabLogViewer_v1.0.0_*`、`LabControlMonitor_v1.0.0.zip`。
3. 量測程式：各電腦按「立即更新」。
4. 讀檔程式：每台電腦手動安裝一次 `LabLogViewer_v1.0.0`（之後的 1.0.x 會推播）。

- `labhub/platform.py`：`LEGACY_LINES`、`_archive_legacy_versions`（標記檔 `modules/.legacy_archived_lablogviewer`）。

- `labhub/static/portal.html`：上傳改用 XMLHttpRequest（`upload.onprogress`），進度條、速度、剩餘時間、取消。

- 讀檔程式 1.0.0：`app_update.VERSION_LINE`、`legacy_feed`（沒有 `line` 的 2.x feed 不提供）、資料夾記 `version_line`（2.x 用過的資料夾算升級）；舊的「新功能」說明移到 `help/whats_new/legacy/`。
