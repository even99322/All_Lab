# Lab Control 1.0.32

- 發佈日期：2026-11-09
- 類型：檢查與防護（對外流量）
- 前一版：1.0.31

## 摘要（貼到版本說明）

- **Hub「網路用量」多了 Tailscale（VPN）**：每分鐘讀 NAS 上的 Tailscale，列出每個 VPN 裝置跟 NAS 之間傳了多少，
  並標出路徑：區網直連（不經外網）、外網直連、DERP 中繼（都經實驗室對外線路）。圖只畫「經外網」的部分。
  NAS 開著「出口節點」或分享子網路由、或有人正把 NAS 當出口上網時，頁面上會出現警告。
- **Hub 從 GitHub 下載新版的量**也記在「網路用量」（今天 / 本月）。
- **自動從 GitHub 取得新版：下載或暫存失敗的檔 24 小時內不再自動重抓**（以前每 30 分鐘會再下載一次同一個檔）。
  在控制台手動按「取得」照樣會試。
- **Lab Control 連 Hub 會自己改回內網**：啟動時如果內網位址剛好連不到而改走 VPN 位址（100.x），之後每 5 分鐘試一次
  內網，連得到就換回去（量測節點每一點的曲線都會即時上傳到 Hub，不要讓它繞 VPN）。

## 細節

- Tailscale 的數字來自 tailscaled LocalAPI `/localapi/v0/status` 每個節點的 RxBytes / TxBytes（NAS 收到 / 送出），
  用 Hub 已經掛載的 socket（`/var/packages/Tailscale/var:/tailscale:ro`，內網 https 憑證也是用它）。
- 路徑判斷：CurAddr 是私有位址 → 區網直連；是公開位址 → 外網直連；沒有直連位址 → DERP 中繼。

## 更新步驟

1. Hub 控制台更新到 1.0.32，打開「網路用量」看 Tailscale 那一區。
2. Lab Control 更新到 1.0.32（App 內更新即可）。
