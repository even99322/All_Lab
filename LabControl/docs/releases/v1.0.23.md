## 摘要（貼到版本說明）

- **網頁「數據查看」2D 圖**（跟讀檔程式一樣可以切換）：
  - 視圖：|S| dB、|S| 線性、相位、相位（展開）、實部、虛部；背景：原始、減背景（每個頻率減所有 trace 的中位數）、
    每條 trace 減自己的中位數、對頻率微分；色階（檔案設定 / LabLog BWR / 紅白藍 / viridis / magma / 灰階、反轉）與範圍（自動 / 手動）。
  - 頻率預設放在 Y 軸（1.0.22），「⇄ 交換 X / Y」換回來；「🔍 框選放大」、「⤢ 全圖」（熱圖上點兩下也是全圖）。
  - 截面預設看 **Trace（固定電流，沿頻率）**，也可以看固定頻率、或兩個一起看；← → ↑ ↓ 鍵逐條移動；顯示曲線最低點。
  - **標記**：「＋ 標記」後在曲線或熱圖上點一下放標記（最多 12 個），「▼ 最低點」「▲ 最高點」直接放在目前 trace 上；
    表格列出每個標記的座標與數值、跟 M1 的差（Δ）。換視圖時數值跟著更新。設定記在這台瀏覽器。
- 相位 / 實部 / 虛部需要原始複數資料：NAS 的數據索引程式這一版起在 2D 預覽多存一份（跟 dB 選同一個點），
  **更新後會在背景把所有檔重新解析一次**（新的檔先做）；還沒重新解析的檔只能看 dB。
