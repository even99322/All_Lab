# Lab Control 1.0.25

- 發佈日期：2026-10-24
- 類型：新功能（手機推播通知）
- 前一版：1.0.24
- 發佈檔：`LabControlHub_v1.0.25.zip`

## 摘要（貼到版本說明）

- **手機推播通知**：網頁導覽列多了「🔔 通知」。每台裝置自己開關，選要收「量測結束」（完成 / 停止 / 失敗）、
  「模擬結束」（HFSS 自動化工具的 S 參數 / 場型 / GIF / 一鍵全流程），也可以只收某幾台電腦；有「送一則測試通知」。
- 手機不用開著網頁、不用連 VPN 就收得到（瀏覽器的推播服務送達）；點通知打開對應的頁面。
- iPhone / iPad：iOS 16.4 以上、先「加入主畫面」再從 App 開通知；網頁要用 https 網址開。
- 模擬完成的通知需要 HFSS 自動化工具 3.8 以上。

## 細節

- `labhub/webpush.py`：只用標準函式庫的 Web Push（P-256 ECDH / ECDSA、RFC 8291 aes128gcm、RFC 8292 VAPID），
  tests/test_122.py 用 `cryptography` 交叉驗證（瀏覽器那一端解得開、簽章驗得過）。
- `labhub/notify.py`：訂閱與設定（data/push/）、`/notify` 頁、`/api/notify/…`、`POST /api/hfss/event`；
  `mobile_routes.MobileStore` 偵測量測結束（Hub 剛重新啟動時，2 分鐘內結束的才送）。
- `sw.js`：收推播顯示通知、點通知開頁面、訂閱過期自動重新訂閱（快取版本 qel-app-v3）。
- llvcore 同步到讀檔程式 1.0.10。

## 更新步驟

控制台「從 GitHub 取得新版」→ 發佈 1.0.25。Hub 的容器要能連外網（推播服務）。
