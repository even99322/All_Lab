# Lab Control 0.0.24

- 發佈日期：2026-10-10
- 類型：電磁鐵組
- 前一版：0.0.23
- 發佈檔：`LabControl_v0.0.24.zip`

## 摘要（貼到 Lab APP「版本說明」）

- 儀器伺服器新增「**＋ 電磁鐵組…**」：選兩個電源輸出，配成一組電磁鐵。
  - 兩台單通道電源：例如 GS200-1 + GS200-2；
  - GS820 的兩個通道：CH1 + CH2（`DC5.ch1` + `DC5.ch2`）；
  - 名稱自動取 magnet_A、magnet_B…；一個電源只能在一組裡。
- 配對的電源**收在電磁鐵組底下**，平時只看到電磁鐵組：
  - 展開後每台電源仍可以單獨連線、中斷、開控制視窗、驅動測試；
  - 電磁鐵組那列顯示「成員 k/n 已連線」；
  - 別台量測節點的電磁鐵組也一樣顯示。
- 主視窗「儀器參數」勾「只顯示常用」時，只列電磁鐵組，不列配對的電源。
- 選電磁鐵組按「移除」= 拆開，電源保留。

## 變更

- 新增 `apps/qt/server/magnet_dialog.py`（電磁鐵組對話框）。
- `remote/groups.py`：
  - `nest_members()`：電磁鐵組的成員收進 `members`；
  - 從節點狀態補上別台量測節點的虛擬儀器。
- `apps/qt/server/window.py`：
  - 樹狀顯示成員，預設收起，記住展開狀態；
  - 群組的「全部連線 / 全部斷線」包含成員。
- `core/grouping.py`：電磁鐵組的成員可以是通道（`DC5.ch1`），即時監控的電源群組卡片也適用。
- `core/nodes.py`：通道寫法的 sources 也能跟著電源歸屬。
- `apps/qt/workbench/channels.py`：配對的電源在「只顯示常用」時隱藏。
