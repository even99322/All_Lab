# Lab Control 1.0.16

- 發佈日期：2026-10-21
- 類型：新功能（平台模塊下載加入模擬工具）
- 前一版：1.0.15
- 發佈檔：`LabControlHub_v1.0.16.zip`（控制台「從 GitHub 取得新版」會一起拿到）；量測程式本身沒有改

## 摘要（貼到版本說明）

- **模塊下載多了「模擬」**：HFSS 自動化工具（DXF → 3D 模型、S 參數與場型模擬、YIG）。站長把工具的 zip 拖進控制台「發佈更新」，
  Hub 自己認得（`hfss_worker.py` ＋ `config.py` 的 `APP_VERSION`，或 zip 裡的 `qel-module.json` `{"id": "hfss"}`），版本說明取 README 的「版本紀錄」。
- 只有 Python 原始碼 zip 的模塊，首頁直接顯示「⬇ 下載 <版本>」按鈕與安裝方式（以後有 .exe 時一樣顯示 Windows 下載）。
- 發佈的檔名有中文時自動換成英數（例如 `HFSS自動化工具v3.2.zip` → `HFSS_v3.2.zip`），不再「檔名不合法」。
