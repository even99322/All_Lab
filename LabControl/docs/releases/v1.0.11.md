# Lab Control 1.0.11

- 發佈日期：2026-10-15
- 類型：功能＋修正（量測監控的 X / Y 截面、控制台更新論文庫、讀檔程式 1.0.7）
- 前一版：1.0.10
- 發佈檔：`LabControl_Setup_v1.0.11.exe`、`LabControlHub_v1.0.11.zip`

## 摘要（貼到版本說明）

- **量測監控的影像有 X / Y 截面**（像讀檔程式 / Labber 的 2D 圖）：影像上方是藍色橫線那一點的整條曲線（X 截面），
  左邊是紅色直線那個頻率在各掃描點的值（Y 截面），左上角顯示交點的數值。橫線預設跟著最新量到的那一點走，拖過就停在你放的位置；
  工具列「截面」按鈕可以關掉（`monitor.cuts`）。
- **讀檔程式 1.0.7**：.nc 與 Labber .hdf5 互轉（瀏覽器右鍵或「檔案 → 轉檔」，可一次多個；有 Labber Python 用 Labber API，
  沒有用內建寫法）；圖的工具列指標右邊多一個「移動」十字箭頭；F1 指標、F2 移動、F3 分享、F4 局部放大（Viewer 說明改 Shift+F1）；
  一個按鈕打開 2D 的 X / Y 截面；2D 色條標題又看得到了；真正的 Labber 多維檔每一格的位置讀對了。
- **控制台不會再一直顯示「更新中…」**：之前只有按「全部發佈」的那個頁面一直開著才會跟著進度；重新整理或換頁之後就停在「更新中…」。
  現在每次打開控制台都會問控制代理：還在跑就顯示目前的步驟與經過時間（例如「更新中：建置映像…（3 分 12 秒）」）並繼續跟著，
  結束了就顯示成功 / 失敗（失敗時已自動換回舊版）。控制代理重新啟動過、查不到結果時會說明，並請看「線上」版本。
- **論文庫的小更新幾秒就好**：只改程式檔（app/、seed/）的部分更新包（例如論文庫 1.8.0 更新包）不再重新建置 Docker 映像
  （之前要重新 apt / pip 安裝，NAS 上可能 10–30 分鐘），改成：備份程式 → 換程式 → 停止 → 備份資料庫 → 檔案放進容器 → 啟動 → 確認；
  失敗時程式、容器裡的檔案與資料庫都換回。包裡有 Dockerfile、requirements.txt 等會影響映像的檔時照舊完整建置。
