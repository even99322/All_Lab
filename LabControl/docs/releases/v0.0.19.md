# Lab Control 0.0.19

- 發佈日期：2026-10-09
- 類型：外觀和讀檔模塊（LabLogViewer 2.0）一致
- Python：3.12
- 前一版：0.0.18
- 發佈檔：`LabControl_v0.0.19.zip`、`LabControlMonitor_v0.0.19.zip`、`LabControlHub_v0.0.19.zip`

## 摘要（貼到 Lab APP「版本說明」）

- 量測模塊（和 Monitor）的外觀改成和讀檔模塊同一套：
  - 顏色相同：淺色是暖白底、藍灰框線、青藍強調色；深色是深藍黑底、青色強調色；
  - 玻璃質感的按鈕；
  - 同樣的分頁樣式：選中的分頁有底色與強調色底線；
  - 輸入框、表格、選單、提示都相同；
  - 樹狀清單的展開箭頭、數字框上下鍵、下拉箭頭都是同樣的細線箭頭，淺色和深色都看得見。
- 流程圖、即時圖表的底色與線條也換成同一組顏色。
- 淺色 / 深色 / 跟隨系統的切換方式不變。

## 變更

- `labmonitor/style.py`：顏色改用讀檔模塊的 `APP_LIGHT` / `APP_DARK`；新增玻璃按鈕、分頁、箭頭圖示（SVG 存在暫存資料夾）。
- `labcontrol/apps/qt/theme.py`：語意顏色（流程圖、圖表、提示）改成同一組。
- 讀檔模塊的程式沒有改。
