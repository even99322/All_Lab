# Lab Control 0.0.16

- 發佈日期：2026-10-08
- 類型：論文庫「專案」串起量測、數據、論文；讀檔模塊直接開整個專案
- Python：3.12
- 前一版：0.0.15
- 需要：論文庫 1.6 以上（有「專案專區」）
- 發佈檔：
  - `LabControlHub_v0.0.16.zip`
  - `LabControl_v0.0.16.zip`
  - `LabControlMonitor_v0.0.16.zip`
  - `QELLauncher_v0.0.16.zip`（量子工程啟動器）
  - `QELPlatform_NAS_v0.0.16.zip`（NAS 專案設定；0.0.15 已經建好專案的話不用重建）

## 摘要（貼到 Lab APP「版本說明」）

- 量測模塊「檔案設置」多了 **論文庫專案**：
  - 從論文庫既有的專案挑選；
  - 選「＋ 新專案…」可以直接在論文庫建立新專案；
  - 量完的數據上傳到平台時歸到這個專案；
  - 資料夾規則可以用 `{project}`，例如 `{project}/{yyyy}/{mm}/Data_{mmdd}`。
- 「🏷 標籤與論文」：
  - 最上面列出這個專案的數據標籤；
  - 勾選或新建的標籤會記到專案裡。
- 讀檔模塊可以**直接開整個專案**，讀檔模塊的程式完全沒改：
  - 從量測模塊的平台選單、啟動器的「數據與論文」或網頁的「專案」頁按「用讀檔模塊開啟整個專案」；
  - Hub 在 NAS 上為每個專案維護一個資料夾 `LabControlHub/data/projects/<專案>/<量測電腦>/…`（硬連結，不多佔空間）；
  - 電腦看得到 NAS 的 docker 共用資料夾（`\\192.168.50.2\docker`、macOS 的 `/Volumes/docker`）就直接開 NAS 上的資料夾；
  - 看不到時，先同步到這台電腦的 `~/QELData/projects/<專案>`（只下載新的或大小不同的檔案），再開啟。
- 網頁新增「專案」頁：
  - 每個專案的數據數、數據標籤、論文（連到論文庫）、量測數據；
  - 可以新增專案、把標籤加到專案、把數據移到別的專案；
  - 數據目錄可以依專案篩選。

## 新增 / 變更

- Hub：
  - `catalog.project` 欄位；
  - `project_tags` 表（專案的數據標籤；上傳時的標籤自動加入）；
  - 專案資料夾 `data/projects/`（硬連結，失敗時複製；只刪除 Hub 自己建的檔案）。
- Hub 新 API：
  - `GET/POST /api/platform/projects`
  - `GET /api/platform/projects/<id>`
  - `PUT /api/platform/projects/<id>/tags`
  - `GET /api/platform/projects/<id>/files`
  - `PUT /api/platform/catalog/<id>/project`
  - 上傳 `?project=`
- `LABHUB_PROJECTS_SHARE`：各電腦看到的專案資料夾位置；不設定時依論文庫的內網位址自動推算。
- qelcomm 0.0.16：`projects()`、`project()`、`create_project()`、`add_project_tags()`、`set_item_project()`、`project_folder()`、`sync_project()`。
- 量測方案的 `output.lab_project = {id, name}`：
  - 存檔資料夾的 `{project}`；
  - `data.exported` 帶 `project`；
  - 量測節點與本機上傳都歸到專案。
- 量子工程啟動器 0.0.16：
  - 讀檔模塊改用命令列參數開啟：資料夾 → 開成資料庫，檔案 → 單檔；
  - 數據分頁可以選專案；
  - 新訊息 `open_project`。
- 讀檔模塊（LabLogViewer 2.0.0）直接把原本的 zip 丟進發佈中心，不需要改它的程式。
