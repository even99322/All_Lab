# Lab Control 0.0.20

- 發佈日期：2026-10-09
- 類型：量測存檔改成 xarray .nc，不再輸出 Labber
- Python：3.12（新套件：xarray、h5netcdf，App 更新時自動安裝）
- 前一版：0.0.19
- 發佈檔：`LabControl_v0.0.20.zip`、`LabControlMonitor_v0.0.20.zip`、`LabControlHub_v0.0.20.zip`

## 摘要（貼到 Lab APP「版本說明」）

- 量測存成 **xarray / NetCDF（.nc）**；不再需要 Labber，也不需要 Labber 的 Python 3.8 環境。
- 讀法（任何電腦、任何分析腳本）：

  ```python
  import xarray as xr
  ds = xr.open_dataset("run.nc", engine="h5netcdf")
  ds["S21"].sel(Average_Current=158.61, method="nearest").plot()
  abs(ds["S21"]).plot()                       # 2D 圖，軸名、刻度、單位自動帶上
  ds.attrs["tags"], ds.attrs["project"]
  ```

- 檔案內容：
  - 每個掃描軸是一個座標（顯示單位，例如 mA）；
  - 每個量測通道是一個變數（例如 `S21`，複數）；
  - 沒量到的點是 NaN；
  - 另有每點的時間、手動保留點；
  - 量測者、標籤、論文庫專案、註解、完整量測方案都在檔案屬性裡，拖回量測模塊可以套用同樣的設定。
- 「檔案設置」的格式改成「NetCDF（xarray .nc）」與「HDF5（原生）」；Labber 的 Project 欄位拿掉了（專案用論文庫專案）。
- 舊方案裡勾的 Labber 會自動換成 .nc；舊方案的檔名副檔名 .hdf5 會自動換成 .nc。

## ⚠ 讀檔模塊

LabLogViewer 2.0 只讀 Labber 格式，**讀不到 .nc**。用讀檔模塊開專案時，新的量測不會出現。

## 變更

- 新 writer `netcdf`（`labcontrol/data/writers/netcdf.py`）：
  - 點落在掃描格子上 → 維度 = 掃描軸（＋ x 軸）；
  - 不在格子上 → 一維 `point`；
  - 複數用 h5netcdf 直接存。
- 新 reader `netcdf`：`open_dataset("x.nc")` 讀回 Lab Control 的 Dataset。
- 方案編譯：`labber` → `netcdf`；預設格式 `data.default_formats: [netcdf]`。
  量測者、標籤先看 `data.user` / `data.tags`，沒有就用舊的 `labber.user` / `labber.tags`。
- `_raw/` 的逐點原始檔照舊（原生 HDF5，當機不丟資料）。
- 拖放、選檔接受 `.nc`。
