# Lab Control 1.0.14

- 發佈日期：2026-10-21
- 類型：改善（網頁 / 手機的電磁鐵控制改成跟量測程式一樣）
- 前一版：1.0.13
- 發佈檔：`LabControl_Setup_v1.0.14.exe`、`LabControlHub_v1.0.14.zip`（控制台「從 GitHub 取得新版」會一起拿到）

## 摘要（貼到版本說明）

- **電磁鐵頁跟量測程式的「即時數據」一樣**：每個群組左邊 M1–M3、中間成員（master / 跟隨、目前值）、
  目標的每一位數字上下都有 ▲▼ 可以單獨調整（點數字可以直接輸入），目前值與 Range、速率、前往、停止；右邊 ＋ / − 微調與步進。
  速率不填 = 儀器的 ramp_rate，並受量測電腦「全域最大調整速率」限制（跟桌面一樣）。
- **M1–M3 跟桌面一樣**：空的點一下記住 master 目前值；有值的點一下用記憶速率斜坡過去；按住（電腦：右鍵）重記或清除。
- **手機版面**：記憶一排在上、微調一排在下，旋鈕一行放得下（360 px 寬的手機也不會左右捲動）。

## 變更

- `labhub/static/magnet.html` 重寫成桌面卡片的樣子；`remote/node.py` `cmd_magnets` 多回傳 `dial_range`、`max_rate`（舊節點沒有時網頁用預設值）。
