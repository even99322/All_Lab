# Lab Control Hub 1.0.43

- 發佈日期：2026-11-16
- 類型：新功能（網路用量改版、封鎖設備、另一間實驗室、提醒安裝流量監看）
- 前一版：1.0.42
- 搭配：QEL 流量監看 1.0.6

## 摘要（貼到版本說明）

- **網路用量改版**：最上面切換「🏠 內網連線／🔐 VPN 連接」，只顯示即時用量與各設備；每日紀錄、NAS 分析、Hub 流量與限流、
  設定收進下面的分頁。
  - 內網：全網／監看不到／NAS 卡片、每分鐘圖、**各設備一張表**（路由器上的設備＋流量監看的電腦＋NAS 合併）：連線方式、
    是否監看、這段時間的量、目前速率、**使用類型**（內網／外網／VPN／VPN 經外網）；可篩「在線」「沒監看」。
  - VPN：VPN 全部／經外網／DERP 中繼／在線台數，每台 VPN 裝置的路徑（區網直連／外網直連／中繼）與用量；出口節點警告移到這裡。
- **改名**：設備表上直接點名稱改（電腦、路由器上的設備、VPN 裝置都可以），大家都看得到。
- **封鎖上網**（站長）：設備表上「封鎖／解除封鎖」，用 Netgear 路由器的「存取控制」；NAS 不能封鎖，封鎖自己正在用的設備、
  或第一次開存取控制時會再確認。記在操作紀錄。
- **另一間實驗室**（另一個路由器下的網段，華碩路由器）：設定 → 其他實驗室，填網段、路由器位址與帳密、指定那邊一台
  開著 VPN 的「代讀電腦」。代讀電腦每分鐘讀那邊路由器的外網累計與連線設備、經 VPN 帶回；網頁最上面可以切換看哪一間。
  兩間的內網都可能是 192.168.50.x，Hub 用路由器的 MAC 分辨（流量監看 1.0.6 回報）。路由器密碼只存在 Hub 的資料夾，
  只交給代讀電腦（它只放在記憶體）。
- **提醒安裝流量監看**：用電腦開 Hub、而那台沒有流量監看在回報 → 網頁上方橘色橫幅（可「稍後再說」3 天）；
  同一個帳號的推播裝置每天最多一則（通知類別「流量監看提醒」，預設開）。
- NAS 記帳容器（labcontrol-netacct）在 Hub 更新後自己重新啟動讀新程式；「NAS 上誰在用網路」沒資料時顯示容器狀態。
- 流量監看回報的來源 IP 改用真正的來源（經代理時看 X-Forwarded-For）。

## 更新步驟

1. Hub 控制台更新到 1.0.43。
2. 每台電腦的流量監看更新到 1.0.6（會自己更新；圖示換成紅色眼睛）。
3. 另一間實驗室：那邊一台電腦裝流量監看 1.0.6、開著 Tailscale；Hub「網路用量 → 設定 → 其他實驗室」新增、選它當代讀電腦。
