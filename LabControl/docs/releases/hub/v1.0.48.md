# Lab Control Hub 1.0.48

- 發佈日期：2026-11-17
- 類型：修正與小功能（固定 IP 立刻生效、顯示流量監看版本）
- 前一版：1.0.47
- 搭配：QEL 流量監看 1.0.11

## 摘要（貼到版本說明）

- **固定 IP 立刻換過去**：路由器設好手動指定 IP 後，設備要重新取得 IP 才會換（租約更新最晚約 12 小時）。
  - 裝了流量監看的 Windows 電腦：固定 IP 時可以選「立刻換」，或在設備表按「⟳ 立刻換」→ 那台的流量監看
    `ipconfig /renew` 那張網卡（沒換過去再 release + renew），網路斷 1–2 秒；**Lab Control 量測中的電腦等量完再換**。
  - 其他設備（手機、印表機）：重新連線（Wi-Fi 關再開 / 重開機）或等租約更新。
  - 「📌 IP」標示：套用中 / 還沒換過去 / 換 IP 中 / 量測中，等量完再換 / 換 IP 失敗 / 已在用（綠色）。
- **設備表顯示流量監看版本**：「監看中」下面顯示 v1.0.x；不是 Hub 上最新版的標橘色 ⬆。

## 更新步驟

1. Hub 控制台更新到 1.0.48；流量監看會自己更新到 1.0.11。
