# Lab Control Hub 1.0.42

- 發佈日期：2026-11-14
- 類型：新功能（論文庫匯出給 GPT）
- 前一版：1.0.41

## 摘要（貼到版本說明）

- **論文匯出**（導覽列「論文匯出」，`/gptexport`）：依「CCU Magnonics 論文庫分類與匯出規範」1.1 把論文庫整理成
  `CCU_Magnonics_Library_Export/`（zip），給 ChatGPT 匯入：`README.md`（規範 1.1）、`metadata/papers.csv`（24 欄）、
  `notes.csv`、`evidence.csv`、`manifest.json`、`classification_warnings.csv`、`proposed_tags.csv`、`papers/MAG-xxxx__標題.pdf`、
  `notes/MAG-xxxx.md`。論文庫本身不改；Hub 用匯出者自己的論文庫登入讀資料。
  - **範圍**：整個論文庫、某個論文庫分類或專案；**PDF**：全部、只附指定等級、或不附。
  - **Paper ID**：`MAG-0001` 起，依論文庫 id / DOI / arXiv 對到，之後每次匯出不變、不重用；同一個 DOI / arXiv 的
    重複條目併成一篇並警告。證據 ID `EVD-000001` 起，對應論文庫的標註，也固定。
  - **優先 A-D** = 論文庫「關聯性」（規範 1.1 改用同一套定義：A 直接實驗相關、B 實驗方法可移植、C 理論可移植、D 背景）；
    AI 評級在「與本實驗室關聯」註明。**閱讀狀態**一律「未讀」。
  - **分類**：同一頁可以逐篇選 8 個主要主題、勾受控次級標籤、論文類型，存在 Hub（記下誰改的）；論文庫標籤剛好是
    受控字彙的會建議帶入，其他論文庫標籤列在 `proposed_tags.csv`。
  - 論文庫「重點」欄帶入研究問題／物理系統／notes.csv，AI 產生的標「AI interpretation」；公開的劃線標註（原文＋頁碼）
    進 evidence.csv（Verified from PDF）；私人標註不匯出。PDF 的 SHA-256 是實際下載時算的。
  - 匯出後自動驗收（表頭、ID 唯一、主題／標籤字彙、日期格式、PDF 路徑、DOI 不重複、manifest 筆數），頁面顯示
    A–D／主題分布與警告統計。匯出檔只有自己和站長能下載，保留最近 5 個。
