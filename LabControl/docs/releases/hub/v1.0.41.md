# Lab Control Hub 1.0.41

- 發佈日期：2026-11-13
- 類型：新功能（NAS 上誰在用網路）
- 前一版：1.0.40

## 摘要（貼到版本說明）

- **NAS 上誰在用網路**（網路用量頁「NAS」下面，10 分 / 1 小時）：記帳容器（labcontrol-netacct）每 20 秒讀 NAS 主機的
  - **網卡**：每一張（ovs_eth / eth / bond = 實體，tap / vnet = 虛擬機，docker / veth = 容器）收送多少、目前速率；
    即時頁也可以選「NAS 網卡 xxx」看每分鐘圖。SNMP 只讀選定的網卡，漏掉的流量在這裡看得到。
  - **程式 / 容器**：每條連線（NAS 的連線追蹤 conntrack）對到 NAS 上的程式（socket → /proc/<pid>/fd），容器的連線算在容器；
    顯示收送量、其中外網多少、連線數、完整指令。
  - **對方**：跟 NAS 傳最多的位址（區網 / VPN / 外網，外網會反查名稱）、方向、埠、哪個程式。
- 為了有每條連線的 bytes，記帳容器會打開 NAS 的 `nf_conntrack_acct`（只是計數，不擋、不改任何連線）。
- 經 Open vSwitch 直接橋接給虛擬機的流量不經過連線追蹤，看網卡表的 tap / vnet。

## 更新步驟

1. Hub 控制台更新到 1.0.41（控制代理會自動重新啟動記帳容器，大約 1 分鐘後開始有資料）。
