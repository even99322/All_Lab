# Lab Control Hub 1.0.38

- 發佈日期：2026-11-13
- 類型：新功能（每台電腦分 內網 / 外網 / VPN；內網電腦不開 VPN 也能用 https 網址）
- 前一版：1.0.37

## 摘要（貼到版本說明）

- **每台電腦分內網 / 外網 / VPN**（要流量監看 1.0.4）：各台裝置的欄位改成「本月：內網／外網／VPN」——
  內網 = 跟實驗室網段裡的裝置（NAS、別台電腦，不經路由器外網口）；外網 = 經路由器出去的（算進對外流量上限）；
  VPN = Tailscale 的加密封包，另外標出其中「經外網」的（DERP 中繼或直連外面的裝置）。滑過看今天的數字。
  上面多一張卡片「電腦經外網 今天」（外網＋VPN 經外網，全部電腦加總）；「即時」裡電腦那一列也分成三種。
  舊版流量監看照舊顯示「跟 NAS／其中經 VPN／其餘」。
- **內網開 https 網址**：流量監看回報時，Hub 告訴它 https 網域（內網 https 有開時）；流量監看 1.0.4 在實驗室網段時
  把這個網域指到 NAS 的內網位址（Windows hosts 檔，只加自己的一段；離開實驗室網段、結束、解除安裝時拿掉）。
  只接受 `*.ts.net` 網域、實驗室網段裡的位址。手機等沒裝流量監看的裝置仍要靠實驗室 DNS（見 docs/PLATFORM.md 0p）。

## 更新步驟

1. Hub 控制台更新到 1.0.38。
2. 各台 Windows 電腦的流量監看更新到 1.0.4（1.0.3 會自動更新；1.0.2 以前要用管理員身分手動裝一次）。
