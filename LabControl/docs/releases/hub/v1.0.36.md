# Lab Control Hub 1.0.36

- 發佈日期：2026-11-13
- 類型：發佈方式調整（Hub 跟 Lab Control 分開發佈）
- 前一版：1.0.35（跟 Lab Control 1.0.35 一起發佈的最後一版）

## 摘要（貼到版本說明）

- **Hub 改成自己發佈**：GitHub 上 Hub 的新版是 `hub-v<版本>`（LabControlHub_v<版本>.zip ＋ NAS 安裝包），
  Lab Control 的發佈 `labcontrol-v<版本>` 只放 Lab Control 與 Monitor。兩邊版本號各自往上加，
  只改 Hub 就只發 Hub，只改 Lab Control 就只發 Lab Control。
- 控制台「從 GitHub 取得新版」（含自動）多看 `hub-v*` 的發佈。

## 更新步驟

Hub 控制台更新到 1.0.36（之後的 Hub 新版會出現在 `hub-v*` 發佈）。Lab Control 不用更新。
