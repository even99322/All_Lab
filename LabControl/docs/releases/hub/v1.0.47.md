# Lab Control Hub 1.0.47

- 發佈日期：2026-11-17
- 類型：新功能（固定 IP）
- 前一版：1.0.46
- 搭配：QEL 流量監看 1.0.10（代讀電腦）

## 摘要（貼到版本說明）

- **在 Hub 固定設備的 IP**（站長）：網路用量切到其他實驗室（華碩），設備表每台有「📌 固定 IP」，填 IP（預設目前的 IP）
  → 代讀電腦把它寫進路由器的「手動指定 IP」（DHCP 保留，區域網路 → DHCP 伺服器），1 分鐘內套用。
  - 填目前的 IP 立刻生效；換別的 IP，那台重新連線後才拿到。清空 = 取消固定（路由器上原本就有的保留也能取消）。
  - 檢查：要在那間的網段裡、不是路由器自己、沒有指定給別台、現在沒有別台在用。路由器上其他手動設定的保留不動。
  - 設備名稱旁顯示「📌 IP」（套用中 / 已套用）；套用失敗會在上方顯示。
- 本實驗室的 Netgear 沒有可以從外面設定的介面：請到路由器管理頁「進階 → 設定 → LAN 設定 → 位址保留」。
- 登記 QR 碼海報的說明改成用「📌 固定 IP」固定代讀電腦。
