# Lab Control Hub 1.0.40

- 發佈日期：2026-11-13
- 類型：新功能（找出沒被監看的流量）
- 前一版：1.0.39

## 摘要（貼到版本說明）

- **路由器上的裝置**（網路用量頁最下面）：Hub 每 2 分鐘讀路由器的「附加裝置」（有線 / 2.4G / 5G / 訪客，跟路由器管理頁
  同一份），列出每台的名稱、IP、MAC、連線方式、第一次 / 最後看到的時間，並標出有沒有被監看（IP 或電腦名稱對到 NAS、
  流量監看程式）。現在連著卻沒被監看的會在上面用黃色提醒。紀錄留 30 天，晚上偷偷連上來的裝置也看得到。
- **即時「監看不到」**：路由器的量 − 已知的外網量（各電腦流量監看的外網＋VPN 經外網、NAS 直接外網、VPN 中繼）。
  這一塊大 = 有沒被監看的裝置在用、或路由器自己 / 外網口那一側；超過路由器的三成而且超過 50 MB 會變黃色。
  路由器每 2 分鐘才讀一次，1 分鐘的區間不準，看 10 分鐘以上。
