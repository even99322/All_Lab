# Lab Control Hub 1.0.49

- 發佈日期：2026-11-18
- 類型：修正（設備表的監看狀態、記錯的路由器）
- 前一版：1.0.48
- 搭配：QEL 流量監看 1.0.12

## 摘要（貼到版本說明）

- **設備表「監看」與「登記」不一致**：以前路由器上的設備只要名稱跟某台流量監看的電腦一樣，「登記」就顯示監看中，
  但「監看」顯示沒監看。現在：
  - 有流量監看、在這間回報 → 「監看中」＋版本；路由器看得到、但流量監看沒在回報 → 「⚠ 監看沒回報」。
  - 有流量監看、但在別間實驗室回報（或關機）→ 「監看中（不在這裡回報）」，不用登記，不算在「沒監看」。
  - 登記欄的「✔ 監看中」改成「✔ 流量監看」。
- **記錯的實驗室路由器**：電腦的預設路由走另一張網卡（例如 192.168.1.x）時，以前會把那台路由器記成本實驗室的；
  現在閘道不在那間的網段就不記，以前記錯的下次回報時自動拿掉。

## 更新步驟

1. Hub 控制台更新到 1.0.49；流量監看會自己更新到 1.0.12（修好「另一張網卡優先時整台不計算」）。
