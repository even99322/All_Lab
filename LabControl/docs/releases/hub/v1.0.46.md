# Lab Control Hub 1.0.46

- 發佈日期：2026-11-17
- 類型：新功能（流量分析、設備登記）
- 前一版：1.0.45
- 搭配：QEL 流量監看 1.0.9（代讀電腦）

## 摘要（貼到版本說明）

- **流量分析**（網路用量下方第一個分頁，像華碩的 Traffic Analyzer）：最近 24 小時每小時的用量（面積圖）、
  各設備用量（圓餅＋清單），點一台看詳細。
  - 其他實驗室（華碩）：讀路由器的 Traffic Analyzer（代讀電腦每 10 分鐘讀一次），有「Apps」分類與每台設備前 5 名 App。
  - 本實驗室（Netgear 沒有 App 分析）：每小時 = 路由器 Traffic Meter；設備 = 流量監看的電腦（可看那台的每小時、
    內網 / 外網 / VPN）、NAS、監看不到的。
- **設備登記**：沒有備註的手機 / 平板 / 電腦連上網路後要登記（設備名稱、身分：學生 / 老師 / 訪客＋到期日）。
  - 站長在「設定 → 設備登記」逐間打開「強制登記」、設寬限分鐘（預設 15）：寬限時間內沒登記就停網，登記後自動解除；
    訪客到期自動停網。開啟那一刻已經在網路上的設備不受影響（不會擋到正在量測的電腦）；儀器、印表機、認不出類型的不管。
  - 本實驗室用 Netgear「存取控制」停網（要先開）；其他實驗室由代讀電腦用華碩「家長電腦控制」只擋上網（內網照通）。
  - 登記方式：設備自己掃 QR 碼（本實驗室 `http://<NAS>:8765/reg`，不用登入、只能登記自己這台；其他實驗室開在
    代讀電腦 `http://<代讀電腦>:47680/`），或登入 Hub 的人在設備表按「登記」代填。「列印登記 QR 碼」產生海報。
  - 已經在網路用量改過名稱、裝了流量監看、NAS 都算已登記。設備表多一欄「登記」。
- Netgear 的連線設備多記裝置類型 / 型號（判斷手機、電腦）。

## 更新步驟

1. Hub 控制台更新到 1.0.46。
2. 代讀電腦的流量監看會自己更新到 1.0.9（安裝時加防火牆規則讓手機連得到登記頁 TCP 47680）。
3. 華碩路由器打開 Traffic Analyzer（AiProtection / 流量分析 → 流量分析器 → 啟用），資料每小時更新。
4. 要強制登記：網路用量 → 設定 → 設備登記 打開；本實驗室要先開 Netgear 的存取控制。
