# Lab Control Hub 1.0.39

- 發佈日期：2026-11-13
- 類型：新功能（版本紀錄頁）
- 前一版：1.0.38

## 摘要（貼到版本說明）

- **版本紀錄**（導覽列「版本紀錄」，`/versions`，登入的人都看得到）：各程式每一版改了什麼、什麼時候發佈、
  什麼時候上到這台 Hub。分頁：最近更新（全部程式依時間排）、Lab Control、Hub、QEL 流量監看、HFSS 自動化工具、
  LabLogViewer；可以搜尋版本號或內容，「詳細說明」展開完整的版本說明，這台 Hub 目前的版本會框起來。
- 內容來源：打包 Hub 時從 repo 的修改紀錄整理好放進去（`labhub/version_history.json`）；發佈時間與連結來自
  GitHub 發佈紀錄（每小時最多讀一次，連不到 GitHub 就顯示上次的；「↻ GitHub」可以手動重讀）；打包後才發佈的
  新版用 GitHub 的發佈說明。「上線到這台 Hub」= 模塊發佈到平台的時間與發佈人；Hub 自己是那一版第一次啟動的時間
  （從 1.0.39 開始記）。
- Lab Control 的 GitHub 發佈說明開頭會放這一版的修改紀錄（之前只有檔案表）。
