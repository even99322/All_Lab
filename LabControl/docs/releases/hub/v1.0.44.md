# Lab Control Hub 1.0.44

- 發佈日期：2026-11-17
- 類型：修正與小功能（別間實驗室不同網段、移除量測電腦）
- 前一版：1.0.43
- 搭配：QEL 流量監看 1.0.7

## 摘要（貼到版本說明）

- **別間實驗室用不同網段**（例如 328 是 192.168.10.x）：那邊的電腦經 VPN 回報時，閘道（路由器）位址落在
  「其他實驗室」設定的網段、而且這個網段跟本實驗室不重疊 → Hub 直接認得是哪一間、記下那邊路由器的 MAC，
  不用先指定代讀電腦；流量監看 5 分鐘內開始記錄。網段一樣（都是 192.168.50.x）時照舊要靠代讀電腦。
- 「其他實驗室」新增時網段改成空白（不再預填 192.168.50.0/24），範例改成 192.168.10.x。
- **移除量測電腦**（站長）：「量測設置」左邊清單上離線的量測電腦右上角有 ✕，移除清單與紀錄（記在操作紀錄）；
  那台之後再開 Lab Control 的「🛰 量測節點」會自己回來。在線的不能移除。API `DELETE /api/nodes/<名稱>`。

## 更新步驟

1. Hub 控制台更新到 1.0.44。
2. 流量監看會自己更新到 1.0.7（多了 VPN 位址；別間實驗室的電腦要開著 Tailscale）。
