# Lab Control 1.0.6

- 發佈日期：2026-10-14
- 類型：功能（手機 / 平板看數據、背景＋去背開關、即時數據圖表自由排版）＋修正（工具列被遮住、讀檔程式啟動卡住）
- 前一版：1.0.5
- 發佈檔：`LabControl_Setup_v1.0.6.exe`、`LabControlHub_v1.0.6.zip`；讀檔程式 `LabLogViewer 1.0.4`

## 摘要（貼到版本說明）

- **手機、平板看數據**：瀏覽器開 `http://<NAS>:8765/m/data`（VPN：`http://100.114.33.20:8765/m/data`），用論文庫帳號登入。
  一層一層點資料夾、搜尋檔名 / 標籤、只看加星號的；點一個檔就看到 NAS 算好的預覽（2D 熱圖點一下看數值，下面自動畫那個位置的截面）
  與量測參數（掃描範圍、VNA 設定、固定的電源）。上一個 / 下一個切換同一個資料夾的檔。可以「加到主畫面」。
- **背景＋去背開關**：流程圖上方「背景＋去背」打開 → 流程最下面只多一個小方塊。點它，在右邊勾選要設定的電源（不限台數）、
  填背景電流；量背景時 VNA 設定和主量測一樣。原本流程裡的背景 / 去背四個節點，打開開關時會自動收成這一個。範本「2D」改用開關。
- **即時數據的圖表像 VNA 一樣排**：拖曳圖的 ⠿ 或曲線名稱，放到另一張圖**中間 = 疊在一起**、放到**邊緣 = 放旁邊**；
  疊圖和並排可以同時存在（例如 dB＋Phase 疊一張、IQ 另一張）。「全部疊圖」一鍵疊起來；版面可選自動 / 上下 / 左右；下次打開照舊。
- **工具列不再被遮住**：視窗不夠寬時，工具列右邊的按鈕換到第二列。
- **讀檔程式 1.0.4**：開數據集散地時不會再卡住進入「安全復原模式」；切換資料夾更順。
