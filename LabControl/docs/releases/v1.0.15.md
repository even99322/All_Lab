# Lab Control 1.0.15

- 發佈日期：2026-10-21
- 類型：新功能（內網 https；Hub 監測憑證剩餘天數）
- 前一版：1.0.14
- 發佈檔：`LabControlHub_v1.0.15.zip`（控制台「從 GitHub 取得新版」會一起拿到）；量測程式本身沒有改

## 摘要（貼到版本說明）

- **內網也能用 https，而且跟 VPN 同一個網址**：`https://<NAS>.<tailnet>.ts.net:8443`（平台）、`:8444`（論文庫）。
  Hub 向 NAS 上的 Tailscale 取同一張正式憑證，自己在內網 IP 開 https；實驗室 DNS 把這個網址指到 192.168.50.2。
  有開 VPN 的裝置照舊走 Tailscale，沒開的在實驗室裡走內網，網址、App、書籤都一樣。
- **Hub 監測憑證**：控制台「內網 https」卡片顯示剩幾天、到期日、來源、兩個埠的狀態，以及「這台裝置打不打得開」；
  每 12 小時向 Tailscale 取一次（Tailscale 剩 30 天左右會自己續約，換了新的 Hub 熱更新，不用重開）。
  剩 20 天以內（`LABHUB_TLS_WARN_DAYS`）控制台、系統狀態與站長的首頁都會警告；換新會記在稽核紀錄（`tls-renew`）。
- 用 http 開平台的人，如果這台裝置已經連得到 https 網址，首頁會提示「改用 https」。

## 要做一次的設定

見 `deploy/platform/README.md`「加上內網 https」：更新 Hub → docker-compose 加兩個埠與 Tailscale socket → `tailscale serve` 加 8444 →
DNS Server 套件（或路由器）把 ts.net 網址指到 NAS。

## 變更

- 新增 `labhub/lan_tls.py`（`LanTLS`：tailscaled LocalAPI 取憑證、DER 解析有效期間、TLS 埠、論文庫轉送、狀態）。
- API：`GET /api/platform/console/tls`、`POST /api/platform/console/tls/check`（站長）；`/api/platform/me` 多 `https_url`、`scheme`；
  控制台 `status` 多 `tls`。用 https 網域連進來時論文庫連結也給 https 網址。
- `deploy/platform/docker-compose.yml`、`deploy/hub/docker-compose.yml`：`192.168.50.2:8443`、`192.168.50.2:8444`、`/var/packages/Tailscale/var:/tailscale:ro`。
