# 五分鐘上手
> 從一個放量測檔的資料夾開始，到看到曲線、放一個標記、把圖複製進簡報。

## 最短流程
1. **開啟資料庫。** 啟動後在第一個視窗（資料庫瀏覽器）按左上的資料夾圖示 **開啟資料庫**，選放 Labber `.hdf5` 檔的資料夾。 ![](start_open.png)
2. **預覽。** 在中間列表點一筆量測，右側 **快速預覽** 會立刻畫出來。 ![](start_preview.png)
3. **開 Viewer。** 雙擊那一筆，在 Viewer（第二視窗）開啟；左側選 **Y 軸** 與 **轉換**，例如 Magnitude、勾 dB。 ![](start_viewer.png)
4. **讀一個點。** 工具列 **標記工具** 選 **點標記** → **新增** → 點曲線，左側列出它的 X、Y。 ![](start_mark.png)
5. **放進簡報。** 在圖上按 ⌘C（Windows：Ctrl+C），到簡報貼上；或按 **拖曳分享** 直接把圖拖進去。 ![](start_copy.png)

## 接下來
- 2D 掃描：把 **繪圖模式** 改成 2D，見〈2D 熱圖與線切〉。
- 找資料：用星號和標籤，見〈星號與標籤〉。
- 擬合共振：見〈單條 trace 擬合〉。
- 任何視窗按 **F1** 會直接開啟那個視窗的說明。

## 怎麼看這份說明
- **資料夾**（預設樣式）：每個主題是一個資料夾；點開後，裡面的說明會變成一疊卡片。捲動（或按 ↓／空白鍵）時，每張卡片停在頂端，下一張從下方蓋上來；被蓋住的卡片會稍微縮小，疊的厚度與右側進度條表示你讀到哪裡。點圖片可以看原尺寸；按 **Esc** 回到資料夾。
- 搜尋欄下方的 **分頁列** 列出所有主題；點一個主題會列出它的說明，點選即可直接跳到那一篇。搜尋欄會同時搜尋中英文的全部說明。
- 右側按鈕：**全部主題**；**改用清單／資料夾顯示**（同樣的說明，以頁面加折疊段落呈現；正在看的那篇會保持開啟）；**一鍵複製全部說明給 AI**（把所有說明與目前狀態摘要──版本、系統、開啟的視窗，不含資料、路徑與使用者名稱──放進剪貼簿）；**匯出給 AI**（預覽並存成檔案）。

## 你的資料是安全的
LabLogViewer 只讀取量測數值。你做的一切（星號、標籤、標記、擬合…）存在另外的資料夾，唯一的例外是註解會寫進 Labber 自己的註解欄位（見〈資料安全〉）。

## 做不出來時先檢查
- **列表是空的**：資料夾裡沒有 `.hdf5`／`.h5`，或還在掃描，看底部狀態列。
- **雙擊沒有反應**：灰色列的檔案無法解析。
- **⌘C 沒有反應**：先點一下圖。
