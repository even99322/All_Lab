# 開啟與瀏覽資料庫
> 選一個放量測檔的資料夾，程式會在背景掃描所有 HDF5，讓你排序、瀏覽並開啟。

## 最短流程
1. **開啟資料夾。** 瀏覽器左上 **開啟資料庫**（資料夾圖示）或 **檔案 → 開啟資料庫⋯**（⌘/Ctrl+O），選擇放 `.hdf5`／`.h5` 的資料夾（子資料夾也會一起掃）。 ![](db_open.png)
2. **等掃描。** 底部狀態列先顯示「資料庫可使用 — 正在補充 N 個檔案的中繼資料⋯」，這時已經可以操作；完成後顯示「資料庫中繼資料已就緒 — N 個 log」。 ![](db_scan.png)
3. **找到量測。** 左側 **資料夾** 樹點選子資料夾；中間 **資料夾中的 Data** 列出量測：星號、Log 名稱、建立日期、Sweep 維度、標籤。點欄位標題排序。 ![](db_list.png)
4. **開啟。** 單擊選取會在右側 **快速預覽**；**雙擊** 在 Viewer 開啟。 ![](db_open_viewer.png)

## 結果代表什麼
- **Sweep 維度**：例如「1D · 501」是一條 501 點的 trace；「2D · 855 × 501」是 855 條、每條 501 點的掃描。
- **建立日期**：Labber 記錄的建立時間；沒有時用檔案修改時間。
- 灰色的列是無法解析為 Labber log 的 HDF5 檔，滑鼠停在上面會顯示原因。
- 掃描結果會快取；再次開啟同一個資料夾會很快。
- **自動刷新**（預設每 2 秒，**設定 › 一般**）：新增、變動、刪除的量測會自動出現或消失，選取與捲動位置不變。只比對檔案大小與時間，放在共用儲存空間也很省資源；新資料夾最晚 30 秒內出現。Labber 還在寫入的檔案會先以檔名列出，能讀取時再讀。**重新載入**（⌘/Ctrl+R）仍可一次重新掃描全部。
- **開啟資料**：第一次在 Viewer 開啟的量測，若有掃描會直接顯示 **2D** 熱圖（只有一條 trace 則顯示 1D）；操作過的資料會回到上次離開時的樣子。

## 選項與參數
- **右鍵選單**：加星／取消星號、編輯標籤⋯、重新命名檔案⋯、開啟。
- **新增資料夾**：在 **資料夾** 樹上對資料夾按右鍵（對空白處按則是最上層）→ **新增資料夾⋯**，或 **檔案 → 新增資料夾⋯**（⌘/Ctrl+Shift+N）建在目前選取的資料夾裡。名稱不能含 / \ : * ? " < > |，也不能以句點開頭。空的資料夾也會顯示。名稱已被使用時可以選 **兩者都保留**（「名稱 (2)」）或取消；既有資料夾不會被取代。
- **重新命名檔案⋯**：只改檔名（副檔名保留），該檔案的星號、標籤、註解、標記、視圖等紀錄會一起跟著新檔名。重新命名前要先關閉這筆資料的 Viewer。若已有其他檔案叫這個名字，可以選 **兩者都保留**（改成「名稱 (2)」）或取消；不會取代另一個量測檔。
- 程式關閉後再開，會回到上次的資料庫與選取位置。

## 做不出來時先檢查
- **列表是空的**：資料夾裡沒有 `.hdf5`／`.h5`，或還在掃描；看狀態列。
- **「無法掃描此資料夾」**：沒有讀取權限，或是雲端資料夾尚未下載；確認檔案真的在本機。
- **某筆顯示灰色**：不是 Labber 格式，或檔案損毀（例如擷取中斷）。
- **「資料庫忙碌中」**：掃描還沒完成時不能重新命名，稍等再試。
- **大型網路資料夾很慢**：第一次掃描需要讀每個檔案的中繼資料；之後會使用快取。
