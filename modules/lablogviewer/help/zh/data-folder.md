# 資料夾（歷史紀錄）
> 你在 LabLogViewer 裡做的一切（星號、標籤、標記、擬合、個人化…）都存在一個叫 LabLogViewerData 的資料夾，可以搬到你想要的位置。

## 最短流程
1. **看目前位置。** **設定 → 一般 → 資料夾位置**：顯示目前路徑；**顯示資料夾** 在 Finder／檔案總管中開啟。 ![](data_folder.png)
2. **換位置。** 按 **變更位置...** 選新的位置（程式會在那裡建立 LabLogViewerData）。
3. **重新啟動。** 程式詢問是否現在結束；**下次啟動時** 所有紀錄會一次搬過去，舊位置清空。設定頁在搬移前顯示「將於下次啟動搬移至 …」。
4. **恢復預設。** **使用預設** 搬回預設位置。

## 預設位置
- macOS：`~/Documents/LabLogViewerData`（若「文件」資料夾被 iCloud 同步，改用 `~/LabLogViewerData`）。
- Windows：`C:\Users\<使用者>\LabLogViewerData`。

## 裡面有什麼
| 位置 | 內容 |
|---|---|
| `state/` | 星號、標籤、註解（外部）、標記、轉換、疊圖、視圖、工作階段、資料庫快取、設定、個人化、拖曳分享暫存、收到的量測 |
| `fitting/` | YIG 擬合的工作階段、模型庫、參數設定 |
| `logs/` | 程式沒回應時的診斷報告 |
| `licenses/` | 已安裝的授權檔 |
| `lablogviewer_data.json`、`README.txt` | 資料夾標記與說明 |

## 結果代表什麼
- 這個資料夾就是你的「歷史紀錄」。換電腦時把整個資料夾複製過去，再用 **變更位置...** 指向它，就能延續所有紀錄。
- 搬移發生在下次啟動、任何紀錄被開啟之前，所以關閉時才寫入的資料也不會遺漏。
- 從舊版升級時，舊位置的資料會被**複製**進來，原本的檔案保留作為備份。

## 把歷史紀錄搬到新的 LabLogViewer 或新電腦
**設定 › 關於 › 授權⋯ › 資料轉移⋯**（授權含「資料轉移」時才會出現）。它會把舊資料夾中的星號、Tags、註解、Mark、視圖、3D 視圖、YIG 工作階段、公式庫、設定與主機名稱複製到這個程式的資料夾，並讓紀錄跟著搬家或改名後的量測檔。
1. 選 **舊的資料夾**，以及 **量測檔現在所在的位置**（會自動填入瀏覽器目前開啟的資料庫；星號與 Tags 是依開啟的資料庫記錄的，所以要選同一個最上層資料夾）。
2. 按 **比對**（不會寫入任何東西）。**內容相同**：檔案的 SHA-256 一致，會搬過去；**檔名與大小相同**：沒有比對內容，確定是同一個檔才勾選；**找不到**：紀錄留在舊路徑下。
3. 對應錯了或找不到：選那一列，按 **手動指定新檔案⋯**。比對為 **內容相同** 或 **結構相同**（通道與掃描大小一致）時，所有紀錄都可以轉移；若 **差異過大**，必須勾選免責聲明，而且只能轉移星號、Tags 與註解──Mark、視圖、3D 視圖與 YIG 工作階段依賴資料的通道與座標軸，會留在舊路徑下。
4. 按 **開始轉移**。會關閉 Viewer 視窗、先備份資料夾（`migration_backups`，含報告），轉移完成後 LabLogViewer 自動重新開啟。按 **復原上一次轉移** 可以還原。
- 兩邊都有同一個檔案的紀錄時，預設保留這個資料夾的；設定只補缺少的部分。
- 舊資料夾與量測檔只會被讀取。

## 雲端資料夾
- 不建議把資料夾放在 iCloud、OneDrive、Dropbox、Google Drive 等同步資料夾：多台電腦同時寫入可能造成紀錄衝突或遺失。
- 選到雲端資料夾時程式會警告；你必須勾選同意「若歷史紀錄遺失由使用者自行負責」才能繼續。

## 做不出來時先檢查
- **「該資料夾已經有 LabLogViewer 資料」**：可以選擇直接使用那裡的資料（目前的資料夾不會被改動）。
- **搬移失敗**：新位置沒有寫入權限或空間不足；程式會繼續使用原位置並提示。
- **紀錄不見了**：確認 **資料夾位置** 指向你原本的資料夾。
