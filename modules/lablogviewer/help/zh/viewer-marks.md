# 標記與局部分析
> 在圖上放標記讀出精確數值，並在標記附近自動找峰、谷或半峰寬。

## 最短流程
1. **選標記工具。** 工具列 **標記工具** 選 **點標記**（也可選 範圍、水平線、垂直線、十字線）。 ![](marks_tool.png)
2. **放到圖上。** 按 **新增**（按鈕變成「點擊圖表⋯」），在曲線上點一下。點標記會吸附到最近的資料點，標上 M1、M2…；**範圍** 需要點兩下（起點、終點）。 ![](marks_place.png)
3. **讀數值。** 左側 **標記** 區列出所有標記與其 X、Y 值；勾 **在圖上顯示數值** 會在圖上直接標出。拖曳標記可以移動它。 ![](marks_values.png)
4. **局部分析。** 左側 **局部分析**：**區域** 選「Around Selected Mark」（或其他）、**運算** 選 Peak／Trough／Half-Peak…，選取一個目標標記後按 **尋找**。結果會放一個點標記在找到的位置，並在下方列出數值。 ![](marks_analysis.png)

## 結果代表什麼
- **Local Maximum／Local Minimum**：區域內的最大／最小值（就是那個樣本點，不做內插）。
- **Peak／Trough**：區域內「顯著度」最大的局部峰／谷；**Prominence** 是它高出（或低於）兩側較高底部的量。
- **Half-Peak**：取區域兩端各 10% 點的中位數當 **Baseline**，找出離基線最遠的峰或谷，**Half Level** = 基線與極值的中點，**Left／Right** 是曲線穿過半高的位置（線性內插），**Half-Level Width** = Right − Left。
- **注意單位：** 半高是在「目前顯示的 Y 單位」中計算。在 dB 顯示下得到的是 dB 深度一半的寬度，不等於線性振幅或功率的半高寬（FWHM）；需要線性的半高寬時，請先取消 **dB** 再分析。Half-Peak 只接受 Magnitude 或 Magnitude + dB。
- 數值來自畫面上的資料（包含轉換與公式），原始檔不變。

## 選項與參數
**標記工具**
- **點標記**：最多 10 個（M1–M10），吸附到資料點；狀態顯示「N 個物件（x / 10 個點標記）」。
- **範圍**：兩點之間的一段，可作為局部分析的區域。
- **水平線／垂直線／十字線**：讀取某個 Y 或 X 值，十字線同時讀兩者。
- **刪除** 移除選取的標記；**清除工具** 移除全部。

**局部分析的區域**
- **Auto Nearby Feature**：以選取的點標記為中心，在兩側各最多 5%（至少 20、最多 500 個點）內找最近的明顯特徵；第一次按 **尋找** 會先預覽區域，確認後再按一次。
- **Around Selected Mark**：以標記為中心的固定視窗（**Window** 點數）。
- **Selected Range**：使用選取的範圍標記。
- **Between Two Marks**：兩個標記之間。
- **Current Visible X Range**：目前畫面看得到的 X 範圍。
- **預覽區域／清除預覽**：先在圖上看要分析的區間。

## 儲存
標記會依資料自動記住，下次開同一個檔案還在（存在資料夾的 `state/marks.json`）。

## 做不出來時先檢查
- **「沒有空的點標記（M1–M10 都已使用）」**：刪掉用不到的點標記。
- **「No nearby feature found」**：附近沒有夠明顯的峰谷；改用 Selected Range 並把範圍拉到特徵兩側。
- **「Ambiguous half-level feature」**：區域內有兩個一樣深的特徵；縮小範圍只包含一個。
- **「No valid left/right half-level crossing」**：範圍太窄，曲線在一側沒回到半高以上；擴大範圍。
- **標記工具不能用**：只有 1D 與 2D 模式支援標記。
