# 1D 圖、Trace 與轉換
> 選擇 X／Y 通道、在 trace 之間切換、把複數資料轉成 Magnitude、Phase 或 dB，並同時比較多條 trace。

## 最短流程
1. **開啟量測。** 在瀏覽器雙擊一筆量測，或在 Viewer 用 **檔案 → 開啟**（⌘/Ctrl+O）。**繪圖模式** 預設是 **1D 繪圖**。 ![](v1d_open.png)
2. **選軸與轉換。** 左側 **繪圖設定**：**X 軸**（通常是 Frequency）、**Y 軸**（例如 VNA - S21）、**轉換**（Magnitude、Phase、Real、Imaginary…）。勾 **dB** 顯示 20·log10|S|；Phase 可勾 **相位展開** 去掉 ±π 跳躍。 ![](v1d_axes.png)
3. **切換 trace。** 圖下方的 Log 項目表每列是一條 trace（一個 Sweep 點）；點一列即顯示它，或用 ↑／↓ 鍵，或在 **Sweep（跳至項目）** 輸入編號。標題顯示 **Trace 目前 / 總數**。 ![](v1d_traces.png)
4. **疊圖比較多條。** 在 Log 項目表 Shift＋點選選一段、⌘/Ctrl＋點選加減單條。被選的 trace 會一起畫出，**Trace 顏色** 選 Sequential（依順序漸變）、Distinct（區分色）或 Single Color；狀態列顯示「已選 N · 顯示 M」。 ![](v1d_overlay.png)

## 結果代表什麼
- **Magnitude** 是 |S| 的線性值；勾 **dB** 後是 20·log10|S|。兩者只是顯示方式，原始資料不變。
- **Phase** 以度或弧度顯示；**相位展開** 只是把相鄰點的 2π 跳躍接起來，會改變顯示的絕對值（差 2π 的整數倍），比較不同 trace 的相位時要注意。
- 每條 trace 對應 Log 項目表的一列；表中的欄位（例如 Average Current）是那條 trace 的掃描參數值。
- 若只擷取到部分 Sweep，狀態列會顯示「部分擷取：顯示 N / M 個 Sweep」。

## 選項與參數
- **座標軸預設**：把目前 X／Y／轉換存成一個名字（**儲存座標軸預設⋯**），之後下拉選單一鍵套用；可 **更新**、**重新命名**、**刪除**。預設是依資料記住的。
- **視圖預設**：記住整個 Viewer 的顯示狀態（模式、軸、範圍…），用 **儲存視圖預設⋯** 與下拉選單切換。
- **顯示資料點**、**點大小**（自動／手動）：除了線，也畫出每個量測點。
- 自訂轉換：在 **轉換** 選單可以使用或管理自訂轉換；只影響顯示。
- 公式：要把 X 或 Y 換算（例如 x/1e9、20·log10|y|），見〈公式〉。

## 做不出來時先檢查
- **Y 軸選單沒有想要的通道**：該通道可能不是向量 trace；Log 通道（每個 Sweep 一個值）請用 2D 或把它設成 X 軸。
- **「無法互相作圖」訊息**：X 與 Y 屬於不同的變化範疇（一個每個 Sweep 一個值、另一個在 trace 內變化）。請選同一範疇的兩個軸。
- **相位看起來鋸齒狀**：勾 **相位展開**；或是頻率點太稀疏。
- **dB 出現 -inf 或斷線**：|S| 有 0 或非有限值，這些點會空著顯示。
- **疊太多條看不清**：減少選取，或把 **Trace 顏色** 改成 Distinct。
