# 2D 熱圖與線切
> 把整個掃描畫成一張熱圖，調整色彩圖與色彩範圍，並用 X／Y 線切看某一條剖面。

## 最短流程
1. **切到 2D。** 開啟一個有 Sweep 的量測後，把工具列的 **繪圖模式** 改為 **2D 繪圖**。 ![](v2d_mode.png)
2. **選 Z、X、Y 與轉換。** 左側 **繪圖設定**：**Z** 選要上色的通道（例如 VNA - S21）、**X** 通常是 Frequency、**Y** 是掃描參數（例如 Average Current）；**轉換** 選 Magnitude 或 Magnitude (dB)、Phase…。 ![](v2d_axes.png)
3. **調整顏色。** 同一區：**色彩映射** 選配色（預設 LabLog BWR，另有 CoolWarm、bwr、viridis、plasma、inferno、magma、gray）；勾 **自動** 讓範圍自動決定，或取消後輸入 **最小值／最大值**，也可以直接拖曳右側色條兩端的控制點。 ![](v2d_color.png)
4. **看剖面。** 移動滑鼠時十字線會讀出 X／Y／Z；工具列 **顯示** 按鈕 → **顯示 X 切線** 或 **顯示 Y 切線** 開啟剖面視窗，勾 **跟隨主圖** 時剖面會跟著十字線位置更新。 ![](v2d_cut.png)

## 結果代表什麼
- 每一橫列是一條 trace（一個 Y 值），顏色是該點的 Z 值經過轉換後的大小；色條標示數值與單位。
- **X 切線**：固定 Y，看 Z 隨 X 變化（就是那條 trace 的 1D 圖）；**Y 切線**：固定 X（例如某個頻率），看 Z 隨掃描參數變化。
- 色彩範圍只影響顏色對應，不改變資料；把範圍收窄可以凸顯弱訊號，但範圍外的值會被截成最深或最淺的顏色。
- 非有限值（NaN、Inf）以空白顯示。

## 選項與參數
- **自動範圍** 按鈕：依目前資料重新計算色彩範圍。
- 剖面視窗：**永遠置頂** 讓它浮在最上面；剖面的座標會記在視圖預設中。
- 2D 也可以放 **標記**（點標記、範圍、十字線…）並做局部分析，見〈標記與局部分析〉。
- 要看 3D 曲面或瀑布圖，用 **分析 → 3D 曲面⋯**（見〈3D 曲面〉）。
- 匯出 2D 數值時會輸出完整的有效網格（見〈複製、儲存與匯出〉）。

## 做不出來時先檢查
- **看不到 2D 選項或圖是空的**：這筆資料只有一條 trace（沒有 Sweep），只能用 1D。
- **「無法建立 2D 曲面」**：X 或 Y 的值不是規則網格，或 X、Y 選了同一個維度；換一組軸。
- **顏色幾乎全同一色**：有極端值把範圍撐大；取消 **自動** 手動設範圍，或改用 dB。
- **剖面不跟著動**：確認勾了 **跟隨主圖**，並把滑鼠移到熱圖上。
