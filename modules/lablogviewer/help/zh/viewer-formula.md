# 公式
> 用運算式換算 1D 圖的 X 或 Y（例如 Hz → GHz、線性 → dB、除以某個值），只改變顯示，不會改到檔案。

## 最短流程
1. **找到公式區。** Viewer 左側 **公式**（只在 1D 模式出現）。上方 `x = F(x, y)`、下方 `y = G(x, y)`。 ![](formula_panel.png)
2. **輸入運算式。** 例如 X 填 `x/1e9`、Y 填 `20*log10(|y|)`。輸入時下方的預覽框會以一般數學寫法即時顯示（分式、根號、絕對值）。留白代表該軸不變。 ![](formula_preview.png)
3. **套用。** 按 **套用**。狀態顯示「公式已套用到目前顯示的 X／Y 值」，圖立即更新。 ![](formula_applied.png)
4. **恢復。** 按 **重設** 讓兩軸回到原始值。

## 結果代表什麼
- `x`、`y` 是**目前顯示**的值——已經過 **轉換**（Magnitude、Phase…）與 **dB** 之後的數值。例如已勾 dB，再寫 `20*log10(|y|)` 會重複取 dB。
- 公式只影響目前（作用中）窗格的顯示；標記、局部分析、以及匯出時選「Displayed Data」都會使用換算後的值；選「Raw Data」匯出則不受影響。
- 原始 HDF5 檔永遠不會被修改；公式與 Viewer 的顯示狀態一起記住，下次開同一個檔案還在。

## 可以用的寫法
- 變數：`x`、`y`；常數：`pi`、`e`（也接受 `np.pi`）。
- 運算：`+ - * /`，次方 `^` 或 `**`，絕對值 `|y|` 或 `abs(y)`。
- 函數：`sqrt`、`log10`、`ln`、`log`（自然對數）、`exp`、`sin`、`cos`、`tan`、`abs`。
- LaTeX：`\frac{y}{x}`、`\sqrt{x}`、`\left|y\right|` 等也可以。
- 為了安全，只允許數學；任何 Python 函式呼叫、屬性、import 都會被拒絕。

## 例子
| 目的 | 填入 |
|---|---|
| 頻率 Hz → GHz | X：`x/1e9` |
| 線性振幅 → dB | Y：`20*log10(|y|)`（先確認沒勾 dB） |
| 正規化到某個參考值 | Y：`y/0.35` |
| 功率 | Y：`y^2` |
| 相位 rad → 度 | Y：`y*180/pi` |

## 做不出來時先檢查
- **看不到公式區**：公式只適用於 1D 圖；把 **繪圖模式** 切回 1D。
- **錯誤訊息（紅字）**：運算式寫錯或用了不允許的名稱；訊息會指出哪個名稱。
- **出現空白或斷線**：例如對負值取 `log10` 或 `sqrt`、除以 0，這些點會變成非有限值而不畫。
- **「儲存的公式無效，已還原為原始值」**：之前存的公式在新版不再合法，已自動清除。
