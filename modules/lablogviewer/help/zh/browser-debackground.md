# 去背景
> 把目標量測的複數 S 參數逐點除以一條背景 trace（例如沒有樣品時量的傳輸線響應），產生一個新的 `_debg.hdf5` 檔。

## 最短流程
1. **開啟。** 在瀏覽器先選目標量測，按工具列 **去背景**（或 **處理 → 去背景⋯**）。**目標資料** 會自動帶入選取的檔案。 ![](debg_open.png)
2. **選背景。** **背景資料** → **選擇⋯**，從資料庫挑一條背景量測（必須是單一 trace）。 ![](debg_background.png)
3. **確認相容性。** 選 **S 參數**，**相容性檢查** 七項會逐一變成通過：S 參數、目標、背景形狀、頻率點數、頻率網格、頻率範圍、分母。 ![](debg_checks.png)
4. **產生。** **輸出** 預設為「目標檔名_debg.hdf5」放在目標旁邊；按 **產生**。完成後資料庫自動更新，並直接在 Viewer 開啟新檔案；它會因檔名含 _debg 而自動得到 **De-background** 標籤。 ![](debg_done.png)

## 資料條件
- 目標：一個複數 S 參數，頻率 × Sweep（1D 或 2D 皆可）。
- 背景：同一個 S 參數名稱、**一條** 複數頻率 trace。
- 兩者頻率點數相同、頻率單位相同、同方向排序，每一點頻率差在很小的數值容忍度內（檢查會顯示最大差 Δ 與容忍度），起訖頻率相同。
- 背景不能有 NaN、Inf 或 0；背景最小 |BG| 必須大於數值下限（約峰值 × 1.5×10⁻⁸），否則 **分母** 檢查不通過、無法產生。

## 結果代表什麼
- 對每個 Sweep：S_debg(f) = S_target(f) ／ S_background(f)，複數相除——同時扣掉背景的振幅與相位。|S| 在 dB 下等於「目標 dB − 背景 dB」。
- **精度（重要）：** 為了與舊版 Labber 的 `_debg` 檔完全相容，輸出的實部與虛部以 float16 精度量化後再以原本的 float64 格式儲存，約 **3 位有效數字**（相對誤差約 10⁻³）。做精細擬合或需要更高精度時，請在分析中直接使用原始目標與背景，不要依賴 `_debg` 檔的最後幾位數。
- 輸出檔是目標檔的完整複本，只有所選 S 參數被替換；其他通道與中繼資料保持不變，Labber 可以直接開啟。
- 原始目標與背景檔都不會被修改；輸出不能覆蓋這兩個檔。

## 選項與參數
- **輸出 → 選擇⋯**：換位置或檔名（必須是 `.h5`／`.hdf5`）。
- **輸出檔名已經有檔案時** 會詢問：**覆蓋**（取代它）、**兩者都保留**（新檔存成「名稱 (2).hdf5」，預設選這個）、**另選⋯** 或 **取消**。目標與背景檔永遠不能當輸出。
- **輸出到 NAS／共用資料夾** 也可以：這類共用磁碟不支援平常用來完成輸出的「硬連結」，程式會改成再檢查一次同名後，把暫存檔改名成正式檔名。
- 處理在背景進行，可以按 **取消處理**；取消時不會留下不完整的檔案（先寫暫存檔，完成才換名）。
- 視窗是非模態的，處理時可以繼續用瀏覽器（但不能重新命名檔案）。

## 做不出來時先檢查
- **「產生」是灰色**：看 **相容性檢查** 哪一項不是通過，右側文字說明原因。
- **頻率網格不符**：兩個量測的頻率設定不同（點數、起訖或單位），需要用相同設定重新量背景。
- **背景形狀不符**：背景是 2D 掃描；請選一條單 trace 的背景。
- **分母接近 0**：背景在某個頻率振幅幾乎為 0（例如背景量測失敗），不能拿來當分母。
- **「比例超出舊版相容的儲存範圍」**：相除後的值超出 float16 可表示範圍（約 6.5×10⁴），通常代表背景振幅過小。
- **完成後找不到新檔案**：資料庫更新時找不到它，確認輸出路徑是否在目前資料庫之內。
- **「Could not safely publish without replacing an existing file: [Errno 45] Operation not supported」**（1.0.3 以前的版本、輸出在 NAS 上）：請更新；或先輸出到本機資料夾，再複製過去。
