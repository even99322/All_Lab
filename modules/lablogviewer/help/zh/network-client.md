# 加入 Host
> 唯讀跟隨同一網路中另一台 LabLogViewer 的畫面。

## 最短流程
1. **打開網路工作區 → Client 分頁。** 同一網路中的 Host 會自動列出；可在搜尋框輸入主機名稱或工作階段名稱篩選。 ![](net_client_list.png)
2. **找不到時手動輸入。** 在 **或輸入位址** 填 Host 的 IP（例如 `192.168.1.20`，或加上連接埠 `192.168.1.20:47811`）。
3. **加入。** 選 Host、輸入 **加入碼**，按 **連線**。 ![](net_client_join.png)
4. **跟隨。** 會開啟 Host 的 Viewer 鏡像（與 YIG 分析鏡像），標題寫「正在跟隨 …（唯讀）」。按 **離開** 結束。 ![](net_client_mirror.png)

## 結果代表什麼
- 連線期間你的 LabLogViewer 是**唯讀**的：鏡像視窗跟著 Host 變化，不能操作。
- 從 Host 收到的資料只放在記憶體，離開後清除；狀態列顯示資料來源（「資料：來自 Host（僅記憶體）」或「資料：本機」）。
- 若 Host 送了永久副本，你會收到通知，檔案存在你的資料夾 `state/received/`。

## 選項與參數
- **共用資料夾⋯**：如果這台電腦也讀得到同一批檔案（例如共用儲存空間），設定後會直接讀本機檔案而不必下載，速度較快。
- 連線中斷時會自動重新連線（狀態顯示「重新連線中」）。

## 做不出來時先檢查
- **列表是空的**：兩台不在同一個網路（子網路），或該網路擋掉自動搜尋；改用手動輸入 IP。
- **加入碼錯誤**：同一台電腦 1 分鐘內輸錯 5 次會被暫時拒絕，等 1 分鐘再試。
- **「品質太差」無法加入**：延遲超過 200 ms 或速度低於 1 MB/s；見〈品質、安全與限制〉。
- **Host 已滿**：一個 Host 最多 5 台 Client。
