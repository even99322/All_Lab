# 網路問題
> 找不到 Host、加不進去、畫面不同步時，依序檢查這些。

## 最短流程
1. **確認同一個網路。** 兩台電腦要在同一個子網路（通常是同一個 Wi-Fi 或同一個交換器）。不同網段會被拒絕。 ![](trouble_network.png)
2. **找不到 Host 就手動輸入。** 有些網路會擋掉自動搜尋；在 Client 分頁 **或輸入位址** 填 Host 的 IP（Host 電腦的網路設定可以看到）。
3. **Windows 防火牆。** Host 是 Windows 時，第一次主持要在系統詢問中選 **私人網路** 並允許；若當時按了取消，到 Windows 防火牆設定中允許 LabLogViewer。
4. **看品質。** 狀態列顯示「太差」時（延遲 > 200 ms 或速度 < 1 MB/s）無法加入；改用有線或靠近基地台。

## 訊息代表什麼
| 訊息 | 意思 |
|---|---|
| 加入碼錯誤 | 重新確認 6 位數；1 分鐘內錯 5 次會被暫停 1 分鐘 |
| Host 已滿 | 已有 5 台 Client |
| 版本不相容 | 兩邊 LabLogViewer 版本的通訊格式不同，請更新到同一版 |
| 重新連線中 | 網路短暫中斷，會自動恢復 |
| Host 正在看 3D | 3D 不同步，等 Host 回到 Viewer |

## 做不出來時先檢查
- **公司／學校網路完全連不上**：有些網路隔離裝置之間的連線（Client isolation），需要換網路。
- **傳送量測失敗**：確認對方已按 **接收**，連接埠一致（見〈快速預覽、註解與接收〉）。
