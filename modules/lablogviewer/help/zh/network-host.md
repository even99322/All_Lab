# 主持連線
> 在同一個網路裡，讓最多 5 台電腦即時唯讀跟隨你的 Viewer 與 YIG 分析畫面（例如組會或遠端討論）。

## 最短流程
1. **打開網路工作區。** 任何視窗最上方選單 **網路工作區**，或點頂端的網路狀態列。第一次會請你替這台電腦取名字（任何語言皆可，之後可按 **重新命名⋯**）。 ![](net_host_open.png)
2. **開始主持。** **Host** 分頁：填 **工作區 / Session** 名稱（例如「週二組會」）→ **開始主持**。畫面顯示 6 位數 **加入碼**。 ![](net_host_start.png)
3. **告訴要加入的人加入碼。** 他們照〈加入 Host〉操作。**已連線的 Client** 列出每一台與它的連線品質。 ![](net_host_clients.png)
4. **正常工作。** 你正在使用的 Viewer（包含切換 trace、軸、標記──點、範圍、線、十字線與半高寬結果，移動或清除也會同步──以及畫筆註記）與它的 YIG 分析視窗會同步到每台 Client。結束時按 **停止主持**。

## 結果代表什麼
- Client 看到的是你的畫面的鏡像，只能看、不能改；你的資料與設定不會被 Client 改動。
- Client 需要的量測資料會在需要時傳過去，只存在對方的記憶體中，對方離開後清除——除非你主動送出永久副本。
- 3D 視窗不會同步；你切到 3D 時 Client 會看到提示。
- 頂端狀態列隨時顯示「主持中 · N / 5 位 Client」與品質。

## 選項與參數
- **送出永久副本...**：選一台 Client，把目前的 HDF5 檔送給它，存在對方資料夾的 `state/received/`（會先確認，並以校驗碼檢查完整性）。只有 Host 能送出副本。
- 加入碼每次開始主持都會重新產生。

## 做不出來時先檢查
- **「無法開始主持」**：通常是連接埠 47811 被佔用或網路不可用；訊息會寫原因。
- **Windows 第一次主持**：系統會詢問是否允許 LabLogViewer 接受連線，請選 **私人網路** 並按允許，否則別人連不進來。
- **「在 Viewer 開啟量測即可分享」**：先開一個 Viewer。
- **Client 連不上**：見〈網路問題〉。
