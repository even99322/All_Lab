# 快速預覽、註解與接收
> 選一筆量測就能在右側看到內容；寫下註解；或把量測傳給另一台電腦上的 LabLogViewer。

## 最短流程
1. **預覽。** 在 **資料夾中的 Data** 點一筆，右側 **快速預覽** 會畫出它：1D 是曲線，2D 是熱圖；上方顯示 Log 名稱與通道，移動滑鼠讀 X／Y／Z。 ![](preview_show.png)
2. **寫註解。** 右下 **備註** 區直接輸入；停止輸入後會自動存檔，狀態列顯示存到哪裡。 ![](preview_comment.png)
3. **（選用）接收量測。** 在接收的電腦按 **接收**，會開始在 **接收端 TCP 連接埠**（預設 53117）等待。 ![](preview_receive.png)
4. **（選用）傳送量測。** 在傳送的電腦把 **接收端** 填成對方的 IP、連接埠相同，然後把列表中的一筆量測拖到 **把量測拖到這裡傳送** 區域放開。

## 結果代表什麼
- 快速預覽只是縮略顯示，完整功能（轉換、標記、匯出）請雙擊在 Viewer 開啟。
- **註解存在哪裡**：先嘗試寫入 HDF5 檔中 Labber 自己的 `comment` 欄位（與 Labber 顯示的是同一份），狀態列顯示「已儲存 Labber 原生 Comment」。檔案沒有這個欄位或文字超過它的固定長度時，改存到你的資料夾（`state/comments.json`），狀態列顯示「已儲存外部註解」。這是 LabLogViewer 唯一會寫入量測檔的地方，而且只改這個文字欄位，不動任何量測數值。
- 若同時有舊版 LabLogViewer 的外部註解與不同的 Labber 註解，兩者都會保留，不會合併。
- **接收到的量測** 存在資料夾的 `state/received/`，狀態顯示「已接收：檔名」。傳送的是整理好的量測內容（不是可執行的檔案）。

## 做不出來時先檢查
- **預覽一直空白**：大型 2D 檔第一次需要讀取時間；灰色列的檔案無法預覽。
- **「請等此資料的快速預覽完成後再試一次」**：預覽還在讀檔時不能重新命名。
- **傳送失敗**：兩台必須在同一個網路、對方已按 **接收**、IP 與連接埠正確；防火牆可能擋住連接埠。
- **「接收端主機無效」**：IP 或主機名稱含空白或留空。
- **註解存成外部**：屬正常情況（檔案沒有 Labber 的 comment 欄位），內容一樣會保留並跟著檔案重新命名。
