# 鍵盤與滑鼠
> 所有快捷鍵與滑鼠操作一覽。

## 最短流程
1. **任何視窗按 F1**：開啟那個視窗的說明。 ![](shortcuts.png)
2. **複製圖**：在圖上 ⌘C（Windows：Ctrl+C）。
3. **放大後退回**：右鍵或 Esc。

## 鍵盤
| 動作 | Mac | Windows |
|---|---|---|
| 開啟資料庫（瀏覽器）／開啟檔案（Viewer） | ⌘O | Ctrl+O |
| 重新載入 | ⌘R | Ctrl+R |
| 複製圖表 | ⌘C | Ctrl+C |
| 複製所有窗格 | Control+Shift+C | Ctrl+Shift+C |
| 上一條／下一條 trace | ↑ ↓ | ↑ ↓ |
| 局部放大退回一層 | Esc | Esc |
| 說明 | F1 | F1 |
| 說明回首頁 | Esc | Esc |
| 示意圖：開啟 DXF／儲存／復原／重做 | ⌘O／⌘S／⌘Z／⌘⇧Z | Ctrl+O／Ctrl+S／Ctrl+Z／Ctrl+Shift+Z |
| 示意圖：刪除選取物件 | Delete | Delete |

## 滑鼠與觸控板
| 位置 | 操作 |
|---|---|
| 1D／2D 圖（指標模式） | 左鍵拖曳平移、滾輪縮放 |
| 局部放大模式 | 左鍵拖出矩形放大；右鍵退回 |
| Log 項目表 | 點選一條；Shift＋點選一段；⌘/Ctrl＋點選加減 |
| 標註開啟時 | 右鍵拖曳畫線或雷射筆 |
| 3D | 左鍵拖曳旋轉、中鍵拖曳平移、滾輪縮放、左鍵點選讀值 |
| Mac 觸控板（1D／2D） | 雙指捏合縮放、雙指滑動平移 |
| Mac 觸控板（3D） | 雙指滑動旋轉、Shift＋滑動平移、捏合縮放 |
| 瀏覽器列表 | 點星號欄切換星號；雙擊開啟 Viewer；右鍵選單 |
