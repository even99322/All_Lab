### Asked before a file with the same name is replaced
- When something is saved where a file of that name already exists (exported images, CSV, animations, Figures, fit results, De-background output, ...), you choose **Overwrite**, **Keep Both** (the new one becomes "name (2)") or **Cancel**, on this computer and on NAS shares alike.
- Renaming a measurement file or creating a folder with a name that is taken offers **Keep Both** or cancel; someone's data is never replaced.

### De-background can write straight to the NAS
- Output on the NAS used to fail with "[Errno 45] Operation not supported"; it now checks that the name is free and finishes normally.

### Re-link moved data (licence)
- **Works when the new path already has records**: records the program made by itself when the new location was opened (automatic tags, the first view) give way to your old ones; your own tags, comments and named views are combined instead of being "kept unchanged".
- If both paths hold your records that cannot be combined (for example Marks on both), you are asked: **Overwrite with Old Records** or **Keep Current Records**.
- **Match by Path**: when only the folder moved or the NAS mounts under another name, pick the old folder and every file is matched at once, without reading the files, quick on the NAS.
- Stars and tags are placed under the database open in the Browser, so they show right away.

### Data Transfer
- Automatic tags are no longer reported as conflicts; merging tag categories was fixed.
