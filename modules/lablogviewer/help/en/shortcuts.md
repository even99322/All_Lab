# Keyboard and mouse
> Every shortcut and mouse action in one place.

## Shortest procedure
1. **F1 in any window** opens that window's help page. ![](shortcuts.png)
2. **Copy a plot**: ⌘C (Windows: Ctrl+C) on the plot.
3. **Step back after zooming**: right-click or Esc.

## Keyboard
| Action | Mac | Windows |
|---|---|---|
| Open database (Browser) / open file (Viewer) | ⌘O | Ctrl+O |
| Reload | ⌘R | Ctrl+R |
| Copy plot | ⌘C | Ctrl+C |
| Copy all panes | Control+Shift+C | Ctrl+Shift+C |
| Previous / next trace | ↑ ↓ | ↑ ↓ |
| Zoom: step back | Esc | Esc |
| Help | F1 | F1 |
| Help: back to the start page | Esc | Esc |
| Figure Builder: open DXF / save / undo / redo | ⌘O / ⌘S / ⌘Z / ⌘⇧Z | Ctrl+O / Ctrl+S / Ctrl+Z / Ctrl+Shift+Z |
| Figure Builder: delete selected | Delete | Delete |

## Mouse and trackpad
| Where | Action |
|---|---|
| 1D / 2D plot (pointer mode) | left-drag pans, wheel zooms |
| Zoom mode | left-drag a rectangle; right-click steps back |
| Log Entries table | click one; Shift-click a block; ⌘/Ctrl-click to add or remove |
| Annotation on | right-drag draws or points |
| 3D | left-drag rotates, middle-drag pans, wheel zooms, left-click reads values |
| Mac trackpad (1D / 2D) | pinch zooms, two-finger scroll pans |
| Mac trackpad (3D) | two-finger scroll rotates, Shift + scroll pans, pinch zooms |
| Browser list | click the star column to star; double-click opens a Viewer; right-click menu |
