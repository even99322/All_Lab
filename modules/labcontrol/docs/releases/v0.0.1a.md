# Lab Control 0.0.1a

- 發佈日期：2026-09-30
- 類型：第一個 Lab APP 發佈版本
- Python：3.12
- 前一版：開發版 v0.2-dev（未發佈）

## 摘要（貼到 Lab APP「版本說明」）

Lab Control 第一版。量測方案編輯器（流程圖 / Labber 式參數表）＋ Yokogawa GS200/GS610/GS820、R&S ZNA 驅動（依手冊修正）。
所有設定集中在 C:\Users\even9\LAB（settings.yaml、instruments.yaml），第一次開啟自動建立，升級不覆寫。
新增儀器依 docs/DRIVER_GUIDE.md 的參數表寫法，放到 LAB\plugins 即可使用。
⚠ 驅動尚未在實機上驗收，正式量測前請先完成 docs/MIGRATION.md 的「上機前檢查」。

## 第一次使用

1. Lab APP 啟動 Lab Control（第一次會建立虛擬環境並安裝 requirements.txt）。
2. 程式建立 `C:\Users\even9\LAB`。打開 `instruments.yaml` 確認儀器位址、`source:` 的上下限與斜坡速率；打開 `settings.yaml` 確認 `data.root`、`labber.python38`。
3. 先用模擬模式熟悉（`settings.yaml` → `app.simulate: true`），再改回 `false` 接實機。

## 新增

- App 名稱、圖示、Lab APP 發佈格式（`main.py`、`.entry`、`.readme`、`.icon`、`.python-version`、`requirements.in/.txt`）。
- LAB 設定資料夾與 `settings.yaml`（全部可調值集中管理，深度合併預設值）。
- 驅動規範：`ParamSpec` 參數表、`_get_/_set_` 自訂讀寫、`instruments.yaml` 的 `parameters:` / `scpi:` / `ranges:` 覆寫、錯誤佇列檢查；範本 `LAB/plugins/_driver_template.py`。
- 方塊庫與量測欄位由 driver 參數表產生；`sweepable` 參數可在流程圖中掃描（例如 VNA 功率、IF 頻寬）。
- 範本改放 `LAB/templates/`；編輯器可存成範本；「設定 ▾」選單。
- `python -m labcontrol init`、錯誤記錄 `LAB/logs/labcontrol.log`。

## 依手冊修正的驅動問題

| 儀器 | 問題（舊程式） | 修正 | 手冊 |
|---|---|---|---|
| GS820 | 用 `:SOURce<n>:…`、`:OUTPut<n>` | `:CHANnel<n>:SOURce:…`、`:CHANnel<n>:OUTPut` | IM 765601-01E §16.2 |
| GS610 | 電流源時設定電流限制器 | 電壓限制器 `:SOUR:VOLT:PROT:ULIM/LLIM` | IM 765501-01E §16.2 |
| GS610/GS820 | 未設定 function 前寫 level 預設寫到 VOLT | 連線讀回實際 function | 同上 |
| GS 系列 | 無解析度 / 量程檢查 | 依量程解析度取整、超出量程拒絕 | 各手冊規格表 |
| GS 系列 | 可在輸出中切量程 | 輸出中拒絕切換量程 / 功能（感性負載可能跳脫、GS610 切功能會關輸出） | 同上 |
| ZNA | 平均開啟時沒有清除 → 上一個電流點被平均進來 | 每點 `:SENS<Ch>:AVER:CLE` | ZNA 手冊 §7.3.15.1 `[SENSe:]AVERage:CLEar` |
| ZNA | 改 active trace 後讀資料 | `CALC:DATA:TRAC? '<trace>', SDAT` | §7.3.2.2 `CALCulate:DATA:TRACe?` |
| ZNA | x 軸自己算 linspace | `CALC<Ch>:DATA:STIM?` 實際頻率 | §7.3.2.2 `CALCulate<Ch>:DATA:STIMulus?` |
| ZNA | IF 頻寬寫入值 ≠ 實際值 | 設定後讀回 | §7.3.15.2 `[SENSe:]BANDwidth` |

## 相容性

- 舊設定 `driver: rs.vna` 仍可用（= `rs.zna`）。
- 舊開發版的原生 HDF5（schema `labmaster/1`）仍可讀取與匯出。
- Labber 輸出結構與舊 `save_labber.py` 相同（通道名稱、`Instrument config/VNA`）。

## 已知限制

- **所有驅動只在模擬與 MockTransport 下測試過**，尚未上機；請依 `docs/MIGRATION.md` 上機前檢查逐項確認。
- SHFQC 實機驅動未實作（參數表已定義，模擬可用）。
- ZNA 功率可用範圍與頻率 / 選配有關，預設不設上下限；請在 `instruments.yaml` 的 `parameters.power.limits` 設定。
- GS610 / GS820 的電壓量程表未填（只用到電流源）；需要時在 `instruments.yaml` 的 `ranges:` 補上。
