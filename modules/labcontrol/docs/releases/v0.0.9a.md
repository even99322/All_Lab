# Lab Control 0.0.9a

- 發佈日期：2026-10-01
- 類型：0.0.9 的修正與調整（即時監控）
- Python：3.12
- 前一版：0.0.9
- 發佈檔：`LabControl_v0.0.9a.zip`、`LabControlMonitor_v0.0.9a.zip`、`LabControlHub_v0.0.9a.zip`（Hub 只有版本號改變，不一定要更新）

## 摘要（貼到 Lab APP「版本說明」）

- 修正：即時監控「獨立視窗」打開是空的。
- 即時監控改成固定版面：
  - 左邊調電流（電源群組）；
  - 右上是 VNA 參數，可以往上拉小或收起；
  - 右下是曲線。
- 曲線可以複選：dB、Linear、Real、Imag、Phase、Unwrap phase、IQ，每種一張圖，頻率軸連動。
  「⧉ 曲線視窗」可以把圖單獨拉成一個視窗。
- 掃描速度可以控制：
  - VNA 參數多了「掃描時間」和「自動掃描時間」（ZNA `SENS:SWE:TIME` / `SWE:TIME:AUTO`）；
  - 連續讀取的間隔可以設定，預設「最短」：讀完一次立刻讀下一次，刷新間隔就等於實際量測時間；
  - 旁邊會顯示每次讀取花的時間和每秒幾次。

## 修正

- **獨立視窗是空的**：0.0.9 在面板變窄 / 變寬時，會把電源與 VNA 在「分頁模式」和「並排模式」之間搬移。搬移後兩個區塊沒有重新顯示，所以獨立視窗裡是空的。
  0.0.9a 取消分頁模式，一律並排，中間可以拖曳調整寬度。
- 獨立視窗與曲線視窗改由 Qt 擁有，關閉時由 Qt 刪除，避免關閉時被 Python 提早回收造成當機。
- 連續讀取時，如果上一次還沒讀完（例如剛按了套用設定），會等它讀完再接著讀；0.0.9 在這種情況會停止連續讀取。
- 「↻」在 Windows 上顯示不出來，改成「重新讀取」。

## 變更

- **VNA 版面**：上下兩塊，中間可以拖曳，參數區可以收到最小。
  - 上：參數，依寬度自動排成 1–3 欄；
  - 下：讀取 / 連續 / 間隔 / 曲線種類 / 曲線視窗 / 圖。
- **曲線種類**：

  | 種類 | 畫法 |
  |---|---|
  | dB | 20 log₁₀\|S\| |
  | Linear | \|S\| |
  | Real、Imag | 實部、虛部 |
  | Phase | 相位，−180～180° |
  | Unwrap | 相位 unwrap（°） |
  | IQ | 橫軸 Re、縱軸 Im，等比例 |

  - 可以複選，至少保留一種；頻率圖的橫軸連動。
  - 選擇會記在 `LAB/live_ui.json`，連同 S 參數與間隔。
- **掃描時間**：
  - ZNA 驅動的 `sweep_time` 改成可寫入，並新增 `sweep_time_auto`；
  - 在即時監控改了掃描時間，會自動關掉「自動掃描時間」；
  - 驅動測試「寫回相同值」會先寫掃描時間，再寫回自動設定，所以測試後儀器仍保持原本的自動狀態。
- 主視窗右上「監控」預設高度加大。

## 測試

- `tests/test_live_gui.py` 新增以下檢查：
  - 掃描時間寫入並關閉自動；
  - 曲線複選 dB + Unwrap + IQ，IQ 資料等於 Re / Im，至少保留一種；
  - 間隔「最短」時連續讀取；
  - 曲線視窗拿出 / 放回；
  - 獨立視窗裡電源和 VNA 都有顯示（0.0.9 的錯誤）。
- 測試清理不再刪除 pyqtgraph 的右鍵選單。刪除這些選單會重複釋放而當機，這也是以前偶發 segfault 的原因。
