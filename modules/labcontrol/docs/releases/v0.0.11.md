# Lab Control 0.0.11

- 發佈日期：2026-10-01
- 類型：即時監控曲線排版、數據點；版本號改為純數字
- Python：3.12
- 前一版：0.0.10（原本稱 0.0.9a）
- 發佈檔：`LabControl_v0.0.11.zip`、`LabControlMonitor_v0.0.11.zip`、`LabControlHub_v0.0.11.zip`（Hub 只有版本號改變，不一定要更新）

## 摘要（貼到 Lab APP「版本說明」）

- VNA 曲線最多 5 張，用九宮格排法：

  | 張數 | 排法 |
  |---|---|
  | 2 | 上下 |
  | 3 | 上排左右，下排一張 |
  | 4 | 四方格 |
  | 5 | 四方格，下方再一張 |

- 拖曳圖的標題列（⠿）到另一張圖，兩張就交換位置。
- 「數據點」：在曲線上加畫每個量測點（橘色點）。
- 版本號改為純數字，每次發佈遞增最後一位。0.0.9a 改稱 0.0.10，本版是 0.0.11。

## 變更

- **曲線排版**：
  - 每張圖上方有標題列，顯示種類與 S 參數，例如「⠿ dB · S21」；
  - 勾選的順序就是排列順序，新勾的排在最後；拖曳後的順序會記在 `LAB/live_ui.json`，下次開啟維持；
  - 已有 5 張時再勾第 6 種，會提示「最多同時顯示 5 張圖」；至少保留一張。
- **數據點**：曲線種類按鈕旁的「數據點」勾選框，IQ 圖也適用。設定會記住。
- **頻率軸連動改成用數值同步**：0.0.10 用 pyqtgraph 的 `setXLink`，寬度不同的圖（例如 5 張時下方那張比較寬）會依像素對齊，頻率範圍會錯開。現在縮放或平移任何一張頻率圖，其他頻率圖會設成相同的頻率範圍。
- 版本規則改為純數字（README、CHANGELOG、ROADMAP 已更新）；`docs/releases/v0.0.9a.md` 改名為 `v0.0.10.md`。

## 測試

- `tests/test_live_gui.py` 新增以下檢查：
  - 3 張圖的位置是上左右、下面一張；
  - 拖曳交換後順序與位置都改變；
  - 第 6 張被拒絕，5 張時最後一張排在下方整列；
  - 頻率軸數值同步；
  - 數據點開關。
