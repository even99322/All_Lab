# Lab Control 0.0.3

- 發佈日期：2026-09-30
- 類型：功能版本（主視窗改版）
- Python：3.12
- 前一版：0.0.1b（Lab APP v0.0.2）

## 摘要（貼到 Lab APP「版本說明」）

主視窗改成 Labber 式四格工作台：左上流程圖（節點可自由拖動、拉線連接，迴圈自動畫框）、左下儀器參數列表（拖進流程圖建立節點、取值 / 設定值）、右上即時監控（開始 / 暫停 / 退回 / 停止、曲線與 2D 影像）、右下檔案設置（檔名、資料夾、Labber tags / 註解）。
雙擊掃描節點開 Labber 式 Step 設定：起訖或中心寬度、步進或點數、線性 / 對數、每步等待、來回掃、掃完後回到第一點 / 停在最後 / 到指定值。
舊的方案檔可直接開啟（自動排版）。

## 新增

**主視窗（`labcontrol/apps/qt/workbench/`）**
- 左上 流程圖：節點自由擺放；從輸出點拉線到節點即連線，拉到空白處跳出選單直接新增並連上；
  掃描節點有「每一點 ⟲」與「完成後」兩個出口；迴圈範圍自動畫框（外框 = 外圈）；錯誤節點紅框、警告橘框；
  從儀器參數列表拖入：放在連線上 = 插入、放在節點上 = 接在後面、放在空白處 = 未連接節點；
  右鍵選單、Delete 刪除、Ctrl + 滾輪縮放、中鍵平移、自動排列、復原 / 重做。
- 左下 儀器參數：依儀器分組列出電磁鐵組、電源輸出、所有可寫數值參數（量程、限制器、VNA 頻率 / 功率 / IF 頻寬…）與量測通道；
  搜尋、只顯示常用、取值、設定值（立刻寫入，電源自動斜坡）、唯讀連線、自動更新電流值。
- 右上 即時監控：狀態、進度、剩餘時間、斜坡進度；掃描軸目前值與位置 [i/N]；量測通道最低點；
  曲線可切換 dB / 相位 / 實部 / 虛部；2D 影像；手動步進；訊息。
- 右下 檔案設置：檔名（日期不是今天時一鍵修正）、資料根目錄、資料夾規則、同名處理、格式、
  Labber Project / User / Tags / 註解、實際存檔路徑與分檔預覽；「執行」分頁；「檢查與估時」分頁（點錯誤跳到節點）。

**方案與引擎**
- 方案檔格式 `scheme: 2`：存節點位置與連線（`labcontrol/scheme/graph.py`，與方塊樹一一對應）；`scheme: 1` 仍可開啟。
- Step 設定：`range_mode`（起訖 / 中心寬度）、`interp: log`（對數間隔）、`alternate`（每軸來回掃）、
  `after`（掃完後：回第一點 / 停在最後 / 到指定值，對應 `run.park` 每軸設定）。
- `run.point_delay`：每點量測前至少等待（Labber 的 Delay between step and measure）。
- 檔案設定集中在方案 `output`（`file_name`、`formats`、`collision`、`project`、`user`、`tags`、`comment`）；
  沒有 Data 節點時整個量測存成一個檔。
- Labber 匯出支援註解（`setComment`；舊版 Labber API 沒有時略過）。
- 所有可寫的數值參數都能當 Step（不限 driver 標為 `sweepable` 的參數）；多通道電源（GS820）每個通道都可掃描。
- 模擬儀器的可寫性與實機 driver 相同（例如 ZNA 的 `sweep_time` 只能讀）。
- `settings.yaml` 新增 `monitor:`（自動更新、更新間隔、曲線預設顯示、色表）。

## 變更

- 舊的「方塊庫 + 屬性面板 + Labber 式參數表」編輯器移除，由新主視窗取代。
- 方案不再內建執行預設值（移到起點 0.5 mA/s 等），一律使用 `settings.yaml` 的 `run_defaults`，方案只存改過的值。
- `python -m labcontrol.apps.qt.monitor`（直接跑實驗 YAML）改用與主視窗相同的監控面板。

## 相容性

- 0.0.1a / 0.0.1b 存的 `.scheme.yaml` 可直接開啟，第一次開啟自動排版；儲存後變成 `scheme: 2`。
- 舊方案裡 Data 方塊的檔名 / 格式仍有效；在「檔案設置」改過後以檔案設置為準。
