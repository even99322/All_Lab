# Lab Control 0.0.13

- 發佈日期：2026-10-01
- 類型：接上 QEL Lab 大程式（通信模塊 labcomm）
- Python：3.12
- 前一版：0.0.12
- 發佈檔：`labcontrol_v0.0.13.zip`（QEL Lab 大程式發佈）；Hub 只有版本號改變

## 摘要（貼到 Lab APP「版本說明」）

- 從 **QEL Lab 大程式** 開啟 Lab Control 時：
  - 存檔時把這次的量測方案和標籤寫進數據檔，並登錄到大程式；網頁、手機、讀檔模塊都看得到，旁邊列出標籤對應的論文。
  - 在讀檔模塊（LabLogViewer）把數據拖到 Lab Control 主視窗，就會載入那次的量測設置。
  - 存好的數據自動交給開著的讀檔模塊開啟。
  - 檔案設置的 Tags 會提示實驗室共用的標籤。
- 單獨執行（Lab APP）時行為與 0.0.12 完全相同。

## 設定（settings.yaml，新版會自動帶預設值）

```yaml
qel:
  embed_scheme: true           # 存檔時把量測方案與標籤寫進數據檔
  register_datasets: true      # 存檔後登錄到大程式
  open_in_viewer: running      # running（讀檔模塊開著才送）| always | never
```

## 程式

- `labcontrol/integrations/qel.py`：整合（`data.exported` / `data.uploaded` 事件、本機傳遞 `apply_scheme`、拖放、Tags 提示）。
- `measure/experiment.py`：`data.exported` 事件多帶 `name`、`scheme`、`tags`。
- `remote/node.py`：上傳到 Hub 後發 `data.uploaded`。
- `app.py`：開啟數據檔＝套用設置；主視窗接上整合。`apps/cli.py node`：無畫面節點也登錄數據。
- 測試：`tests/test_qel.py`。
