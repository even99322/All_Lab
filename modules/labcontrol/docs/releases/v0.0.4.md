# Lab Control 0.0.4

- 發佈日期：2026-09-30
- 類型：功能版本（儀器伺服器）
- Python：3.12
- 前一版：0.0.3

## 摘要（貼到 Lab APP「版本說明」）

新增「儀器伺服器」（Labber Instrument Server）：儀器清單與狀態、新增 / 移除 / 停用儀器（寫回 instruments.yaml，保留註解並備份）、掃描 VISA 並用 *IDN? 辨識。
雙擊儀器開控制視窗直接操作：讀取全部 / 寫入變更、電源設定輸出（自動斜坡）與開關、VNA 取 trace、收發紀錄與指令耗時。
新增驅動測試：讀取 / 寫回相同值 / 量測一次 / 小幅度輸出，每一步查錯誤佇列，報告存在 LAB\logs；上機步驟見 docs/INSTRUMENT_TEST.md。
新增套件 ruamel.yaml（Lab APP 會自動安裝）。

## 新增

**儀器伺服器（主視窗工具列「🖧 儀器伺服器」或 `python main.py --server`）**
- 儀器清單：`instruments.yaml` 全部儀器（含停用），狀態：已連線 / 未連線 / 量測使用中 / 測試中 / 停用 / 未載入 / 錯誤。
- 新增儀器：選驅動、名稱、位址、逾時；電源的安全上下限、斜坡速率、單次跳動上限；電磁鐵組選兩台電供。
  「掃描 VISA」與「連線測試（*IDN?）」；依 IDN 自動建議驅動。
- 移除、啟用 / 停用、連線（唯讀）、中斷、全部連線；新增 / 移除後主視窗的儀器參數列表與方案檢查自動更新。
- 寫入 `instruments.yaml` 用 ruamel.yaml 保留註解、順序與 YAML anchor；每次寫入前備份到 `LAB/logs/backup/`，寫入前先驗證內容可讀回。

**儀器控制視窗（= Labber driver 設定視窗）**
- 讀取全部 / 寫入變更（改過的欄位黃色）/ 變更立即寫入 / 自動讀取。
- 電源：目前輸出、設定輸出（超過單次跳動上限自動斜坡、可中止）、開 / 關輸出、斜坡歸零後關閉。
- VNA：取得 trace（dB / 相位 / 實部 / 虛部）。
- 通訊紀錄（每條收發與錯誤）、SCPI 次數與平均耗時（Labber Timing statistics）、手動送 SCPI（寫入指令先確認）。
- 量測使用中的儀器唯讀。

**驅動測試（`labcontrol/diagnostics.py`；視窗與命令列共用）**
- 讀取：連線、`*IDN?` 與驅動比對、讀取所有參數、狀態檢查（源模式、波形、自動量程）、trace 清單與頻率點。
- 寫回相同值：驗證設定指令語法且不改變狀態（輸出開啟時量程 / 功能略過）。
- 量測一次、小幅度輸出（至少 2 個解析度，超過單次跳動上限或輸出關閉時略過，結束回原值）。
- 每一步之後讀錯誤佇列；報告（Markdown）含每項結果、SCPI 統計與收發紀錄。
- 命令列：`python -m labcontrol resources`、`python -m labcontrol test <名稱|all> [--write-same] [--acquire] [--step 1uA]`。

**其他**
- Transport 收發監聽（taps）與指令統計（stats）；`Station.remove` / `disconnect`、`station.changed` / `instrument.closed` 事件。
- 驅動宣告 `IDN_PATTERN`（GS200 / GS610 / GS820 / ZNA）；GS 通道的量程 / 限制器單位隨源功能顯示（A / V）。
- `settings.yaml` 新增 `server:`（VISA backend、掃描選項、收發紀錄行數、開啟時自動連線、新電源預設安全值、預設逾時）。
- 儀器可在 `instruments.yaml` 設 `visa_backend`、`write_termination`、`read_termination`。
- `labcontrol/testing/fake_scpi.py`：依手冊語法模擬 GS200 / ZNA 的 SCPI 端（測試用），不認得的指令回 -113。
- 文件：`docs/INSTRUMENT_TEST.md`（上機測試指南）。

## 已知限制

- 儀器伺服器與主視窗在同一個程序（Labber 是獨立程序；獨立程序版在 1.0.0 規劃）。
