# 上機測試指南（用儀器伺服器驗證驅動）

目的：在實機上確認每個驅動的 SCPI 都被儀器接受，找出需要修正的地方。
所有步驟都在 Lab Control 的 **儀器伺服器** 完成（主視窗工具列「🖧 儀器伺服器」，或 `python main.py --server`）。

> 原則：先只讀，再寫回相同值，最後才做小幅度輸出。電磁鐵接著時，每一步都先確認電流、面板數值沒有跳動。

## 0. 準備

1. `settings.yaml` 的 `app.simulate` 設為 `false`（工具列右上顯示綠色「實機」）。
2. 儀器開機、USB / 網路接好。電腦需要 NI-VISA 或 Keysight IO Libraries。
   沒有的話可 `pip install pyvisa-py` 並在 `settings.yaml` 設 `server.visa_backend: "@py"`。
3. 關掉舊程式（sweep_main.py、web_yoko.py），避免兩個程式同時開 VISA。

## 1. 找到儀器並加入清單

1. 儀器伺服器 →「掃描 VISA…」：列出電腦看得到的儀器，並用 `*IDN?` 辨識（只讀）。
2. 對照 `instruments.yaml` 的位址是否正確；不在清單的儀器雙擊 →「新增儀器」（會自動選好建議的驅動）。
3. 新增時的安全設定（上下限、斜坡速率、單次跳動上限）會寫進 `instruments.yaml`，原檔先備份到 `LAB/logs/backup/`。

## 2. 連線（唯讀）

1. 選儀器 →「▶ 連線」。連線只讀狀態，**不會改變輸出**。
2. 狀態應變成綠色「已連線」，`*IDN?` 顯示在右欄。紅色「錯誤」→ 看下方訊息（位址、逾時、VISA）。
3. 雙擊儀器開「控制視窗」→「讀取全部」：每個欄位應與儀器面板一致。

## 3. 驅動測試

選儀器 →「驅動測試…」（或「全部測試…」），依序做：

| 步驟 | 勾選 | 會做什麼 | 儀器狀態 |
|---|---|---|---|
| A | （預設） | 讀取所有參數、trace 清單、頻率點；每一步查 `:SYST:ERR?` | 不變 |
| B | 寫回相同值 | 每個可寫參數設成目前的值，驗證「設定」指令語法 | 不變（輸出開啟時量程 / 功能自動略過） |
| C | 量測一次 | VNA 觸發一次掃描並讀回資料 | 掃描一次，結束恢復連續掃描 |
| D | 小幅度輸出（例如 1 uA） | 電源輸出開啟時 +步進 再回原值，確認讀回 | 短暫改變 1 個步進 |

結果：✔ 通過、⚠ 注意（例如讀回值被儀器捨入）、✖ 失敗（指令被拒絕、逾時或讀取格式錯誤）、– 略過（例如儀器上沒建立的 trace）。
每次測試的報告存在 `LAB/logs/driver_test_<名稱>_<時間>.md`，內容包含每一項結果、SCPI 次數與耗時、完整收發紀錄。
**有 ✖ 或 ⚠ 時，把報告檔傳給開發者**，就能直接看出是哪一條指令要改。

命令列也可以做同樣的測試：

```bash
python -m labcontrol resources                     # 掃描 VISA + *IDN?
python -m labcontrol test DC1                      # A：只讀
python -m labcontrol test DC1 --write-same         # A + B
python -m labcontrol test VNA1 --write-same --acquire
python -m labcontrol test DC1 --step 1uA           # D（輸出關閉時略過）
python -m labcontrol test all                      # 全部儀器（只讀）
```

## 4. 直接控制（控制視窗）

- **電源**：「設定為」輸入新值（例如 `158.7`，單位 mA）→「設定輸出」。超過單次跳動上限時自動以斜坡前進，可隨時「中止斜坡」。
  「斜坡歸零後關閉」會先以斜坡速率回到 0 再關輸出（接電磁鐵時請用這個，不要直接關）。
- **參數**：改過的欄位會變黃色，按「寫入變更」才寫入；勾「變更立即寫入」則每改一欄就寫（像 Labber 的 active 狀態）。
- **VNA**：「Trace」分頁 →「取得 trace」量一次並畫圖。
- **通訊紀錄**：每條送出 / 收到的指令、錯誤；「更新統計」看每個指令的次數與平均耗時。可以手動送 SCPI（寫入指令會先確認）。
- 量測進行中，被量測使用的儀器在控制視窗是**唯讀**的（和 Labber 一樣），不會跟量測搶著寫。

## 5. 各儀器要特別確認的地方

| 儀器 | 確認 |
|---|---|
| GS200 | 量程 / 限制器讀值與面板一致；輸出開啟時改量程會被拒絕（保護） |
| GS610 | 寫回相同值時限制器（`:SOUR:VOLT:PROT:ULIM/LLIM`）無錯誤；面板電壓限制器數值正確 |
| GS820 | 兩個通道分開測；`:CHAN<n>:` 指令無錯誤；`measured` 與面板一致 |
| ZNA | `trace 清單` 有 S21；平均 ≥ 2 時每次量測面板平均計數從 1 開始；IF 頻寬 6 kHz 讀回 7 kHz（⚠ 屬正常捨入） |
| 電磁鐵組 | 小幅度輸出後兩台電供回到原值；平均電流讀值正確 |

測完後把 `docs/MIGRATION.md` 的「上機前檢查」逐項打勾，並把驗證過的安全值寫進 `instruments.yaml`。
