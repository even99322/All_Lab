# LAB-QEL論文庫

實驗室自架的論文管理網站（版本 1.5.1）。主資料庫放在 NAS，成員用瀏覽器就能上傳、分類、閱讀、標註、討論、翻譯，也能讓 AI 幫忙整理。電腦、平板、手機都用同一個網址；也可以安裝成 App（Android、iPhone／iPad、電腦），沒網路時照樣讀已保存的論文。

## 二、部署到 NAS

需要能跑 Docker 的 NAS：Synology（DSM 7.2 以上，用 Container Manager）或 QNAP（用 Container Station）。

### 1. 放檔案

1. 在 NAS 建一個資料夾，例如 `/volume1/docker/paperlib`，把整包程式放進去。
2. 在裡面建兩個子資料夾：
   - `data`：主資料庫，所有論文、筆記、設定都在這裡。
   - `import`：第一次匯入時，把現有的論文資料夾放在這裡。

### 2. 建立專案

- **Synology**
  1. Container Manager →「專案」→「新增」。
  2. 路徑選 `/volume1/docker/paperlib`，選「使用現有的 docker-compose.yml」。
  3. 建置並啟動。第一次建置約 5–10 分鐘，因為要安裝 OCR 工具。
- **QNAP**
  1. Container Station →「應用程式」→「建立」。
  2. 貼上 `docker-compose.yml` 的內容，把 `./data`、`./import` 改成 NAS 上的絕對路徑。

### 3. 開始使用

瀏覽器開 `http://<NAS 的 IP>:8080`。第一次開啟時會要求建立管理員帳號。

> Synology 注意：建立專案時**不要勾選**「透過 Web Station 設定網頁入口」，否則 8080 埠會被攔截。

### 4. 匯入現有論文（只需做一次）

在 NAS 的 SSH，或 Container Manager 裡容器的「終端機」執行：

```bash
docker exec -it paperlib python -m app.importer --manifest seed/manifest.json --source /import --enrich
```

- `seed/manifest.json` 是整理好的清單：124 篇論文、139 個檔案，已去重並配對好補充資料，也分好類。
  - 無法確定分類的論文會放進「未歸檔待讀」，並附上建議分類。
- 檔案用內容（SHA-256）比對，資料夾怎麼擺、檔名叫什麼都沒關係。原始資料夾只會被讀取，不會被修改。
- 可以重複執行：已匯入的會跳過，只補上缺的檔案。
- `--enrich` 會透過 Crossref 和 arXiv 補齊作者與摘要，需要 NAS 能連外網。沒有網路就拿掉這個參數。
- 匯入後，背景會自動分析參考文獻、建立引用關聯，並檢查掃描檔。

## 三、在沒有 Docker 的電腦上執行

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt          # Windows：.venv\Scripts\pip
PAPERLIB_DATA=/path/to/data .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8080
```

- 也可以直接執行 `run_local.sh`（Mac、Linux）或 `run_local.bat`（Windows）。
- `PAPERLIB_DATA` 可以指向 NAS 掛載的共用資料夾。
- 要用 OCR 的話，另外安裝 Tesseract：
  - Mac：`brew install tesseract tesseract-lang`
  - Windows：UB Mannheim 的安裝檔
  - 沒有安裝時其他功能照常，只是不會出現 OCR 按鈕。

## 四、從外網連線（不用 VPN）

**不要**直接在路由器把 8080 埠轉到網際網路。那樣是明碼 HTTP，而且學校網路通常也沒有對外 IP。

下面兩種方式都不必開路由器的埠，而且自帶 HTTPS。

### 方式 A：Cloudflare Tunnel（推薦，網址固定）

需要一個由 Cloudflare 代管的網域（一年約 10 美元）。

1. 登入 Cloudflare，進入 **Zero Trust** → **Networks** → **Tunnels** → **Create a tunnel**。
   - 類型選「Cloudflared」。
   - 在「Install connector」頁面選 Docker，複製指令裡 `--token` 後面那一串。
2. 打開 `docker-compose.yml`，把最下面 `cloudflared` 那一段取消註解，token 貼到 `TUNNEL_TOKEN`。
3. 回到 Tunnel 設定 → **Public Hostname** → **Add**：
   - Subdomain 填 `papers`，Domain 選你的網域。
   - Service 選 `HTTP`，URL 填 `paperlib:8080`。
4. 在 Container Manager 重新建置專案。之後用 `https://papers.你的網域` 連線。
5. 到「管理 → 網站、翻譯與 AI」，把「網站網址」改成這個 https 網址。

選用：在 Zero Trust → **Access** → **Applications** 保護這個網址，只允許 `@學校.edu.tw` 的信箱進入。這樣陌生人連登入頁都看不到。

### 方式 B：Tailscale Funnel（不需要網域）

1. 到 Tailscale 後台：
   - **DNS** 頁面開啟 **HTTPS Certificates**。
   - 確認 NAS 有 `funnel` 權限。
2. SSH 登入 NAS，執行：
   ```bash
   sudo tailscale funnel --bg --https=443 localhost:8080
   ```
3. 網址是 `https://<NAS 名稱>.<你的 tailnet>.ts.net`，成員的裝置不用裝 Tailscale。
4. 要停止公開時執行：`sudo tailscale funnel --https=443 off`。

### 方式 C：Tailscale Serve（不公開，但有 HTTPS）

只給裝了 Tailscale 的成員用，但網址是 HTTPS，可以安裝成 App、離線閱讀（見 6.28）：

1. Tailscale 後台 **DNS** 頁面開啟 **MagicDNS** 與 **HTTPS Certificates**。
2. SSH 登入 NAS，執行：
   ```bash
   sudo tailscale serve --bg --https=443 localhost:8080
   ```
3. 成員用 `https://<NAS 名稱>.<你的 tailnet>.ts.net` 連線（和 Funnel 同一個網址格式，但只有 tailnet 裡的裝置連得到）。

### 只在區網或 VPN 內使用

- Tailscale：成員裝 Tailscale 後，用 NAS 的 Tailscale IP 連線（`http://100.x.x.x:8080`）。這樣可以正常使用網站，但**手機與瀏覽器只允許 HTTPS 網站安裝成 App、離線閱讀**；要這兩項請用方式 A、B 或 C。
- NAS 內建 VPN：Synology VPN Server 或 QNAP QVPN。

### 網站內建的防護

- **登入失敗鎖定**：同一帳號 15 分鐘內錯 8 次、或同一 IP 錯 20 次，會鎖 15 分鐘。
- **兩步驟驗證（TOTP）**：各自在「我的帳號」開啟，用 Google Authenticator、Microsoft Authenticator、1Password 等 App。管理員帳號強烈建議開啟。
- **HTTPS**：走 HTTPS 時 cookie 會自動加上 Secure，並送出 HSTS 等安全標頭。
- **紀錄**：「管理 → 動態紀錄」記下每次登入的 IP。
- **登出其他裝置**：「我的帳號 → 登出其他裝置」可以一次登出其他地方的連線。

| 裝置 | 使用方式 |

## 六、使用說明

網站裡也有同樣內容的**使用說明頁**（附截圖）：左側選單最下方「使用說明」、右上角頭像選單「使用說明」，或「管理 → 使用說明」。上方可以搜尋，例如輸入「並排」「離線」就只顯示相關段落。

### 6.1 論文群總覽（首頁）

首頁由上而下依序是：

- 置頂論文
- 最近開啟：你最近打開的 12 篇，附上次讀到的頁數（頁數記在各自的裝置上）
- 全站必讀的閱讀進度
- 指派給你還沒讀完的論文
- 你接下來要報告的組會
- 未歸檔待讀
- 新論文追蹤
- 各分類卡片：顯示最新 4 篇的首頁縮圖、說明、篇數
- 標籤
- 最近動態

### 6.2 分類與資料夾

- **分類**＝架設類型大類，例如「1D 半開放波導・Mirror」「腔 magnon」。
  - 一篇論文可以屬於多個分類。
  - 分類分成幾個群組（例如「架設類型」「理論與基礎」），群組決定側欄與首頁的分段。
- **資料夾**：每個分類裡可以再建資料夾，例如「理論」「實驗」「回顧」。
  - 分類頁上方的資料夾列：按「＋新資料夾」建立；資料夾右邊的「⋯」可以改名、調整順序、刪除。
  - **拖放**：把論文卡片拖到資料夾上就移過去了。勾選多篇後可以一起拖，或按「移到資料夾」。
  - 分類的「全部」頁面會依「置頂 → 各資料夾 → 不在資料夾」分段顯示，每段都可以收合。
  - 刪除資料夾不會刪除論文，論文會回到「不在資料夾」。
- **未歸檔待讀**：還沒分類的論文都放在這裡。
  - 系統會依內容給建議分類，卡片上按「歸到〇〇」就完成歸檔。
  - 也可以勾選多篇，按「套用建議」。

### 6.3 標籤

標籤是跨分類的自由註記，例如「P1」「推甄 Ref」「組會報告」。

- 外觀是 `#名稱` 加左側色條，和分類的圓角膠囊不同，一眼可以分辨。
- 在論文的「重點」分頁輸入即可新增。
- 「標籤」頁顯示所有標籤，以及每個標籤的論文預覽。
- 「管理 → 標籤」可以設定顏色、說明、順序，也可以改名（同名會合併）或刪除。

### 6.4 置頂

在論文卡片的「⋯」選單操作：

- 在分類頁按，是「在此分類置頂」，論文會排在該分類最前面。
- 在其他列表按，是「全站置頂」，論文會出現在首頁的「置頂論文」。

### 6.5 閱讀狀態（私人）

「未標記、待讀、閱讀中、已閱讀」是**每個人自己的**狀態，只有自己看得到。

- 可以在這些地方修改：
  - 論文頁右上的下拉選單
  - 列表勾選多篇後按「我的狀態」
- 左側「我的待讀」「閱讀中」只列出你自己的。
- 列表上方的狀態篩選也是依你自己的狀態。

### 6.6 指派（全站可見）

- **怎麼指派**：
  - 論文頁「⋯ → 指派給成員」
  - 論文卡片「⋯ → 指派給…」
  - 列表勾選多篇後按「指派」
- 可以一次選多位成員（@名字），並附上說明，例如「組會前讀完、重點看 Fig. 3」。
- **被指派的人**：
  - 收到通知，論文自動列入他的「待讀」。
  - 論文出現在他的「指派給我」和首頁提醒。
- **讀完時**：被指派的人把狀態改成「已閱讀」，指派的人會收到通知，論文頁上他的名字旁會打 ✓。
- 指派只公開「有沒有讀完」，其他閱讀狀態仍然是私人的。
- 指派的人、被指派的人、有指派權限的人都可以取消指派。

### 6.7 全站必讀

- 有「管理」權限的人可以把論文設為必讀：用論文頁或卡片的「⋯」，或勾選多篇後按「必讀」。設定後全體成員會收到通知。
- 左側「全站必讀」顯示你讀了幾篇，首頁有進度條，卡片上有紅色「必讀」標記。
- 必讀頁的進度區：
  - 管理員看得到每位成員的進度，點名字可以看他還差哪幾篇。
  - 一般成員只看得到自己的。

### 6.8 上傳

1. 按右上「上傳」，一次選或拖入多個 PDF。
2. 系統會自動：
   - 用 SHA-256 判斷重複檔，重複的直接略過；OCR 過的檔案也能認出原始掃描檔。
   - 抽出 DOI、arXiv 編號、標題、年份。
   - 和既有論文 DOI 相同時，建議附加為「其他版本」。
   - 看起來是補充資料或審稿意見時，建議附加到對應的正文。
   - 沒有文字層的掃描檔，入庫後自動 OCR。
3. 確認清單後按「確認入庫」。可以一併指定預設的分類和標籤；沒指定分類的會進「未歸檔待讀」。
4. 已經在論文庫的論文，可以在論文頁的「檔案」分頁加入附件：補充資料、審稿意見、其他版本。

### 6.9 閱讀與標註

論文頁左邊是 PDF，右邊有六個分頁：重點、標註、圖卡、關聯、書目、檔案。

- **收起右側欄**：標題列右邊的側欄按鈕可以把右側欄收起來，PDF 放到最大；再按一次展開。點任何分頁或標註也會自動展開。這個設定記在各自的裝置上。
- **從上次的頁數繼續**：打開論文會跳到上次讀到的頁（記在各自的裝置上）。
- **縮放論文**：手機兩指捏合、電腦 Ctrl＋滾輪（Mac 觸控板捏合也可以）只縮放 PDF，不會縮放整個網頁；在右側欄上按 Ctrl＋滾輪也是縮放 PDF。
- **個人模式／全域筆記**：「標註」分頁上方與手寫工具列有「全域筆記」開關，**預設關閉**。
  - 關閉：只顯示自己的劃線、筆記、手寫，新增的都是私人。
  - 開啟：顯示所有人的公開標註，新增的會公開（可以討論、@提及）。
  - 開關記在各自的裝置上；從通知點進來的那則標註，個人模式下也會顯示。
- **手寫**：閱讀器上方的筆形按鈕。
  - 工具：筆、螢光筆（半透明、較粗）、橡皮擦（劃過筆跡就擦掉）。
  - 七種顏色（黑、紅、藍、綠、橘、紫、黃）與三種粗細；上次用的會記住。
  - 「復原」可以一筆一筆退回。
  - 平板上可以勾「只用觸控筆」：只有 Apple Pencil 等觸控筆會畫，手指照常捲動與縮放。
  - 同一次手寫中，同一頁的筆畫存成一則「手寫」標註，會出現在「標註」分頁（附縮圖），可以加文字、設為私人、回覆討論或刪除；別人也看得到（私人的除外）。
  - 只能擦掉自己的筆跡（管理員可以擦任何人的）。
  - 下載「帶劃線與筆記的 PDF」時，手寫也會一起寫進 PDF。
  - **即時儲存**：每畫一筆就存，不必按「完成」。沒網路或伺服器沒回應時，筆跡先存在這台裝置的瀏覽器裡（工具列顯示「⚠ N 筆待上傳」），連上網路、或下次打開網站時自動補送；重新打開論文會先顯示還沒上傳的筆跡。每一筆有自己的編號，重送不會重複。「✓ 已儲存」代表都已存到伺服器。
- **筆記頁**：閱讀器上方的「筆記頁」按鈕，在論文旁邊開一本空白筆記直接手寫（每篇論文每個人各一本）。
  - 單篇時自動改成並排（論文一側、筆記頁一側）；已經並排時，筆記頁開在這篇論文的另一側。再按一次或按筆記頁的 × 就關掉，原本單篇的會回到單篇。
  - 工具同手寫，多一個「捲動」（用手指翻頁時切換）；頁面樣式可選橫線、方格、點陣、空白；「新增一頁」；右上角下載整本 PDF。
  - 筆記頁的手寫列在「標註」分頁（「筆記頁 N」），公開或私人跟「全域筆記」開關一致。

- **劃線**：選取文字後點色盤，四種顏色代表：
  - 黃：重點
  - 藍：方法／公式
  - 綠：參數／數據
  - 紅：疑問
- **劃線＋筆記**：劃線後直接寫筆記。
- **頁面筆記、整篇筆記**：在「標註」分頁新增。
- **私人筆記**：只有自己看得到。
- **討論**：每則標註底下都能回覆。用 `@名字` 提及成員，對方會收到通知。
- **重點欄**：每篇論文有一組共用欄位，預設是「重點、架設／平台、關鍵參數、可萃取特徵／觀測量、與我們實驗的關係、備註」。
  - 欄位名稱可以自訂，打字後自動儲存。
  - AI 填寫、還沒有人修改過的欄位會標「AI」。
- **書目**：可以編輯標題、作者、年份、期刊、DOI、arXiv、citekey、摘要。「用 DOI／arXiv 補齊」會從 Crossref 或 arXiv 抓資料。
- **檔案**：
  - 正文、補充資料等多個檔案可以切換閱讀。
  - 掃描檔有「OCR 辨識文字」按鈕。
  - 可以下載原檔，或下載帶劃線與筆記的 PDF。

**我的筆記**（左側選單）：所有論文的筆記頁、手寫、劃線、文字筆記集中在一頁。
- 筆記頁以整本列出（第一頁縮圖、頁數），點了在論文旁邊打開；其他標註依論文分組，點一則會打開論文並跳到那個位置。
- 可以切換「只有我的／含所有人公開的」、依類型篩選、搜尋內容或論文標題；「匯出 Markdown」把劃線與文字筆記存成 .md。

### 6.10 翻譯

- 在 PDF 選取文字 → 按「翻譯」，右下角會出現譯文卡片。
  - 「複製」：複製譯文。
  - 「劃線並存譯文」：把原文劃線，譯文存成標註。
- 「書目」分頁有「翻譯摘要」，可以存成整篇筆記。
- 行尾斷字（mag-non）會自動接回。
- 同一段文字第二次翻譯直接讀快取，不會重複計費。
- 服務的設定方式見第九節。

### 6.11 閱讀桌（多篇同時看）

- **電腦**：
  - 在論文庫點論文，會在獨立的「閱讀桌」視窗打開。
  - 「分頁」模式一次看一篇；「並排」模式固定兩篇同時看。
  - 閱讀桌裡點論文連結會加到閱讀桌；點其他連結則回到論文庫視窗。
  - 右上角頭像選單可以關掉「獨立視窗」，改在同一個視窗開。
  - 按住 Ctrl（Mac 用 ⌘）點論文，會用瀏覽器新分頁開。
- **手機**：論文頁「⋯ → 加入閱讀桌」，閱讀桌上方的分頁可以切換，也可以用「並排」上下對照兩篇。
- **並排（一次兩篇）**：
  - 視窗寬比高大時左右並排，高比寬大時上下並排；轉手機方向或拉視窗大小會自動切換。
  - 上方分頁會標出哪篇在「左／右」（或「上／下」）。
  - **換掉其中一邊**：先點那一邊的論文（有藍框表示選中），再點上方分頁的另一篇論文，就會換到那一邊；另一邊不動。
  - 在任一邊捲動或點擊都不會讓兩篇交換位置。
  - 從閱讀桌外新加入的論文會放到「沒選中」的那一邊。
- 最多同時開 8 篇。開過的論文和讀到的頁碼記在各自的裝置上，下次打開接著讀；在分頁之間切換、或把論文換出並排再換回來，頁數、縮放比例、筆記分頁與右側欄狀態都會保留。
- **收起右側欄**：閱讀桌上方的側欄按鈕會一次收起（或展開）所有論文的右側欄，並排時每篇的 PDF 都更寬；每篇標題列也有自己的按鈕。

### 6.12 關聯與關聯圖

- **手動關聯**：在「關聯」分頁搜尋另一篇論文，選擇方向與關係。
  - 關係可以選「延伸自」「使用其方法／公式」「實驗驗證其理論」「對照／比較」等，也可以自己打。
- **自動引用**：系統讀每篇論文的參考文獻，用期刊卷頁、DOI、arXiv、標題比對論文庫，自動建立「引用」關聯。
  - 上傳新論文時會自動更新。
  - 手動刪除的自動關聯不會再被加回來。
- **關聯圖**：
  - **分群版面**：每個分類一個框。跨分類的自動引用線畫得比較淡。
  - **時間軸版面**：橫軸是年份，每個分類一條泳道。
  - 節點越大，代表被越多篇引用。縮小時只顯示重要論文的名字，放大才會全部出現。
  - 滑過或點選論文時，只凸顯與它相連的論文。右側會列出它引用誰、被誰引用，點名字可以跳過去。
  - 另外有搜尋框、分類篩選、「以這篇為中心」，以及可收合的圖例（點分類會放大到那一群）。

### 6.13 搜尋

在頂列搜尋框輸入後按 Enter。結果頁上方可以切換兩種模式，網站會記住你上次用的模式。

- **關鍵字搜尋**：搜尋標題、作者、期刊、全文、重點欄、公開筆記。
  - 多個詞用空白分隔，結果必須全部符合。
  - `EP`、`SM` 這類短縮寫會以整個字比對。
  - 結果依相關度排序，並顯示命中的片段。
- **語意搜尋**：用一段描述找「意思接近」的論文，例如「用 YIG 做非互易耦合的」「atom in front of a mirror」。
  - 不必完全對上字。卡片上的「相關：…」是這篇和你的描述共同的關鍵詞。
  - 內建引擎不需設定；中文描述會先用 AI 轉成英文關鍵字（需要設定 AI），也會直接比對中文的重點欄與筆記。
  - 接上向量模型後（見第九章），換句話說、中英文混搜都更準。
- **相似論文**：每篇論文的「關聯」分頁最下方列出最相似的幾篇，附共同關鍵詞；還沒建立關聯的可以直接按「建立關聯」。

### 6.14 AI 功能

- **AI 預填**：在「重點」分頁按「AI 預填」。AI 讀全文後給建議，你勾選、修改後才套用。
- **問這篇**：針對單篇論文提問。
- **問論文庫**：左側選單「問論文庫（AI）」。
  - AI 會先在論文庫搜尋相關論文（全文、重點欄、公開筆記），再回答，並用 `[citekey]` 標出處，點了會跳到該論文。
  - 可以限定只找某個分類。
- **AI 綜述**：左側選單「AI 綜述」。只有管理員或同時有「管理」和「AI」權限的人可以整批執行。
  1. **逐篇填寫重點欄**：選範圍與模式後開始，頁面會顯示篇數、預估時間與費用。
     - 已經有人寫的欄位不會被覆蓋。
     - 掃描檔請先做 OCR。
  2. **分類綜述**：每個分類一份，內容包括一句話總結、研究脈絡、架設與參數比較表、主要結果、未解問題、和我們實驗的關係、建議閱讀順序。
  3. **整個論文庫總覽**：彙整各分類的綜述。
  - 也可以按「一鍵：填重點欄 → 分類綜述 → 總覽」，三步依序在背景執行。
  - 綜述可以下載成 Markdown。分類頁右上角也有「AI 綜述」按鈕。
- AI 產生的內容請對照原文確認，尤其是數值。

### 6.15 新論文追蹤

左側選單「新論文追蹤」。

- 系統每天在設定的時間自動檢查（預設 7:00），也可以按「立即檢查」。
- **arXiv 追蹤**：填關鍵字（搜尋標題與摘要），並可限制 arXiv 分類，例如 `cond-mat.mes-hall`、`quant-ph`。
- **期刊 RSS**：內建 PRL、PRB、PRA、PR Applied、PRX Quantum、Nature Physics、Nature Communications、npj Quantum Information 的網址，也可以貼其他期刊的 RSS；關鍵字留空就全部收錄。
- 每個追蹤可以設定「加入論文庫時自動加的標籤」。
- 找到的論文先列在「待看」，按「加入論文庫」才會建立，arXiv 的會一併下載 PDF。
- 不要的按「略過」；已經在論文庫的會自動標示。

**期刊搜尋**（左側選單「新論文追蹤 → 期刊搜尋」）：在指定期刊裡依關鍵字與時間範圍找論文，不限最近幾天。

- **期刊**：內建 Physical Review 系列（PRL、PRX、PRX Quantum、PRA、PRB、PRE、PR Applied、PR Research、RMP）、Nature 系列（Nature、Nature Physics、Nature Communications、Nature Photonics、Nature Materials、Nature Nanotechnology、Nature Reviews Physics、npj Quantum Information、Communications Physics）、Science 與 Science Advances，以及 APL、Physics Letters A、New Journal of Physics、Optica、J. Appl. Phys.。每組可以全選或清除；有「管理」權限的人可以用 ISSN 新增其他期刊。
- **關鍵字**：清單是從論文庫每篇的標題與摘要抽出的單字與片語（例如 exceptional point、level attraction、waveguide qed），**依出現在幾篇論文排序**，右邊的長條與數字是篇數。上方可以篩選，也可以自己輸入。
- **交集／聯集**：交集＝標題或摘要要同時出現所有勾選的關鍵字；聯集＝出現任一個就算。還可以填「排除」的字。
- **時間範圍**：近 1 個月、3 個月、半年、1 年、3 年、5 年，或自訂起訖日期（依發表日期）。
- 結果依發表日期由新到舊，標出命中的關鍵字、被引用次數；論文庫已有的會打勾，也可以隱藏。勾選後「加入論文庫」會放進「未歸檔待讀」，開放取用的論文會一併下載 PDF。
- **存成自動追蹤**：把目前的期刊、關鍵字、交集／聯集存成一個追蹤，每天檢查最近一段時間（1–3 個月，依設定的時間範圍；更長時用 30 天）發表的論文，新的出現在「新論文追蹤」。之後在「追蹤設定」按「在期刊搜尋中編輯」可以修改。
- **搜尋引擎**：
  - 建議設定免費的 **OpenAlex 金鑰**（「管理 → 維護與備份 → 新論文追蹤排程」）：搜尋標題＋摘要，交集／聯集由 OpenAlex 直接處理。金鑰到 openalex.org 註冊帳號後在設定頁取得；2026 年起 OpenAlex 必須有金鑰才能正常使用，免費額度對實驗室的用量綽綽有餘。
  - 沒有金鑰時改用 **Crossref**（免金鑰）：先依書目相關度找候選，再在本機依交集／聯集篩選。Nature、Science 通常不提供摘要給 Crossref，所以主要是比對標題，找到的會比較少。

### 6.16 組會與閱讀清單

左側選單「組會／閱讀清單」。

- 新增組會（日期、標題、備註），再加入論文與報告人；也可以只寫自由主題。
- 論文頁「⋯ → 排進組會」可以直接排入。
- 被排到的人會收到通知，首頁會提醒「你接下來要報告」。
- 論文頁標題下方會顯示接下來的組會與報告人。
- 每場組會右上角的「投影片」按鈕可以產生整場的 PowerPoint，見 6.26。

### 6.17 通知

右上角鈴鐺的紅點代表有未讀通知。會通知的事件：

- 有人在筆記或討論中 @你
- 有人回覆你參與的討論
- 有人指派論文給你
- 你指派的論文被讀完
- 有論文被設為全站必讀
- 你被排進組會報告
- 有人幫你安排了入門路徑

點通知會直接跳到對應的論文或標註。

### 6.21 參數比較與對照表

左側選單「研究工具 → 參數比較與對照表」。四個分頁：

**① 比較表**
- 加入要比較的論文（上方搜尋框），或在論文列表按「選取」勾幾篇 →「比較參數」。
- 每一列是一個參數，每一欄是一篇論文。滑鼠移到格子上會看到原文的寫法、換算說明與頁碼；有編輯權限的人點格子就能修改。
- 有 g、κ_m、κ_c 的論文，最下面會自動算出**協同度 C = g²/(κ_m κ_c)** 與**耦合區間**（強耦合、Purcell 區、磁致透明、弱耦合；g/ω ≥ 0.1 時標示超強耦合）。
- 「AI 抽取沒有參數的 N 篇」、「CSV」（Excel 可開）、「AI 解讀這張表」（落在哪個區間、差異的原因、換成 cQED 語言、對我們的啟示）。

**② 名稱對照（magnon 參數名稱對照表）**
- 約 30 個常用參數，依「頻率與磁場、耦合、損耗與線寬、導出量與區間、非厄米與波導、材料與樣品、量測與環境」分群。
- 每個參數有：名稱、符號、**其他寫法**（例如耦合強度在不同論文寫成 g、g_m、g_mc、g_eff、J；線寬寫成 κ、γ、δ）、統一單位、定義、**慣例與陷阱**（HWHM／FWHM、rad/s 與 Hz、Oe 與 mT、協同度的兩種寫法）、qubit／cavity 對應。
- 頻率與速率一律記 ω/2π（Hz 單位），線寬一律記 HWHM。AI 抽取參數時就照這張表認名稱、換單位。
- 有「管理」權限的人可以新增、修改（點任一列）；勾掉「放進比較表」的參數不會出現在比較表與 AI 抽取裡。

**③ 預估值（各平台的典型數量級）**
- 依平台列出典型範圍：YIG 球＋3D 腔（室溫、mK）、YIG＋平面共振器、YIG＋開放波導、magnon＋超導 qubit、金屬鐵磁膜，以及材料常數（YIG 的 M_s、旋磁比、自旋密度）。
- 「論文庫實測」欄是從已填參數的論文算出的實際範圍與篇數，可以和預估值對照。
- 預設內容是常見數量級，**請以原文核對並依實驗室經驗修改**。

**④ qubit／cavity 對照**
- 把 magnon 的描述對應到超導電路（cQED）與原子腔／波導 QED 的語言，附公式或換算。例如：Kittel 模 ↔ 諧振子；g ↔ 真空 Rabi 分裂 2g；κ_m ↔ qubit 的 γ₁ = 1/T₁；κ_e／κ_i ↔ κ_ext／κ_int（β 因子）；耗散耦合 ↔ 波導 QED 的關聯衰減 Γ₁₂；YIG 在短路端前 ↔ 鏡前原子；多點耦合 ↔ 巨原子；magnon Kerr ↔ transmon 非諧性。
- 讀 cQED 或波導 QED 的論文時，用這張表換回 magnon 的說法。

**論文頁的參數**
- 「重點」分頁最下方有「參數」區塊：「編輯」手動填；「AI 抽取」讓 AI 讀全文找參數，換好單位後列出來給你勾選套用；「比較」開比較表。
- AI 填的值標「AI」，有人修改後標記消失。整個論文庫一次抽取在「管理 → 維護與備份 → AI 批次抽取參數」。

### 6.22 圖表剪貼簿（圖卡）

- **框選**：論文頁閱讀器上方的「框選」圖示（或「圖卡」分頁的「框選圖／公式」）→ 在 PDF 上拖出範圍 → 確認後存成圖卡。手機也可以用手指拖。按 Esc 取消。
- 伺服器會用高解析度重新裁切（不是截螢幕），放大或放進投影片都清楚。
- **圖說自動抓**：系統會找框選範圍下方（表格是上方）以「FIG.」「Table」開頭的文字當圖說，可以修改。也可以寫筆記（這張圖要看什麼）。
- **類型**：圖、公式、表格。公式可以按「轉成 LaTeX」讓 AI 辨識（需要支援看圖的模型，Claude 都可以）。
- **圖卡能做的事**：複製圖片（直接貼到投影片或筆記）、下載 PNG、複製 LaTeX、點圖跳回原文位置（會閃一下框）。
- 論文頁的「圖卡」分頁列出這篇的圖卡；左側選單「圖表剪貼簿」列出全部，可以依類型、只看我的、關鍵字篩選，勾選幾張「下載 ZIP」或「做成投影片」。
- 只有做圖卡的人（或管理員）能刪除。

### 6.24 預印本與重複論文

- **自動偵測正式發表**：每週日清晨，系統檢查只有 arXiv 編號的論文：
  - arXiv 記錄了正式版 DOI → 直接更新 DOI、期刊、年份，類型改為期刊論文（保留 arXiv 編號）。
  - 否則用標題＋第一作者在 Crossref 比對；相似度很高才自動更新，不確定的列出來等人確認。
  - 論文頁標題下會顯示「已正式發表」；待確認的會出現在「書目」分頁上方。
  - 單篇可以在「書目」分頁按「檢查是否已正式發表」。
- **重複論文**：同一 DOI、同一 arXiv 編號、同一篇的預印本與正式版、或同一作者且標題幾乎相同的論文，會列在左側選單「預印本與重複論文」。
- **合併**（需要「管理」權限）：選要保留為主的那篇（預設是正式版），按「合併」。
  - 另一篇的 PDF 變成「其他版本」（標為 arXiv 版）。
  - 標註與討論、圖卡、參數、關聯、分類與資料夾、標籤、每個人的閱讀狀態（取進度較多的）、指派、組會、入門路徑都搬到保留的那篇；重點欄空白的欄位用另一篇補。
  - 被合併那篇的資料備份在 `data/trash/`。
  - 不是重複的按「不是重複」，之後不會再提示。
- 可以在「管理 → 維護與備份」關掉自動檢查，或改成只提示、不自動更新。

### 6.25 新人入門路徑

左側選單「入門路徑」。

- **建立**（需要「指派」權限）：「新增路徑」→ 名稱、說明 → 加入論文並排順序，每篇寫「讀這篇要看懂什麼」。
  - 有設定 AI 時可以按「起草」：AI 依重點欄從指定分類挑 4–8 篇、由淺入深排序並寫閱讀目標，之後再調整。
- **加入**：成員可以自己「加入這條路徑」，或由學長姐「安排成員」（會收到通知）。加入後，路徑上的論文自動列入他的「待讀」。
- **進度**：用每個人自己的「已閱讀」狀態計算。路徑頁顯示每篇誰讀完（✓）、誰在讀（…），以及每位成員的進度與下一篇。**路徑成員的進度對大家公開**，其他閱讀狀態仍是私人的。
- 首頁會提醒「入門路徑：下一篇 …」；論文頁標題下方顯示「路徑 第 N/M 步」，「重點」分頁最上面顯示這一步的閱讀目標。

### 6.26 組會投影片

- **整場組會**：「組會／閱讀清單」每場右上角「投影片」。
- **單篇論文**：論文頁「⋯ → 產生報告投影片」。
- **圖卡**：圖表剪貼簿勾選後「做成投影片」。
- 對話框可以選要放哪幾張圖卡，以及內容來源：
  - **直接用重點欄**：立即產生、不花錢。
  - **AI 精簡成要點**：AI 把重點欄、參數、標註改寫成每頁 2–5 點的短句。
- 每篇論文的頁面：標題頁（作者、期刊、DOI、第一頁預覽）→ 這篇在做什麼（背景、架設＋一張圖卡）→ 關鍵參數表 → 其他圖卡 → 可萃取特徵與和我們的關係 → 疑問與討論（大家標成紅色「疑問」的標註）。整場會加封面、議程、結尾。
- 產生的是 16:9 的 PowerPoint（.pptx），可以用 PowerPoint、Keynote、Google 簡報開啟再修改；完整重點欄與疑問原文放在講者備忘稿。字型是 Calibri＋微軟正黑體，Mac 會自動換成蘋方。
- 伺服器保留最近 40 份，舊的自動清掉。

### 6.27 實驗室動態看板

左側選單「實驗室動態」，可以看 30 天、90 天或一年：

- 新增論文、公開標註、討論回覆、圖卡、手動關聯的數量，以及和前一期相比的增減。
- 每月新增論文、每月公開標註（近 12 個月）；論文發表年份分布；各分類論文數。
- 成員貢獻（上傳、標註、回覆、圖卡、關聯）。
- 最常被打開的論文（幾個人、幾次）與熱門討論。
- 閱讀進度：全站必讀的整體完成率、指派完成率、各入門路徑的成員進度。
- **隱私**：只統計公開的內容。私人筆記與個人閱讀狀態不列入個人統計；開啟次數只統計總數，不顯示誰看了哪篇。

### 6.28 安裝成 App 與離線閱讀

- **安裝**：頭像選單「安裝成 App」（Android、電腦的 Chrome／Edge）或「加到主畫面」（iPhone／iPad，有圖解）。安裝後全螢幕開啟，沒有網址列；主畫面長按圖示有「我的待讀、新論文追蹤、組會」捷徑。
- **需要 HTTPS**：手機與瀏覽器只允許 HTTPS 網站安裝成 App、使用離線功能。用 `http://100.x.x.x:8080` 開啟時仍可正常使用網站，但不能安裝與離線；請改用第四章方式 A、B 或 C 的 https 網址。
- **離線閱讀**：
  - 看過的頁面（論文列表、論文資料、標註）會留在裝置上，沒網路時顯示上次的內容，畫面下方會出現「離線中」。
  - 讀過的最近 20 篇 PDF 會在背景完整下載一份，之後沒網路也能讀。
  - 論文頁「⋯ → 離線保存」：把這篇的 PDF、附件、標註、圖卡、參數存到裝置上，不會被擠掉，適合出差、搭飛機前先存。
  - 離線時可以閱讀，但新增或修改（劃線、筆記、狀態）無法儲存，會提示你連上網路後再試。
- **管理**：頭像選單「離線閱讀與儲存空間」看已保存的論文、用了多少空間，可以關掉「自動保存最近讀過的 PDF」或清除快取。
- 登出時會清掉這個帳號在裝置上的快取，換人登入不會看到上一個人的資料。
- iPhone／iPad 請從主畫面的圖示開啟；只用 Safari 瀏覽而沒加到主畫面時，iOS 可能在一段時間沒使用後清掉保存的資料。

## 七、帳號、角色與權限

三種角色，各有預設權限。每個帳號都可以在「管理 → 使用者與權限 → 權限」逐項加開或收回。

- **站長**：網站的擁有者，擁有管理員的全部權限，另外負責審核註冊、指定或取消站長。
  - 剛更新時還沒有站長：管理員在「管理 → 使用者與權限」對任一帳號按「設為站長」（會自動變成管理員）。
  - 有站長之後，**只有站長**能指定或取消站長；其他管理員也不能修改站長的帳號（角色、權限、密碼、2FA、停用）。
  - 最後一位站長不能取消自己的身分，要先把另一位設為站長（交接）。站長的帳號不能停用。
- **註冊申請**：登入頁的「還沒有帳號？申請註冊」，填用戶名稱、帳號、密碼（至少 8 字元）、Email，可以附申請說明。
  - 申請送給站長：站內通知＋寄信（要先設定 SMTP，見第十章）；左側「管理」旁會出現待審數字。
  - 站長在「管理 → 使用者與權限 → 註冊申請」選角色（成員或唯讀訪客）按「通過」，或「不通過」（可寫原因寄給對方）。通過後帳號立即可用，並寄信通知。
  - 還在審核中的人登入時，會看到「申請還在等站長審核」。
  - 還沒有站長時由管理員代為審核。可以取消勾選「開放在登入頁申請帳號」關閉註冊。
  - 同一個網路一小時最多送出 5 筆申請，並有防機器人欄位。
- **Email 提醒**：還沒填 Email 的帳號，每次登入會跳出提醒填寫（可以按「下次再說」）；填了才收得到通知信與每週摘要。頭像選單也有「填寫 Email」。
- **限制項「只能修改自己上傳的論文」**：勾選後，這個帳號只能編輯、分類、加附件、刪除自己上傳的論文。其他論文只能閱讀、劃線、翻譯。適合學弟妹或外部合作者。
- **只有管理員能做的**：管理帳號、網站設定、備份、Zotero，以及 AI 整批處理（或有「管理＋AI」權限的人）。管理員永遠擁有全部權限。
- **所有人都能做的**：閱讀狀態是私人的，任何人都能改自己的；看參數表、圖卡、看板、產生投影片（不用 AI 時）、加入入門路徑。
- **標註與關聯**：只有建立者本人或管理員能修改、刪除。自動引用關聯則有「關聯」權限的人都能刪。
- 權限一律在伺服器端檢查，沒有權限的按鈕在畫面上也會隱藏。
- 刪除的論文和檔案不會直接消失，會移到 `data/trash/`。

## 九、翻譯與 AI 服務設定

在「管理 → 網站、翻譯與 AI」設定。金鑰只存在 NAS 的資料庫，不會傳到瀏覽器。NAS 需要能連外網；自架的 LibreTranslate 或 Ollama 則只需要區網。

### 建議做法：一把 Claude 金鑰同時處理翻譯與 AI

1. 到 console.anthropic.com 註冊。
2. 在 **Billing** 儲值（先儲 5–10 美元即可），建議設定每月花費上限。
3. 在 **API Keys** 建立一把金鑰。
4. 回到論文庫的「網站、翻譯與 AI」：
   - 翻譯服務選「Claude（Anthropic API）」，貼上金鑰，模型留空，按「儲存並測試」。
   - AI 服務選「沿用翻譯設定」。
   - 「實驗室背景」寫兩三句，例如：「VNA 量 YIG 與 1D 波導／node mirror 耦合的 S21、S11，調整磁場與位置；關心 level attraction、EP、非互易、巨原子」。AI 填「與我們實驗的關係」時會參考這段。按「儲存並測試」。

預設模型是 `claude-haiku-4-5-20251001`，費用大約是：

| 動作 | 約略費用 |
| --- | --- |
| 翻譯一段文字 | < 0.01 美元（第二次翻譯同一段不計費） |
| AI 預填一篇重點欄 | 0.02–0.03 美元 |
| 問論文庫一題 | 0.03–0.05 美元 |
| 整批填寫 100 多篇 | 約 3 美元 |
| 一份分類綜述 | 幾分錢 |
| AI 抽取一篇的參數 | 0.02–0.03 美元 |
| 一條公式轉 LaTeX | < 0.01 美元 |
| 一篇論文的投影片「AI 精簡」 | < 0.01 美元 |

### 各服務比較

| 服務 | 用途 | 需要填 | 說明 |
| --- | --- | --- | --- |
| Claude（Anthropic） | 翻譯、AI | 金鑰 | 品質最好，會保留專有名詞原文，例如「磁振子（magnon）」 |
| OpenAI 相容 | 翻譯、AI | 金鑰、網址、模型 | 可以接 OpenAI；網址留空、模型預設 `gpt-4o-mini` |

| Google Cloud Translation | 翻譯 | API key | 依字數計費 |
| LibreTranslate（自架） | 翻譯 | 網址 | 資料不出實驗室，物理專有名詞的品質較弱 |

### 自架 Ollama

1. 找一台有顯示卡的電腦，安裝 Ollama，執行：
   ```bash
   ollama pull qwen2.5:14b
   ```
2. 設定環境變數 `OLLAMA_HOST=0.0.0.0` 後重開 Ollama，讓 NAS 連得到。
3. 在論文庫的設定：
   - 翻譯和 AI 都選「OpenAI 相容」。
   - 網址填 `http://<那台電腦的 IP>:11434/v1`，模型填 `qwen2.5:14b`，金鑰留空。
   - 「每次最多送出的字數」改成 15000 左右，因為本地模型一次能讀的長度比較短。

### 語意搜尋的向量模型（選用）

語意搜尋與相似論文有內建引擎，不設定也能用。想要更準（換句話說、中英文混搜）時，在「管理 → 網站、翻譯與 AI → 語意搜尋與相似論文」選「向量模型」：

| 服務 | 網址 | 模型 | 說明 |
| --- | --- | --- | --- |
| OpenAI | 留空 | `text-embedding-3-small` | 整個論文庫建一次通常不到 0.1 美元 |
| Voyage AI（Anthropic 推薦的向量服務） | `https://api.voyageai.com/v1` | `voyage-3.5` | 在 voyageai.com 申請金鑰 |
| Ollama（自架） | `http://<主機>:11434/v1` | `bge-m3` | 先 `ollama pull bge-m3`；免費，中英文都好，金鑰留空 |

按「儲存並測試」確認連得到，再按「建立全部向量」。之後新論文每天清晨自動補上；論文內容有改才會重算。

### 自架 LibreTranslate


## 十、通知與每週摘要

在「管理 → 通知與摘要」設定。

- **站內通知**：不用設定，右上角鈴鐺就會顯示。
- **每週摘要**：
  - 內容：
    - 接下來兩週的組會與報告人
    - 本週新增的論文
    - 誰標註了多少
    - 新論文追蹤的待看數
  - 寄給個人的 Email 還會多列出：
    - 他要報告的論文
    - 指派給他還沒讀完的論文
    - 必讀還差幾篇
    - 未讀通知數
  - 可以選每週寄送的星期與時間。
- **Email（SMTP）**：網站用這個帳號寄出通知信、每週摘要、註冊審核信。建議開一個實驗室專用的 Gmail。
  1. 那個 Google 帳號先開啟「兩步驟驗證」（Google 帳戶 → 安全性）。
  2. 到 Google 帳戶搜尋「應用程式密碼」，建立一組（名稱例如 paperlib），會得到 16 個字母的密碼。
  3. 論文庫「管理 → 通知與摘要 → Email（SMTP）」填：主機 `smtp.gmail.com`、連接埠 `587`、加密 `STARTTLS（587）`、帳號＝完整 Gmail 地址、密碼＝剛剛的 16 字應用程式密碼（不是 Gmail 登入密碼）、寄件人留空或填同一個地址。
  4. 按「儲存」→「寄測試信給我」（要先在「我的帳號」填你自己的 Email）。收不到時看「管理 → 維護與備份 → 背景工作」裡「寄送通知信」的錯誤訊息，或控制台的「背景工作與維護」。
  - 學校信箱：用學校提供的 SMTP 主機與埠（多半是 587 STARTTLS 或 465 SSL），帳號密碼同信箱；有些學校只允許校內網路寄信。
  - 常見錯誤：`Authentication failed`＝帳號或應用程式密碼錯；`Connection refused／timed out`＝主機或埠錯，或 NAS 連不到外網。
  - 成員在「我的帳號」填 Email，也可以自行取消訂閱每週摘要。
- **還沒填 Email 的帳號**：每次登入會跳出填寫視窗；已經登入、分頁一直開著的人，網站也會定期檢查並提醒，首頁頂端也會有提醒列。管理員在「管理 → 使用者與權限」（或控制台「帳號」分頁）按「提醒他們填寫」，會送站內通知，對方的網頁在一分鐘內跳出填寫視窗。
- **Webhook**：把摘要貼到實驗室的聊天頻道。
  - Discord：頻道設定 →「整合」→「Webhook」。
  - Slack：用 Incoming Webhook。
  - Teams 也可以用。
- 設定頁有「預覽摘要」「寄測試信給我」「測試 Webhook」「立即寄送本週摘要」可以先試。

## 十一、Zotero 同步

在「管理 → Zotero」設定。

1. 登入 zotero.org → **Settings → Security** → **Create new private key**，勾選要同步的 library 的讀寫權限。
2. 填入 Library ID：
   - 個人 library 的 ID 在同一頁的「Your user ID」。
   - 群組 library 的 ID 在群組網址 `zotero.org/groups/<ID>`。
3. 按「測試連線」→「立即同步」。也可以開啟「每天凌晨自動同步」。

同步內容：

- **推送到 Zotero**：
  - 書目與標籤。
  - 分類對應成指定收藏夾下的子收藏夾。
  - 重點欄與公開標註寫成子筆記。
  - 有設定網站網址時，會附上「在論文庫開啟」連結。
  - 之後每次同步都更新同一個項目，不會重複建立。
- **從 Zotero 匯入**（可以關閉）：
  - Zotero 裡有、論文庫還沒有的項目，會進「未歸檔待讀」，並加上標籤「Zotero 匯入」。
  - 有 PDF 附件的會一併下載。
  - DOI 或標題相同的會對應到既有論文，不會重複。

## 十四、更新程式

三種方式擇一。都不會動到 `data/`（論文、筆記、設定）與 `import/`，而且都會先把資料庫備份到 `data/backups/before-update-日期.db`（保留最近 5 份）。

### 方式 0：控制台程式（推薦，監控＋更新都在這裡）

**Windows**：直接執行 **`PaperlibConsole.exe`**（單一執行檔，不用裝 Python）。第一次開啟會問要不要在桌面建立「論文庫控制台」捷徑。
- 檔案沒有數位簽章，第一次開啟時 Windows 可能顯示「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
- 要自己重新打包 exe：在 `tools/console` 執行 `build-exe.bat`（需要 Python）。

**Mac 或想用 Python 執行**：雙擊 `console-mac.command`（Windows 也可以用 `console-windows.bat`）。需要 Python 3.10 以上；第一次開啟會自動建立環境並安裝連 NAS 用的 paramiko，約 1 分鐘。

- **登入網站**：用管理員或站長帳號登入（可勾「記住登入」）。**連線 NAS**：DSM 帳號密碼（密碼只留在這次開啟的程式裡）。
- **總覽**：網站是否正常、回應時間、程式版本、連續執行多久；近 60 分鐘的請求數、伺服器錯誤、平均回應、最慢的請求、線上人數；容器狀態、健康檢查、CPU、記憶體；論文與使用者數量、待審註冊；NAS 剩餘空間、資料量、資料庫檢查、最近備份；SMTP／AI／OCR／站長設定檢查；回應時間與請求量圖；自動整理的「提醒」（空間不足、太久沒備份、背景工作失敗、有伺服器錯誤、有待審註冊、網站版本比手上的舊⋯）。
- 每 30 秒自動檢查（可在「設定」改）；網站沒有回應時會跳出視窗提醒，恢復時也會通知。
- **帳號**：所有帳號的列表（身分、Email、個別權限調整、停用、2FA）。可以新增帳號、編輯（帳號名稱、名稱、Email、角色、逐項權限、停用）、重設密碼、重設 2FA、設為／取消站長、**刪除帳號**；上方可以審核註冊申請。
  - 刪除帳號會一起刪掉他的登入、閱讀狀態、被指派的論文、通知、入門路徑進度、筆記頁設定與私人筆記；上傳的論文保留。可以選擇連同公開的標註、手寫、討論一起刪，或保留（顯示為「已刪除的帳號」）。要輸入帳號名稱確認，不能復原。
  - 站長的保護一樣適用：有站長之後，只有站長能修改或刪除站長帳號；不能刪除自己，也不能刪除最後一位站長。網站的「管理 → 使用者與權限」也有同樣的「刪除」按鈕。
- **背景工作與維護**：最近的背景工作與結果；立即執行「檢查新論文、重新分析引用、檢查預印本、檢查 PDF 文字層、重建相似度索引、寄送每週摘要」；備份資料庫（可直接下載到這台電腦）、重建全文索引、OCR 所有掃描檔。
- **日誌**：網站記下的錯誤與警告；容器日誌（最後 400 行）。
- **更新與重啟**：選擇新版的 zip（或資料夾）→「更新網站」，過程即時顯示（停止舊容器 → 備份資料庫 → 換程式 → 重建 → 啟動 → 確認版本）；也可以「完全重建」、「重新啟動網站」、「停止」、「啟動」。

### 方式 A：一鍵更新（推薦）

在自己的電腦上解壓縮新版，雙擊：

- **Windows**：`update-windows.bat`
- **Mac**：`update-mac.command`（第一次若被擋，按右鍵 →「打開」）

第一次會問 NAS 的 IP、SSH 埠、DSM 管理員帳號、專案資料夾（預設 `/volume1/docker/paperlib`），之後會記住。接著依提示輸入 DSM 密碼（輸入時畫面不會顯示，總共會問 2–3 次；第一次連線問是否信任這台 NAS 時輸入 `yes`）。工具會自動：傳程式到 NAS → 停掉舊容器（包括專案「停止」停不掉的）→ 備份資料庫 → 換新程式 → 重建 → 啟動 → 確認網站回報的版本號。

事前準備（只需一次）：DSM「控制台 → 終端機和 SNMP → 啟動 SSH 功能」，帳號要在 administrators 群組。Windows 需要 Windows 10 以上（內建 ssh 與 tar）。

### 方式 B：自己用 SSH

1. 用 File Station 把新版的**內容**蓋到 `docker/paperlib`（直接在 NAS 上解壓縮也可以；多一層 `paperlib/paperlib` 沒關係，工具會自己處理）。
2. 登入 NAS：
   - Windows：開始選單搜尋「PowerShell」打開，輸入 `ssh 帳號@NAS的IP`（例如 `ssh admin@192.168.1.20`，SSH 埠不是 22 就加 `-p 埠號`）。
   - Mac：打開「終端機」，輸入同樣的指令。
   - 第一次連線會問 `Are you sure you want to continue connecting`，輸入 `yes`；接著輸入 DSM 密碼（畫面不會顯示，打完按 Enter）。
3. 執行：
   ```bash
   sudo bash /volume1/docker/paperlib/update.sh
   ```
   再輸入一次密碼。看到綠色「✓ 更新完成：目前版本 x.y.z」就好了，輸入 `exit` 離開。
   - 要完全不用快取重建（例如懷疑映像檔壞掉）：`sudo bash /volume1/docker/paperlib/update.sh --clean`，約 5–10 分鐘。
4. 舊版還沒有 `update.sh` 的話，改用：
   ```bash
   cd /volume1/docker/paperlib
   sudo docker stop paperlib; sudo docker rm paperlib
   sudo docker-compose -p paperlib build
   sudo docker-compose -p paperlib up -d
   ```

### 方式 C：Container Manager 介面

1. 先備份 `data/`，用新版程式覆蓋專案資料夾。
2. Container Manager →「專案」→ 選 paperlib →「停止」→「建置」→「啟動」。
   - 選單裡沒有「建置」時，依序按「停止」→「清除」→「建置」。「清除」只移除容器，不會動資料。
   - 專案按「停止」後網站仍在執行：到左側「**容器**」頁選 `paperlib` 停止並刪除，再回「專案」建置。這種情況用方式 A 或 B 最省事。
3. 資料庫會在啟動時自動升級，既有資料不受影響。

### 更新後

- 瀏覽器強制重新整理一次：電腦按 Ctrl＋F5，手機把 App 或分頁關掉再開。
- **確認版本**：右上角頭像選單的「程式版本」要和 `app/config.py` 的 `VERSION` 一致。

**更新後看起來沒變？**依序檢查：

1. **檔案有沒有放對位置**：用 File Station 打開專案資料夾（例如 `docker/paperlib`），看 `app/config.py` 裡的 `VERSION` 是不是新版號。解壓縮時常會多一層，變成 `docker/paperlib/paperlib/app/…`，這時 Container Manager 建置的還是舊檔案；請把內層 `paperlib` 裡的東西搬到外層覆蓋。
2. **伺服器有沒有換成新程式**：瀏覽器打開 `http://<NAS>:8080/api/site`，看 `"version"` 的值。
   - 值是新版號，但畫面還是舊的：是瀏覽器快取，按 Ctrl＋F5；還不行就用無痕視窗開一次。
   - 沒有 `version` 或版號是舊的：伺服器還在跑舊的映像檔，看下一步。
3. **強制重新建置**：Container Manager →「映像」刪掉舊的 `paperlib` 映像檔，再到「專案」按「建置」→「啟動」。或用 SSH：
   ```bash
   cd /volume1/docker/paperlib
   sudo docker compose build --no-cache
   sudo docker compose up -d
   ```
4. 還是不行時，看「專案 → 日誌」有沒有錯誤訊息（例如套件下載失敗）。建置失敗時 Container Manager 會沿用舊的映像檔繼續跑。

**不要刪除專案再重建**：刪除時如果勾到「一併刪除專案資料夾」，`data/` 會一起不見。

## 十五、常見問題

**連不到網站？**
- 確認建立專案時沒有勾選 Web Station 網頁入口。
- 先用區網 IP 試 `http://<NAS IP>:8080`。
- 走 Tailscale IP 連不到時，檢查 NAS 防火牆是否允許 100.64.0.0/10。
- 看 Container Manager 裡專案的「日誌」，確認有出現 `Application startup complete`。

**瀏覽器擋下了閱讀桌視窗？**
允許這個網站的彈出視窗；或在頭像選單關掉「論文開在獨立的閱讀桌視窗」。

**掃描檔選不到字、搜尋不到？**
在「檔案」分頁按「OCR 辨識文字」，或到「管理 → 維護與備份」按「OCR 所有掃描檔」。中文論文請把辨識語言設成 `eng+chi_tra`。

**翻譯或 AI 沒有反應？**
到「管理 → 網站、翻譯與 AI」按「儲存並測試」看錯誤訊息。最常見的原因是 NAS 連不到外網、金鑰錯誤，或帳戶餘額不足。

**自動引用太多、太雜？**
關聯圖可以取消勾選「自動引用」。個別錯誤的自動關聯可以在論文的「關聯」分頁刪除，刪除後不會再被加回來。

**成員忘記密碼、手機遺失？**
管理員在「使用者與權限」按「重設密碼」或「重設 2FA」。

**手機上沒有「安裝」、離線不能用？**
網址必須是 HTTPS（見 6.28 與第四章）。iPhone 要用 Safari 的「分享 → 加入主畫面」；Android 用 Chrome。

**框選圖卡時頁面一直捲動？**
先按閱讀器上方的「框選」圖示（按鈕變成藍色）再拖；完成或按「取消」後就恢復一般捲動與選字。

**投影片的中文字型不對？**
投影片用 Calibri＋微軟正黑體，Windows 的 PowerPoint 會完全一致；Mac 與 Google 簡報會自動換成系統的中文字型，版面可能略有差異，可以全選後換成你習慣的字型。

**語意搜尋找不到中文描述的論文？**
內建引擎要靠 AI 把中文問題轉成英文關鍵字，請先設定 AI；或接上向量模型（第九章）。也可以直接用英文描述。

**背景工作卡住？**
「管理 → 維護與備份 → 背景工作」可以看每個工作的進度與錯誤。重開容器後，中斷的工作會自動重新排隊。

## 十六、技術架構

- **後端**：
  - Python 3.11、FastAPI、Uvicorn。
  - SQLite（WAL），全文索引用 FTS5 trigram。
  - PyMuPDF：抽文字、縮圖、帶標註 PDF。
  - OCRmyPDF＋Tesseract：OCR。
  - segno：兩步驟驗證的 QR code。
  - python-pptx：組會投影片。
- **背景工作**：程式內建的工作佇列與排程，存在資料庫的 `jobs` 表，不需要另外架 Redis 或 cron。
- **前端**：
  - 原生 JavaScript（ES modules），不需要編譯。
  - PWA：manifest＋service worker（`sw.js`），可安裝、離線快取。
  - pdf.js（Apache-2.0）負責 PDF。
  - cytoscape.js 與 cytoscape-fcose（MIT）負責關聯圖。
  - 以上都附在 `app/static/vendor/`，區網沒有外網也能用。
- **安全**：
  - PBKDF2 密碼雜湊。
  - HttpOnly session cookie。
  - 會修改資料的請求都必須帶自訂標頭（防 CSRF）。
  - 登入失敗鎖定、TOTP 兩步驟驗證、安全標頭。

```
paperlib/
  app/
    main.py        主要 API（帳號、論文、檔案、上傳、標註、關聯、搜尋、設定）
    api_more.py    追蹤、AI、組會、指派、必讀、資料夾、通知、OCR、匯出、Zotero
    api_ext.py     參數、圖卡、語意搜尋、預印本與合併、入門路徑、投影片、看板
    params.py      參數對照表、預估值、qubit／cavity 對照、AI 抽參數
    figures.py     圖卡裁切、圖說偵測、LaTeX
    semantic.py    語意搜尋（TF-IDF／向量模型）、相似論文
    versions.py    預印本發表偵測、重複論文、合併
```
